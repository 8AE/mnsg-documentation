`func_801F15E0_5AD4F0` · **Function**

This constructor sets up the native Sudden Impact aura effect for selector 0x23.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x801F15E0` | `0x005AD4F0` | `.file_11` |

Native code size: **748 bytes**.

## Signature

```c
void func_801F15E0_5AD4F0(void *effect_manager, uint32_t selector);
```

## How it works

The effect has a main aura model 0x190006B8 and five satellite effects using model 0x1900074C.

The effect uses resource 0x152 and character asset 0x120.

The constructor masks the selector to its low eight bits before effect selection.

The main aura and satellite objects use task-local material lists at their task +0xA4 fields.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `effect_manager` | `void *` | Native effect manager that owns the allocated tasks. |
| `selector` | `uint32_t` | Effect selector; the constructor masks the low eight bits before effect selection. |

## Return value

No value.

## Usage example

```c
#include <stdint.h>

extern void func_801F15E0_5AD4F0(void *effect_manager, uint32_t selector);

/* This native constructor owns task allocation and callback lifetime. */
```

The example illustrates the native interface and its required state.

## Notes

- The constructor allocates native tasks and owns their callback lifetimes; its declaration is not a safe arbitrary-call interface.
- The RSP material list must resolve in original 8 MiB RDRAM. Whether an individual extended task allocation crosses that boundary depends on its actual address.
