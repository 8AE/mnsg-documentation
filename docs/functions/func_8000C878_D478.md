`func_8000C878_D478` · **Function**

Releases the native allocation belonging to a message-window slot.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8000C878` | `0x0000D478` | `.main` |

Native code size: **88 bytes**.

## Signature

```c
extern void func_8000C878_D478(int slot);
```

## How it works

Releases the selected native window and clears its slot in D_80167C48_168848.

Use a validated slot and verify that its current pointer still belongs to the interaction being closed. A room change or replacement scenario can transfer shared dialog ownership.

This is window cleanup, not a complete scenario cancellation API. Interpreter state, pending callbacks and acquired player-control bits require their own ownership-aware completion.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `slot` | `int` | Validated native window slot, 0 through 2. |

## Return value

No return value.

```c

void release_owned_window(void *owned_window)
{
    if (owned_window && D_80167C48_168848[0] == owned_window)
```

## Notes
