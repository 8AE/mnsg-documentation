`func_0800058C_72BDDC` · **Function**

Stores seconds multiplied by 30 in the waterfall HUD's signed raw timer at +0x84.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x0800058C` | `0x0072BDDC` | `.file_69` |

Native code size: **20 bytes**.

## Signature

```c
void func_0800058C_72BDDC(void *hud_task, int seconds);
```

## How it works

Writes seconds*30 as a 32-bit word at HUD task +0x84. The normal controller call supplies 50, producing 1500 raw 30 Hz countdown ticks.

This helper initializes only the timer scalar. It does not construct the HUD, draw it, create the swimmer, or start the trial.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `hud_task` | `void *` | The live File 69 waterfall HUD task, not its display object or a player task. |
| `seconds` | `int` | Whole-second value. The native trial supplies 50; arbitrary ranges and multiplication overflow behavior are not established. |

## Return value

No return value.

## Usage example

```c
extern void func_0800058C_72BDDC(void *hud_task, int seconds);

/* hud_task must already be the native waterfall HUD. */
void initialize_waterfall_time(void *hud_task)
{
    func_0800058C_72BDDC(hud_task, 50);
}
```

Uses the native trial's observed 50-second timer value after HUD construction. This is not a complete challenge-start sequence.

## Notes

- The helper does not validate the task pointer or clamp seconds. Use only the matching live HUD and a verified bounded value.
