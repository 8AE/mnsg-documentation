`func_08000090_732FC0` · **Function**

Advances the native post-Tsurami reward presentation, dialogue, control release and exit transition.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x08000090` | `0x00732FC0` | `.file_73` |

Native code size: **2604 bytes**.

## Signature

```c
extern void func_08000090_732FC0(void *task, void *object);
```

## How it works

The unsigned phase word is at controller-state +0x00 and its timer at +0x04. Phase zero waits for native flag 0x1AB before acquiring its camera/player-control state.

Creates a Miracle Star child through the file 73 helper at offset 0x0EAC and retains that task in controller-state +0x0C. This reward has entity 0x350; that ID also appears on other reward tasks, so entity ID alone does not establish ownership.

Phase six retires the presented Star through its own native child command, then starts scenario 0x73. That scenario writes 1 to the signed 32-bit inventory field at save +0x250. Receiving inventory ownership is not permission to destroy the controller’s retained actors.

The following story phases include a wait for packed flag 0x074 in phase 15. The flag’s byte offset is +0x0E with mask 0x10; it is separate from the Star inventory field and from a completed controller lifetime.

Phase 23 waits for the timer to be exactly zero. It then calls native player-control release and requests the transition to room 0x0147. Phase 24 destroys the controller. Observe phase 23 with timer zero at entry and its successful return to identify this native terminal path.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Initialized file 73 reward controller; +0xD0 points to its 0x34-byte state block. |
| `object` | `void *` | Native display object supplied by the scheduler. |

## Return value

No return value.

## Usage example

```c
#include "modding.h"

static unsigned int star_scene_terminal_selected;

RECOMP_HOOK("func_08000090_732FC0")
void observe_star_scene(void *task, void *object)
{
    (void)object;
    if (!task) return;
    const unsigned int *state =
        *(const unsigned int *const *)((const char *)task + 0xD0);
    if (!state) return;
    if (state[0] == 23u && state[1] == 0u)
        ++star_scene_terminal_selected;
    /* Native callback performs control release and the room transition. */
}
```

Observe the exact native terminal phase without changing the camera, reward actor, or scenario. Production observers should also validate task identity and room lifetime.

## Notes

- Do not remove a reward child or force a remote story flag while this local scene still owns its camera, task references and player input.
- The inventory grant and story flag can precede final input release and room transition. Never equate either early write with scene completion.
- Do not dereference retained controller state after the terminal room transition or directly invoke its cleanup functions.
