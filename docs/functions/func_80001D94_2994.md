`func_80001D94_2994` · **Function**

Returns the ROM end address for a file-table ID.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80001D94` | `0x00002994` | `.main` |

Native code size: **44 bytes**.

## Signature

```c
extern unsigned int func_80001D94_2994(unsigned int file_id);
```

## How it works

Query both ROM boundaries to calculate the stored file length. Reject end <= start before allocating a destination or requesting DMA.

The boundaries describe stored ROM bytes. Whether they are raw model data or a compressed file depends on the selected asset.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `file_id` | `unsigned int` | File-table ID. |

## Return value

ROM end address as unsigned int.

## Usage example

```c
extern unsigned int func_80001D68_2968(unsigned int file_id);

extern unsigned int func_80001D94_2994(unsigned int file_id);

/* File ID must identify a known raw action-model file. */
unsigned int raw_file_size(unsigned int file_id) {
    unsigned int start = func_80001D68_2968(file_id);
    unsigned int end = func_80001D94_2994(file_id);
    return end > start ? end - start : 0;
}
```

## Notes

- A plausible ROM range does not prove the selected file is raw rather than compressed. The character action-file table identifies known raw model data.
