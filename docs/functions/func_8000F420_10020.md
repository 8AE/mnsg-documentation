`func_8000F420_10020` · **Function**

Plays a spatial sound using coordinates read from a native object.

| Runtime address | ROM address | Section |
| --- | --- | --- |

## Signature


## How it works

Reads object xyz from +0x08/+0x0C/+0x10, then forwards the coordinates, sound ID, sound-state pointer and range argument to FUN_8000F6E8.

A concrete usage is sound 0x2B2, the scene sound-state buffer D_8020CBF0_5C8B00, the current player object and a range of 400.0f.
