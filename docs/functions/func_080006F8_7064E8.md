`func_080006F8_7064E8` · **Function**

Initializes a native collision platform and updates its orbit and vertical motion using a 360- or 240-tick period and a floating-point radius of 30.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x080006F8` | `0x007064E8` | `.file_47` |

Native code size: **576 bytes**.

## Signature

```c
void func_080006F8_7064E8(void *task, void *object);
```

## How it works

Phase 0 initializes the native platform and binds its collision representation. Phase 1 updates pose, visibility and the local motion counter.

Task signed halfwords +0xD2, +0xD4 and +0xD6 hold yaw offset, period and tick. Task floats +0xD8, +0xDC and +0xE0 hold radius, baseline Y and amplitude. The observed radius is 30.0 and amplitude is 20.0.

The first four orbit platforms, in native creation slots 0, 1, 2 and 3, use period 360. The later five orbit platforms, in slots 9, 11, 13, 15 and 16, use period 240. The constructor truncates its floating-point period argument into the signed halfword at +0xD4.

The object XYZ floats are at +0x08, +0x0C and +0x10; object yaw is the halfword at +0x16.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Live task initialized by the matching native constructor. |
| `object` | `void *` | The task's own native render or collision object, where this callback uses one. |

## Return value

No return value.

## Usage example

```c
extern void func_080006F8_7064E8(void *task, void *object);

typedef void (*NativeTaskCallback)(void *, void *);

/* Observe callback identity; the native scheduler owns execution. */
NativeTaskCallback documented_callback(void)
{
    return func_080006F8_7064E8;
}
```

This returns the callback address without executing initialization, moving a platform, or advancing the challenge. The callback requires the matching resident overlay and initialized native task graph.

## Notes

- Collision binding is part of native initialization. A pose-only object is not a replacement for an initialized collision platform.
- The documented layout belongs to this platform callback; it is not a general task layout.
