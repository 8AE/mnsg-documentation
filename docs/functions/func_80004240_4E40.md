`func_80004240_4E40` · **Function**

Clears the native text/UI slot state for transition setup.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80004240` | `0x00004E40` | `.main` |

Native code size: **60 bytes**.

## Signature

```c
extern void func_80004240_4E40(void);
```

## How it works

Identified as clearing sixteen small native text/UI slots beginning at g_system+0x3B168 before the next scene builds its interface.

This concerns the game own UI state. It is not an API for external UI contexts or custom document elements.

No return value in the established declaration.
