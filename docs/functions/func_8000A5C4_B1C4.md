`func_8000A5C4_B1C4` · **Function**

Copies the native kind-2 reset template while preserving its free-list link.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8000A5C4` | `0x0000B1C4` | `.main` |

Native code size: **80 bytes**.

## Signature

```c
extern void func_8000A5C4_B1C4(void *record);
```

## How it works

Resets the 0x98-byte CPU display/model record from the native template and restores the original word at +0x00. This preserves a free-list next pointer while clearing pose, material, segment and cached-tree state.

The template sets byte +0x04 to 0x82 (retired kind 2), byte +0x05 to 5, and byte +0x65 to 1. Allocation clears the retirement bit; native visibility accepts a nonnegative signed +0x65.

## Usage example

```c
extern void func_8000A5C4_B1C4(void *record);

void reset_detached_display_record(void *record) {
    if (record) func_8000A5C4_B1C4(record);
}
```

The example illustrates the native interface and its required state.

## Notes

- Only reset a detached or newly provisioned record. Resetting a live tree node can orphan its children and owner links.
- Storage must cover 0x98 bytes. Native model records have an 8-byte-aligned stride.
