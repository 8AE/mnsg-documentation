`func_80003E10_4A10` · **Function**

Returns a float from the game’s 1024-step sine lookup table.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80003E10` | `0x00004A10` | `.main` |

## Signature

```c
float func_80003E10_4A10(unsigned int angle);
```

## How it works

Masks the integer angle with 0x3FF and returns the corresponding table value with quadrant reflection/sign handling. It performs no gameplay-state update.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `angle` | `unsigned int` | Integer angle word; the helper masks it to its low 10 bits. |

## Return value

The sine-table value as a float in floating-point return register f0.

## Usage example

```c
extern float func_80003E10_4A10(unsigned int angle);

float sample_native_sine(unsigned int angle)
{
    return func_80003E10_4A10(angle & 0x3FFu);
}
```

Uses the native integer-angle lookup. The helper itself also masks the input to 10 bits.

## Notes

- The parameter is an integer word, not a floating-point angle. Keep the native 10-bit angle convention when reproducing callers.
