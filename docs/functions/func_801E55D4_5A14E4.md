`func_801E55D4_5A14E4` · **Function**

Detaches a local player’s held object after rotating its launch velocity and offset into world space.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x801E55D4` | `0x005A14E4` | `.file_11` |

## Signature

```c
void func_801E55D4_5A14E4(void *player, float local_x, float local_y, float local_z);
```

## How it works

Reads the held object from the player task and uses the player object’s current angles to rotate the supplied local velocity into world space. The Impact controller calls it with local velocity (0.0, 4.4, 1.8).

It separately rotates the native launch offset (0, 10, 12), adds the player object world position, writes the held object’s world position and angles, then detaches it from the player.

After the function returns, its writes to the held object’s position, velocity, and attachment state are complete. A return observer can inspect this local release edge after validating the held task identity.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `player` | `void *` | The live local player task whose held-object state is updated. |
| `local_x` | `float` | Local launch-velocity X component. |
| `local_y` | `float` | Local launch-velocity Y component. |
| `local_z` | `float` | Local launch-velocity Z component. |

## Return value

No return value.

## Usage example

```c
extern void func_801E55D4_5A14E4(void *player, float local_x, float local_y, float local_z);
typedef void (*ReleaseCallback)(void *, float, float, float);

ReleaseCallback documented_release_callback(void)
{
    return func_801E55D4_5A14E4;
}
```

Returns the native routine address without invoking the local-player release operation.

## Notes

- This function reads and mutates the live local player and its held object. Do not call it for a remote player or substitute a remote actor pointer.
- Before return, the object can still be attached and its final world velocity and position have not all been written. Observe the completed release after return if needed.
