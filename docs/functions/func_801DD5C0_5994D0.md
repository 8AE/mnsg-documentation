`func_801DD5C0_5994D0` · **Function**

Applies a playable-character swap to the live player task.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x801DD5C0` | `0x005994D0` | `.file_11` |

Native code size: **148 bytes**.

## Signature

```c
extern void func_801DD5C0_5994D0(void *arg0, unsigned char value);
```

## How it works

Writes the selected character to task+0x60 and global 0x8015C5DC, updates the linked player state at task+0x5C, clears movement/action fields, marks character-change state, and sets action byte +0xCC to 0xBA.

Installs the native character-change callback. This mutates the authoritative live player and global character state; visual-only characters should use independent render tasks instead.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `arg0` | `void *` | Live player task. |
| `value` | `unsigned char` | Character ID: Goemon=0, Ebisumaru=1, Sasuke=2, Yae=3. |

## Return value

No return value.

## Notes

- Use only on the actual live player and an enabled/recruited character.
- This changes global player state. It is inappropriate for spawning another visual player model.
