`func_80221FB0_5DD480` · **Function**

Ends a native local-control state by clearing the input lock and its companion player-control state.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80221FB0` | `0x005DD480` | `.file_12` |

Native code size: **36 bytes**.

## Signature

```c
extern void func_80221FB0_5DD480(void);
```

## How it works

Writes zero to D_800C7AE2 and to the companion local-control state byte.

Also clears the pointed local-player control halfword. The function performs the release directly and does not receive an owner token or task pointer.

## Return value

No return value.

## Usage example

```c
#include "modding.h"

static volatile unsigned int local_control_exits;

RECOMP_HOOK("func_80221FB0_5DD480")
void observe_local_control_exit(void)
{
    ++local_control_exits;
}
```

Observes the native release without issuing another global unlock.

## Notes

- The routine does not prove that the caller owns the current lock. A delayed or replayed call can clear control state acquired by a newer native sequence.
- Use it only at the matching native release boundary; a remote actor's phase change is not sufficient ownership evidence.
