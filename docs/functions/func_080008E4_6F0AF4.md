`func_080008E4_6F0AF4` · **Function**

Stores the displayed heart count in a minigame HUD task.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x080008E4` | `0x006F0AF4` | `.file_42` |

Native code size: **8 bytes**.

## Signature

```c
extern void func_080008E4_6F0AF4(void *hud, int displayed_hearts);
```

## How it works

Stores the signed 32-bit displayed-heart count at HUD task +0x88. The renderer draws one heart for each positive count.

In the sweets challenge, the controller supplies local player HP minus 17; this setter changes the HUD display and does not change player health.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `hud` | `void *` | Live native minigame HUD task. |
| `displayed_hearts` | `int` | Signed heart count written to HUD task +0x88. |

## Return value

No return value.

## Usage example

```c
#include "modding.h"
extern void func_080008E4_6F0AF4(void *hud, int displayed_hearts);

void set_minigame_display(void *hud, int hearts)
{
    if (hud) func_080008E4_6F0AF4(hud, hearts);
}
```

The example shows the verified native call shape. Use it only at a lifecycle point where the documented task and state are valid.

## Notes

- This setter only changes the display count. It is not a health adjustment or a separate health authority.
