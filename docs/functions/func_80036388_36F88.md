`func_80036388_36F88` · **Function**

Moves an existing cached model record to the front of its sibling chain.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80036388` | `0x00036F88` | `.main` |

Native code size: **108 bytes**.

## Signature

```c
extern int func_80036388_36F88(void *parent, void *record);
```

## How it works

Searches the existing chain rooted at parent +0x78, unlinks record from its old position, and places it at the front. Per-record next-sibling links use +0x74.

No allocation or initialization occurs. The caller must have already found the requested record in this exact chain.

## Return value

One on the successful native move, zero for explicitly rejected null inputs.

## Usage example

```c
extern int func_80036388_36F88(void *parent, void *record);

#include "modding.h"

RECOMP_HOOK("func_80036388_36F88")
void observe_cache_promotion(void *parent, void *record) {
    (void)parent; (void)record;
}
```

The example illustrates the native interface and its required state.

## Notes

- Passing an unrelated record is unsafe: native traversal assumes membership and can dereference a null link.
