`func_8021804C_5D351C` · **Function**

Creates and returns a visual child task through the native actor-effect manager.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8021804C` | `0x005D351C` | `.file_12` |

Native code size: **68 bytes**.

## Signature

```c
void *func_8021804C_5D351C(void *actor, int variant);
```

## How it works

Variant 0 allocates a category-8 child under the global actor-effect manager at D_8015CCBC; the child is not owned by the source actor or source coin task.

The helper returns the allocated child-task pointer from func_802171A8_5D2678, or null if the native category cannot allocate another child.

The returned task stores its model object at task +0x18. Its +0x0C callback advances from initialization (func_80211EF8_5CD3C8) to following (func_80211F70_5CD440) and then fading (func_80212020_5CD4F0).

The child already has native cleanup at task +0x10 through func_80218F30_5D4400; preserve this callback.

The fading callback rebuilds a 24-byte material display list at object +0x80, passed with the 0x60000000 segment tag.

If the child model record places object +0x80 outside original 8 MiB RDRAM, the renderer may be unable to read that display list. The risk depends on the actual address; a low-RDRAM mirror refreshed after native callbacks avoids replacing the existing callback chain.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `actor` | `void *` | Live native actor task with a valid object. |
| `variant` | `int` | Zero selects a category-8 child with model 0xB4; nonzero selects another child initializer/category 0xD. |

## Return value

The allocated child task, or null when allocation fails.

## Usage example

```c
#include <stdint.h>

extern void *func_8021804C_5D351C(void *actor, int variant);

/* The actor and its object must remain live; check allocation failure. */
void *spawn_pickup_visual(void *actor)
{
    if (!actor) return 0;
    return func_8021804C_5D351C(actor, 0);
}
```

The example illustrates the native interface and its required state.

## Notes

- This helper creates a visual child; it does not award ryo.
- The source actor and its object must remain live, and file_12 content must be loaded.
- The child has a native +0x10 cleanup callback. Do not replace it when installing observation or rendering work.
- The child appearance has not been verified in a live scene.
- The object +0x80 display list must resolve within original 8 MiB RDRAM for RSP access; confirm the actual address before assuming an extended model record is GPU-readable.
