`func_802171A8_5D2678` · **Function**

Allocates a child actor task and inherits its owner context and transform.

| Runtime address | ROM address | Section |

## Signature

```c
extern void *func_802171A8_5D2678(void *, void (*)(void *, void *), unsigned char);
```

## How it works

Selects an owner/list through func_80219CA0_5D5170, creates the task and copies actor context through FUN_80218C28. An owner object supplies initial position and rotation; an owner without an object supplies a zero transform.

The new task starts with resource ID 0xFFFE at +0x28 and pointer 0xFFFFFFFF at +0x2C. Install the resource fields expected by its initializer before the first scheduled update.

The initializer runs through the native scheduler. Null indicates owner selection or allocation failed.

The inherited rotation halfwords are forwarded unchanged, including special values such as 0x8000. Tsurami ring children illustrate this: their travelling-projectile owner supplies roll 0x8000, which their initializer retains.

| `task_kind` | `unsigned char` | Native scheduler/actor category used for owner selection and cap checks. |

## Return value

New child task pointer, or null if owner selection/allocation fails.

## Notes

- The owner pointer itself is dereferenced even when its object is absent.
- Do not manually run the initializer immediately after allocation: it may depend on current-task context and caller-installed resource fields.
