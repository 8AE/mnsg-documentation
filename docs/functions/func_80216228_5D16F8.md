`func_80216228_5D16F8` · **Function**

Projects the local player into the room minimap and updates its blinking directional marker.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80216228` | `0x005D16F8` | `.file_12` |

Native code size: **1036 bytes**.

## Signature

```c
extern void func_80216228_5D16F8(void *task, void *sprite);
```

## How it works

The scale is 128.0 divided by unsigned system word +0x3B008. World X/Z are read from the local player display record.

For system u16 orientation +0xCF88E equal to 0, 0x100 and 0x200, projected axes are (-X,-Z), (Z,-X) and (X,Z), respectively. The remaining branch uses (-Z,X). Multiply both axes by the scale.

Truncate each scaled offset toward zero, add the corresponding origin at system +0x3B000/+0x3B004 and add 13. Clamp X to 8..144. Clamp Y to 8..80 for task +0xE4 equal to zero, otherwise 8..144.

The function also changes task +0xD8 and sprite alpha for the local blink, and selects one of sixteen direction descriptors according to orientation and local heading. It is not a pure coordinate helper.

## Usage example

```c
/* Pure projection for the orientation-zero case, using already validated
 * room metadata and ordinary in-room coordinates. */
int project_minimap_x(float world_x, unsigned int extent, int origin_x)
{
    int pixel;
    if (!extent) return -1;
    pixel = (short)origin_x + (int)(-world_x * (128.0f / extent)) + 13;
    if (pixel < 8) return 8;
    if (pixel > 144) return 144;
    return pixel;
}
```

The example illustrates the native interface and its required state.

## Notes

- Only access this layout while its owning overlay and task are active. Task-pool addresses can be reused after destruction.
- Calling this routine for another player still reads the local player and mutates the local blink state. Use its verified projection formula for independent markers.
