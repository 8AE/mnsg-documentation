`func_80038BC8_397C8` · **Function**

Queues a 16-bit native audio command; the Goemon and Sasuke instruction scenarios use 0x0052 to enter gameplay music.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80038BC8` | `0x000397C8` | `.main` |

Native code size: **48 bytes**.

## Signature

```c
void func_80038BC8_397C8(unsigned short cue);
```

## How it works

Masks the command to 16 bits and forwards it to the native audio queue with both additional parameters set to zero.

The queue holds at most eight pending commands and suppresses duplicates only while they remain pending. A later call can enqueue the same command again.

Scenario 0x0179 supplies command 0x0292 before its final instruction text and wait. After setting instruction flag 0x21, it supplies gameplay music command 0x0052 and ends.

Goemon's scenario 0x0173 also supplies command 0x0292 before its final instruction wait and text, then sets instruction flag 0x1B, supplies gameplay music command 0x0052 and ends. Its controller's later VM-idle/HUD/target transition contains no audio call.

The scenario helper reads the unsigned low halfword of its command word and invokes this wrapper. The separate func_80038B98_39798 wrapper has equivalent queue defaults, but this wrapper is used by both scenarios 0x0173 and 0x0179.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `cue` | `unsigned short` | Native 16-bit audio command. Scenarios 0x0173 and 0x0179 use 0x0292 during instructions and 0x0052 at their completion. |

## Return value

No return value. The wrapper does not report whether the queue accepted the command.

## Usage example

```c
extern void func_80038BC8_397C8(unsigned short cue);

/* Call once when the native instruction sequence reaches active play. */
void queue_challenge_gameplay_music(void)
{
    func_80038BC8_397C8(0x0052);
}
```

Queues the verified gameplay command once. The caller owns the transition lifetime; the wrapper supplies its native queue defaults.

## Notes

- Invoke once at the intended transition. Skipping the scenario skips its audio commands, and the later controller HUD transition does not queue the gameplay command.
- The wrapper supplies no player, fade or volume arguments, and no acceptance acknowledgment. Preserve the native audio scheduler and queue lifetime.
