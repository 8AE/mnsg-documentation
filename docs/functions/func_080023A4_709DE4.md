`func_080023A4_709DE4` · **Function**

Allocates the controller work area and installs its native update callback.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x080023A4` | `0x00709DE4` | `.file_48` |

Native code size: **120 bytes**.

## Signature

```c
void func_080023A4_709DE4(void *task, void *object);
```

## How it works

Allocates a zeroed 60-byte work area and stores its pointer in task word +0xD0.

Installs func_080018E8_709328 as the task update callback. The object argument is preserved by the calling convention but unused by this initializer.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | The matching live native task. |
| `object` | `void *` | Object supplied by the native scheduler for this task callback. |

## Return value

No return value.

## Usage example

```c
extern void func_080023A4_709DE4(void *task, void *object);

typedef void (*NativeTaskCallback)(void *, void *);

/* Observe identity without replaying the native lifecycle. */
NativeTaskCallback documented_callback(void)
{
    return func_080023A4_709DE4;
}
```

The native scheduler owns callback execution. This example returns the function address and does not allocate work, advance challenge state or replay a contact pass.

## Notes

- Task +0xD0 is a work pointer for this controller. The target callback in the same challenge uses inline data beginning at +0xD0.
- Use the native constructor and scheduler lifecycle; rerunning this initializer is not established as a reset operation.
