## How it works

Benkei combat uses room 0x171 and entity 0x1C0. Relevant fields include a state byte at task +0xD0, signed lives byte at +0xD3 and native fight-active flag 0x07A.

The individual controller branches have not been fully reconstructed. Identify this task separately from Benkei noncombat NPC tasks.

Benkei uses signed lives byte +0xD3, AI state +0xD0 and command byte +0xD2. Combat states 2,5,6 consume status hit bit 0x80. This differs from common actor health at +0x8D.

State zero performs initialization. Entity 0x1C0 also exists as an idle NPC, so a live fight requires encounter-state validation, including active fight flag 0x07A. Lives zero begins the subsequent native fall/reward flow.
