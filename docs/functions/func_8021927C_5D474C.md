`func_8021927C_5D474C` · **Function**

Refreshes a task’s target-object pointer from the current-player global.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8021927C` | `0x005D474C` | `.file_12` |

## Signature

```c
extern void func_8021927C_5D474C(void *task);
```

## How it works

Copies the pointer stored in D_8015CD60 to task +0x84.

The helper does not select a target or compute a position. Native robot logic can call it again during later phases, replacing a target pointer set between those refreshes.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Live native task with the expected initialized fields. |

## Return value

No return value.

## Usage example

```c
#include "modding.h"
extern void func_8021927C_5D474C(void *task);

void refresh_native_target(void *task)
{
    if (task) func_8021927C_5D474C(task);
}
```

The example shows the verified native call shape. Use it only at a lifecycle point where the documented task and state are valid.

## Notes

- Use only with a live task and a valid current-player object. The copied pointer is runtime state and must not be retained after its native owner or target is gone.
