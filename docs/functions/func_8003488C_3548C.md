`func_8003488C_3548C` · **Function**

Initializes the root task and the stock task free list.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8003488C` | `0x0003548C` | `.main` |

Native code size: **388 bytes**.

## Signature

```c
typedef void (*NativeRootTaskUpdate)(void *task, void *object);
extern void func_8003488C_3548C(NativeRootTaskUpdate root_update);
```

## How it works

Initializes the native root task and 79 free task records with a 0xF0-byte stride. Each record is cleared through func_80034A10.

Resets task-list bookkeeping, active task telemetry, the optional display overflow owner, and per-frame display allocation telemetry. Installs root_update as the root task callback.

The free-list head is the pointer at byte +0x08 of D_8006D328. Separately provisioned free records are not included by this initializer.

## Usage example

```c
typedef void (*NativeRootTaskUpdate)(void *task, void *object);
extern void func_8003488C_3548C(NativeRootTaskUpdate root_update);

#include "modding.h"

RECOMP_HOOK_RETURN("func_8003488C_3548C")
void after_task_lists_initialized(void) {
    /* Prior native task ownership has been invalidated. */
}
```

The example illustrates the native interface and its required state.

## Notes

- Use as an initialization boundary. Calling it on live tasks loses their list and resource ownership.
- Task storage uses a 16-byte-aligned 0xF0 stride. The native active task count is unsigned 16-bit.
