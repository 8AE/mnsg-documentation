`func_80013B14_14714` · **Function**

Loads a file into the scene resource registry and advances its aligned allocation boundary.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80013B14` | `0x00014714` | `.main` |

Native code size: **248 bytes**.

## Signature

```c
extern void *func_80013B14_14714(unsigned int file_id);
```

## How it works

Scans 48 accepted file-ID records for an existing ID or the first zero-file sentinel. A full ID scan returns zero without loading. An existing ID returns the following record data value, not the loaded file base.

For a new ID, reads the sentinel destination and queries func_80001DF4_29F4. A nonzero result requires 0x1000 alignment and a native 0x40000000 resource tag. Loads through func_80001C00_2800, registers through func_800142BC_14EBC and writes a following zero-ID sentinel with the next 0x40-aligned cursor.

The load allocation extent comes from the native start/end table, not the raw ROM file length. func_80001C00_2800 copies or decompresses the file, zero-fills its allocation tail and writes back the cache. Raw copy length rounds up to an even byte count. PIC-part registration can add writes at native part destinations; validate those decoded spans and their terminator as well as the allocation extent.

This routine has no heap-capacity check and does not evict cached entries. Check the live retained prefix, the union of resource IDs, allocation extents and required alignment before appending.

Ordinary File11 world setup preserves 0x80304000..0x803214FF and begins appends at 0x80321500. The boot File10 bank ends at 0x80594000; using that exclusive end for a bounded extension is an explicit policy, not a bound enforced here.

## Return value

Aligned next allocation boundary, or null if the registry scan cannot allocate an entry. It is not the resource base.

## Notes

- Only call during a valid native loading phase after independent ID-slot and memory-capacity preflight. A nonzero returned cursor alone does not prove a safe load.
- The return is an aligned next cursor or following-entry data value. Use func_800141C4_14DC4 to retrieve the registered resource, preserving its native tags.
- Allocation extent, raw even-copy extent and decoded PIC-part destinations all require bounds checks. Do not substitute raw file length for native allocation size.
- Scene-resident pointers must be reacquired after a stage change. Arbitrary replacement resources or relocated backing banks fall outside the fixed canonical allocation contract.
