`func_80010374_10F74` · **Function**

Releases the backing buffer owned by a native sprite queue.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80010374` | `0x00010F74` | `.main` |

Native code size: **104 bytes**.

## Signature

```c
extern void func_80010374_10F74(int queue);
```

## How it works

Loads the queue's backing-buffer pointer and passes that exact allocation to the native scene-pool free routine.

This releases queue storage. It is separate from resetting pending records or finalizing a draw list.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `queue` | `int` | Queue index returned by native sprite-queue creation. |

## Return value

No return value is used by the inspected native caller; whether the routine returns an ignored value is unconfirmed.

## Usage example

```c
extern void func_80010374_10F74(int queue);

void destroy_sprite_queue(int queue)
{
    func_80010374_10F74(queue);
}
```

Call when the queue's owning scene or display lifetime ends.

## Notes

- Do not append or finalize through a queue after its backing buffer has been released.
