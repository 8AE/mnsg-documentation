## How it works

Installed only on the health-bearing root at task +0x10. Its body is skipped when D_8015C5E4 is zero.

The private post includes the common actor pipeline plus boss-specific collision/damage and phase/defeat work. It is separate from the current AI callback at task +0x0C.

This root owns health at +0x8D but does not initialize the usual entity field at +0x5E. Establish identity from its initializer/callback path rather than assigning visual child ID 0xCB to it.

Tsurami reaches its lethal custom callback at one remaining HP. A generic HP-zero path bypasses that custom transition and is not equivalent to native victory.
