## How it works

Installed only on the health-bearing root at task +0x10. Its body is skipped when D_8015C5E4 is zero.

The private post includes the common actor pipeline plus boss-specific collision/damage and phase/defeat work. It is separate from the current AI callback at task +0x0C.

The nonlethal damage state func_08002E34_6B60D4 creates a screen overlay with RGB (128,128,255) and alpha 0 through func_8022026C_5DB73C. Its next AI func_08002EC8_6B6168 increases alpha by 80 per invocation through func_80220210_5DB6E0, clamping at 255 before scheduling func_08002F0C_6B61AC.

The fade-out AI subtracts 80 through func_80220168_5DB638. At zero it releases the root-owned display record and advances to func_08002F50_6B61F0. After the animation condition, func_08002FA4_6B6244 clears task-status bit 0 and schedules neutral state func_08001D54_6B4FF4. The native one-HP lethal branch instead selects func_08002FFC_6B629C before creating the flash.

This root owns health at +0x8D but does not initialize the usual entity field at +0x5E. Establish identity from its initializer/callback path rather than assigning visual child ID 0xCB to it.

Tsurami reaches its lethal custom callback at one remaining HP. A generic HP-zero path bypasses that custom transition and is not equivalent to native victory.
