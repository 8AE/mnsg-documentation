`func_08003F84_6CC194` · **Function**

Processes Dharumanyo damage carrier and its orbit position.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x08003F84` | `0x006CC194` | `.file_31` |

Native code size: **936 bytes**.

## Interface

A complete callable prototype has not been established. Use the observation or callback-identity pattern in the example rather than guessing the native arguments.

## How it works

Owns collision, damage, lives and death transitions on the linked carrier. Its yaw is a 16-bit value at task +0xD8 and wraps to 10 bits.

Phase flags at 0x8015CDB4 select an orbit step of 0x20 normally, 0x30 in phase 2, 0x40 in phase 3 and 0x50 in phase 4. Native processing advances the angle and computes the resulting carrier position.

The controller resets generic actor health +0x8D to ten during normal updates. Real remaining lives occupy byte +0xD1.

It calls inner damage routine func_80218350 directly. Generic health carries hit processing; the later boss-specific callback consumes a real life.
