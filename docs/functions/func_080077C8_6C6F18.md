`func_080077C8_6C6F18` · **Function**

Rotates the Bazooka equipment pickup and starts its native acquisition scenario when local player contact is reported.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x080077C8` | `0x006C6F18` | `.file_30` |

Native code size: **216 bytes**.

## Signature

```c
extern void func_080077C8_6C6F18(void *task, void *object);
```

## How it works

Each normal update adds 4 to object yaw halfword +0x16, masked to 0x3FF.

Task status word +0x68 bit 0x200 admits the local acquisition branch. It acquires local player control, starts scenario 0x85, and sets collection flag 0x1A5. The idle callback does not reread that flag.

The acquisition branch disables the attack shape, hides the root, creates its native local poof and sets byte +0xD0 of the shine child linked at root +0xE4.

The task then installs func_080078A0_6C6FF0. That continuation waits for the scenario to finish before releasing local control. It must remain scheduled for a pickup that has already begun.

The constructor tests collection flag 0x1A5 before creating the equipment and its shine. The flag controls whether a new root should appear; it is separate from the scenario continuation.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Initialized File30 entity 0x3D5 task in room 0x81. |
| `object` | `void *` | The native object stored at task +0x18. |

## Return value

No return value.

## Usage example

```c
#include "modding.h"

static volatile unsigned short observed_value;

RECOMP_HOOK("func_080077C8_6C6F18")
void observe_native_state(void *task, void *object)
{
    if (!object) return;
    observed_value = *(volatile unsigned short *)((char *)object + 0x16);
}
```

The entry hook observes yaw without running the native acquisition branch a second time.

## Notes

- Do not replay this callback for visual catch-up: its contact branch changes progression, allocates effects and acquires player control.
- Keep task pointers, shine pointers and scenario/control ownership local. An already-collected flag alone does not prove the active local scenario has finished.
- Fire Ryo is the equipment upgrade; this collection flag does not encode the current ryo balance.
