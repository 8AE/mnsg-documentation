`func_8001DB04_1E704` · **Function**

Updates three packed native angle halfwords using a direction vector and orientation offsets.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8001DB04` | `0x0001E704` | `.main` |

Native code size: **880 bytes**.

## Signature

```c
extern void func_8001DB04_1E704(unsigned short angles[3], const float direction[3], unsigned short rx, unsigned short ry, unsigned short rz);
```

## How it works

Reads three existing unsigned 16-bit angles at output offsets +0/+2/+4, computes a direction-based orientation with three native angle offsets, then writes the resulting halfwords. A kind-2 object uses this layout at +0x14/+0x16/+0x18.

The previous angle values are inputs to the final native angle adjustment; initialize the output rather than passing uninitialized storage. The supplied vector is read as three floats at offsets +0/+4/+8.

The angle arguments use their low 16 bits. Native projectile code calls this helper for moving model orientation and for the reversed direction of an impact. It does not allocate a task or register an attack.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `angles` | `unsigned short[3]` | Initialized packed input/output native angles. |
| `direction` | `const float[3]` | Finite, nonzero direction vector in native coordinate order. |
| `rx, ry, rz` | `unsigned short` | Native orientation offsets, each read at unsigned 16-bit width. |

## Return value

No return value.

## Usage example

```c
extern void func_8001DB04_1E704(unsigned short angles[3], const float direction[3], unsigned short rx, unsigned short ry, unsigned short rz);

void orient_display_object(void *object, const float direction[3])
{
    if (!object || !direction) return;
    /* Caller supplies a live object, initialized rotations and valid vector. */
    unsigned short *angles = (unsigned short *)((unsigned char *)object + 0x14);
    func_8001DB04_1E704(angles, direction, 0, 0, 0);
}
```

Uses the native packed object rotation fields and leaves task ownership, motion and combat state unchanged.

## Notes

- This is an input/output rotation helper, not a function returning an angle or a three-float output vector.
- Preserve signed display sentinels as their 16-bit bit patterns; do not widen the packed native fields to three integers.
- The numerical behavior for invalid vectors or uninitialized output angles is not established by the inspected call sites.
