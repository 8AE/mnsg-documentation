`func_8021DDE8_5D92B8` · **Function**

## How it works

Rotates the supplied local xyz offset using owner pitch/yaw, adds owner position and allocates a child through func_802171A8_5D2678.

Writes the resulting position to the child object and stores the low 16 bits of angle at task +0x88. Congo uses this path for kind-10 flame children.

## Parameters

| --- | --- | --- |
| `owner` | `void *` | Valid owner with a valid native object. |
| `initializer` | `void (*)(void *, void *)` | Scheduled child initializer. |
| `task_kind` | `unsigned char` | Native child task category; Congo flames use 10. |
| `x, y, z` | `float` | Local offset relative to owner orientation, not world position. |
| `angle` | `int` | Low 16 bits stored at child task +0x88. |

## Return value

New child task or null on allocation failure.
