`func_801DCD48_598C58` · **Function**

Applies a signed player-health adjustment, with negative byte deltas representing damage.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x801DCD48` | `0x00598C58` | `.file_11` |

Native code size: **200 bytes**.

## Signature

```c
extern int func_801DCD48_598C58(signed char delta);
```

## How it works

Sign-extends the argument as a signed byte. Negative values apply health loss; positive values heal. The routine updates the complete current-health word at 0x8015C5E4.

Negative adjustments clamp below zero. Positive adjustments clamp to the maximum health at 0x8015C5E0 and play the normal healing sound when health was below its maximum.

Health adjustment alone does not perform the complete hurt or death lifecycle. Those reactions belong to native player intake and subsequent player updates.

An entry hook sees health before the original adjustment, while a return hook observes the updated value.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `delta` | `signed char` | Signed health-unit delta; negative for damage and positive for healing. |

## Return value

Returns 1 when the adjustment clamps, or healing is requested while already at maximum health; otherwise returns 0. This is not the amount of health changed.

## Usage example

```c
#include "modding.h"
extern unsigned char D_8015C608_15D208[];
extern int func_801DCCF0_598C00(short delta);

RECOMP_HOOK("func_801DCD48_598C58")
void charge_for_damage(signed char delta)
{
    char *save = (char *)D_8015C608_15D208;
    if (delta >= 0 || *(volatile int *)(save - 0x28) <= 0 ||
        *(volatile unsigned char *)(save - 0x21) == 0) return;
    (void)func_801DCCF0_598C00(-50);
}
```

Example of a separate currency side effect on negative HP adjustments. The original routine still applies health changes; adding a Ryo penalty is optional calling code, not the native health routine behavior.

## Notes

- A hook that reacts to negative deltas should distinguish an already-dead player and unloaded save state.
