## How it works

Applied damage paths use a negative signed byte; positive changes represent healing. An entry hook sees the health value before the original adjustment.

The complete native clamp, death and downstream reaction behavior is not reconstructed here. Use the native routine instead of replacing it with an assumed direct HP write.
