`func_80036058_36C58` · **Function**

Removes and releases records from a native owner list.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80036058` | `0x00036C58` | `.main` |

Native code size: **256 bytes**.

## Signature

```c
extern int func_80036058_36C58(void *list, int count);
```

## How it works

Uses owner+0x18 as the record head, advances the chain, clears owner+0x1C when empty and releases the removed record. The count argument is narrowed to a byte.

The single kind-2 allocator uses this to recycle one record from its optional owner before reusing the native free list.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `list` | `void *` | Native owner/list object whose records can be recycled. |
| `count` | `int` | Number of records to release; low eight bits used by native routine. |

## Return value

Native integer/address result; zero is used for empty/short-list paths. Do not dereference a released record.

## Notes

- This removes existing engine-owned records; do not call it on an unrelated task or arbitrary memory.
- The integer result can contain a removed record address and is not documented as a simple boolean; the current allocator ignores it.
