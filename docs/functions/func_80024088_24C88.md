`func_80024088_24C88` · **Function**

Clears one bit in the packed game-flag bank, preserving other flags. Use it when a documented game-state transition requires a flag to become clear.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80024088` | `0x00024C88` | `.main` |

Native code size: **84 bytes**.

## Signature

```c
extern void func_80024088_24C88(int flag_id);
```

## How it works

For a valid nonnegative ID, reads byte (flag_id >> 3) & 0xFF and ANDs it with the inverse of 1 << (flag_id & 7). Clearing a clear flag has no additional effect.

Clearing a completion bit alone does not restore an actor or reconstruct an encounter. Actor state, room state, and event state have separate lifecycles.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `flag_id` | `int` | Known flag bit index, 0x000–0x7FF. |

## Return value

No return value.

## Usage example

```c
extern void func_80024088_24C88(int flag_id);

static void clear_known_game_flag(unsigned int flag_id)
{
    if (flag_id < 0x800u) {
        func_80024088_24C88((int)flag_id);
    }
}
```

Use with a documented transient flag in a game-state transition you control. The range check does not establish that clearing a particular flag is appropriate.

## Notes

- IDs are not bounds-checked by the native routine.
- Do not treat this as a generic boss reset: actor state, room state, and other progression bits can remain changed.
