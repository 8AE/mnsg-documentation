## How it works

Installed after the pre-fight proximity waiter func_08002EB4_703FB4 completes.

The battle child uses a spin-up callback (func_08002F8C_70408C), timed hold (func_08003054_704154), spin-down (func_080030B0_7041B0), and hit-accepting wait (func_0800316C_70426C). The loop uses task +0x8A as a 16-bit timer, +0xDA as signed angular speed, +0xDC as signed spin increment, and +0xDE as signed colour/alpha ramp. The spin-up seeds +0x8A=0x80; spin-down seeds +0x8A=0x50.

Scheduler callbacks consume a0=task and a1=object. The damage helper func_08002540_703640 is called from func_0800316C_70426C with task in a0 and obtains the local object through task +0x18.

The live child fields include +0x0C callback pointer; +0x18 local object pointer; +0x68 u32 status (bit 0 pending hit, bit 1 remove-pending); +0x8A 16-bit timer; +0x8D u8 HP; +0xD0 root pointer; +0xD4 u16 hit-flash countdown; +0xD8 s16 oscillation phase; +0xDA s16 angular speed; +0xDC s16 spin increment/direction; +0xDE s16 colour/alpha ramp; and +0xE0 s16 yaw cache. The object stores XYZ as f32 at +0x08/+0x0C/+0x10, rotations as s16 at +0x14/+0x16/+0x18, and scales as f32 at +0x1C/+0x20/+0x24.

Each combat phase runs pose/attack producer func_080029CC_703ACC. It updates orbit and root-relative position from signed speed and local root pose, then may create at most one shot when the unsigned object yaw is strictly between 0x140 and 0x2C0, absolute speed is at least 0x40, and local u16 world counter D_8015CC30 is divisible by 3. The pose producer has no RNG; its shot cadence depends on this local frame counter, so phase state alone does not determine identical shot timing.

The damage helper clears task +0x68 bit 0. When angular speed is nonzero it does not reduce HP. At zero speed it decrements the u8 HP, then branches on the old value: old HP nonzero writes status 1 to D_8015CDB6 and mirrors remaining HP to D_8015CDBC; old HP zero writes status 2, seeds timer +0x8A=0x80 and schedules death callback func_080031D8_7042D8. Starting at HP 5, the fifth accepted hit leaves the child alive at HP 0; the next accepted hit wraps HP to 0xFF while beginning death. HP 0 alone does not mean the child is dead.

A Control Machine encounter can validly begin with D_8015CDB6 equal to 0; status 10 is not a required initial value for this battle child. The hit/death path writes status 1 for nonterminal hit, 2 for terminal hit, 3 at the death transition, and 4 at root departure. The native death animation advances through func_080031D8_7042D8, func_08003634_704734, func_08003678_704778 and func_080036CC_7047CC before deleting the child.

The separate local File_58 controller func_080004F8_71AA08 consumes local arrival flag 0x19F in phase 8. At phase 7/timer 1 it locks input and opens intro scenario 0x217, then waits until func_8003F1D8_3FDD8 reports the scenario pointer D_80077858 is null. It then clears the local transition state and enters phase 6; phase 6 waits for immediate event 0, written by the terminal-hit path and read through func_80023E94_24A94.

The statically identified pre-open skip boundary is before the phase-7/timer-1 callback dispatch, after local arrival has completed and only when the scenario-active predicate reports no scenario. This ordering is a static finding and has not been verified in a running game.
