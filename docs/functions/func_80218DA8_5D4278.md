`func_80218DA8_5D4278` · **Function**

Stores a cylinder-style attack shape using a signed radius input scaled by ten, a height and a vertical offset.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80218DA8` | `0x005D4278` | `.file_12` |

Native code size: **36 bytes**.

## Signature

```c
extern void func_80218DA8_5D4278(void *task, int radius_times_ten, unsigned short height, short offset);
```

## How it works

Writes 0xFFFFFFFF to task word +0x48 to select this shape representation.

Stores the low halfword of signed radius_times_ten / 10 at +0x4E, height at +0x50 and offset at +0x52. It makes no calls.

Equipment constructors pass (500,25,0), producing radius50. Their acquisition branches pass (0,0,0) to disable the shape.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Initialized native actor task. |
| `radius_times_ten` | `int` | Signed radius numerator; native signed division by 10 precedes the halfword store. |
| `height` | `unsigned short` | Raw height halfword. |
| `offset` | `short` | Signed vertical-offset halfword. |

## Return value

No return value.

## Usage example

```c
#include "modding.h"

extern void func_80218DA8_5D4278(void *, int, unsigned short, short);

void disable_actor_attack_shape(void *task)
{
    if (task) func_80218DA8_5D4278(task, 0, 0, 0);
}
```

Use on an initialized actor when its own lifecycle has ended attack admission. Previously latched contact remains a separate concern.

## Notes

- The radius argument is a signed 32-bit integer, not a pre-scaled halfword.
- This setter changes shape data; it does not perform a contact or damage pass and does not clear previously latched task contact status.
