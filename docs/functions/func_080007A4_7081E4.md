`func_080007A4_7081E4` · **Function**

Returns the timer task's signed raw frame counter divided by thirty.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x080007A4` | `0x007081E4` | `.file_48` |

Native code size: **32 bytes**.

## Signature

```c
int func_080007A4_7081E4(void *timer_task);
```

## How it works

Reads signed task word +0x84 and divides it by 30 to obtain the displayed seconds value.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `timer_task` | `void *` | Live native timer task containing the signed counter at +0x84. |

## Return value

Signed timer counter divided by 30.

## Usage example

```c
extern int func_080007A4_7081E4(void *timer_task);

int challenge_seconds_remaining(void *timer_task)
{
    if (!timer_task) return 0;
    return func_080007A4_7081E4(timer_task);
}
```

Reads the documented timer task rather than interpreting a controller work pointer as a timer.

## Notes

- This read does not advance the counter.
- The timer task must remain valid; a saved task pointer is not valid after native cleanup.
