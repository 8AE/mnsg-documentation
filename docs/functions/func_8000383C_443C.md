`func_8000383C_443C` · **Function**

Resets render/texture state for the next scene.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8000383C` | `0x0000443C` | `.main` |

Native code size: **68 bytes**.

## Signature

```c
extern void func_8000383C_443C(void);
```

## How it works

Runs the broader render initialization path and clears graphics/texture buffers used by the following scene.

This belongs in scene transition setup before gameplay control/UI initialization. Invoking it from ordinary object rendering would reset shared scene graphics state.

## Return value

No return value in the established declaration.
