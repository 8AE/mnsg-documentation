`func_080001A4_6AC6F4` · **Function**

Emits moving wiper children from a Dango-machine controller.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x080001A4` | `0x006AC6F4` | `.file_24` |

Native code size: **128 bytes**.

## Interface

A complete callable prototype has not been established. Use the observation or callback-identity pattern in the example rather than guessing the native arguments.

## How it works

The native cadence uses the shared frame counter at 0x8015CC30 and mask 0x3F, producing one child every 64 frames.

Allocates a kind-6 child with initializer func_08000224_6AC774, binds resource file 0x18 at task +0x28/+0x2C and increments the active-child count at 0x8015CDB4.
