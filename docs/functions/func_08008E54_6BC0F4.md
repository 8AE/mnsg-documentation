`func_08008E54_6BC0F4` · **Function**

Applies Congo camera shake while immediate event 0x0B remains set.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x08008E54` | `0x006BC0F4` | `.file_29` |

Native code size: **816 bytes**.

## Signature

```c
extern void func_08008E54_6BC0F4(void *camera_task, void *object);
```

## How it works

The ordinary Congo camera selects this callback when immediate event 0x0B is set. It returns to the ordinary camera callback when the event is clear.

Compares squared distance between the local player and task camera-position fields +0x80, +0x84 and +0x88 with threshold 10000.

Uses the unsigned-halfword world frame at full system +0x3ADCE modulo four. Far target-Y offsets follow 30, 33, 30, 27; near offsets follow 10, 13, 10, 7.

Updates the native camera target and matrix, then clears byte task +0xDC. The shake phase follows the native world frame; it is not a once-only effect triggered by a health value.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `camera_task` | `void *` | Initialized Congo camera task with its live native camera handle at +0xD0. |
| `object` | `void *` | Second scheduler callback argument. This routine saves it but does not otherwise consume it. |

## Return value

No return value is used by the native callback convention.

## Usage example

```c
typedef void (*CameraCallback)(void *task, void *object);
extern void func_08008E54_6BC0F4(void *camera_task, void *object);

int congo_camera_is_shaking(void *camera_task)
{
    if (!camera_task) return 0;
    CameraCallback current = *(CameraCallback *)((char *)camera_task + 0x0C);
    return current == func_08008E54_6BC0F4;
}
```

Identify the installed native camera state without replaying its update or changing the event bank.

## Notes

- Run in the initialized Congo camera context with the file_29 code and camera resources resident. This is not a generic camera effect helper.
- The camera follows the local player and the current immediate event bank. Preserve its own task and handle rather than substituting a root actor or saved progress flags.
