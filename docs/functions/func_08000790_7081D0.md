`func_08000790_7081D0` · **Function**

Stores a signed seconds value multiplied by thirty in the timer task.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x08000790` | `0x007081D0` | `.file_48` |

Native code size: **20 bytes**.

## Signature

```c
void func_08000790_7081D0(void *timer_task, int seconds);
```

## How it works

Writes signed task word +0x84 as seconds multiplied by 30. The observed value 100 produces 3000 native frames.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `timer_task` | `void *` | Initialized native challenge timer task. |
| `seconds` | `int` | Signed duration; the challenge controller supplies 100. |

## Return value

No return value.

## Usage example

```c
extern void func_08000790_7081D0(void *timer_task, int seconds);

void initialize_challenge_timer(void *timer_task)
{
    if (timer_task) func_08000790_7081D0(timer_task, 100);
}
```

Uses the native controller's observed 100-second duration on an already initialized timer task.

## Notes

- This writes timer data only. It does not allocate the HUD or run its draw callback.
- Negative or overflowing durations have no established supported contract.
