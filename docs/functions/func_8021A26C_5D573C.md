## Interface

A complete callable prototype has not been established. Use the observation or callback-identity pattern in the example rather than guessing the native arguments.

## How it works

Writes a 24-byte display list at the child object +0x80 address and uses the 0x60000000 segment tag when binding the material.

The fading pickup callback rebuilds this list as the child updates.

The destination must be GPU-readable in original 8 MiB RDRAM; a model record valid to the CPU can still place its material list beyond the renderer-visible region.
