`func_801FBD50_5B7C60` · **Function**

Builds the stock player-heart display from current and maximum health measured in half-heart units.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x801FBD50` | `0x005B7C60` | `.file_0C` |

Native code size: **2088 bytes**.

## Interface

A complete callable prototype has not been established. Use the observation or callback-identity pattern in the example rather than guessing the native arguments.

## How it works

Reads the native current-health and maximum-health halfword values in half-heart units and clamps the displayed range to 0x28 units (20 hearts).

Selects heart imagery from the native descriptor arrays: current/full heart at atlas coordinate (0, 24), maximum/empty heart at (8, 24), base image at (16, 24), and half-heart image using the same red cell at (0, 24).

The half-heart is rendered as a 4 by 4 red heart at offset (+2,+2) over the 8 by 8 dark-heart base. It does not use a separate semi-transparent texture or alpha treatment; the native scale-enable bit and 0.5 object scales produce the smaller image.

The descriptor bank uses native image resource 0x8004, a 64 by 32 RGBA5551 sheet. Each full heart represents two native health units; the half-heart descriptor represents one unit.

## Notes

- This mapping describes the native player HUD. Congo's separate health counter is a byte at boss task +0x8D with a native range of 0 through 30; mapping two Congo units to one displayed heart is a separate presentation choice, not a native player-health equivalence.
- The atlas coordinates describe source image locations, not screen positions.
