`func_80003478_4078` · **Function**

Advances and resets gameplay control/UI substate.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80003478` | `0x00004078` | `.main` |

Native code size: **88 bytes**.

## Signature

```c
extern void func_80003478_4078(void);
```

## How it works

Increments the byte at g_system+0x3ADDE, clears +0x3ADDF, then calls the substate reset helper with zero.

It is one component of the native gameplay transition setup. Scene destination, save activation and render-buffer preparation are separate responsibilities.
