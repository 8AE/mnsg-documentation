`func_8021BB04_5D6FD4` · **Function**

Sets planar velocity toward a waypoint and snaps the object to the target when the next step would pass it.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8021BB04` | `0x005D6FD4` | `.file_12` |

## Signature

```c
extern int func_8021BB04_5D6FD4(void *task, float target_x, float target_z, float speed);
```

## How it works

Reads the task object at +0x18 and compares its X/Z with the requested waypoint. For a nonzero distance, sets task velocity +0x78/+0x80 using the normalized direction and speed.

If the helper detects that the next velocity increment crosses the waypoint, it snaps object X/Z to the waypoint and clears both planar velocities. Returns 1 while movement remains and 0 when already at or snapped to the waypoint.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Task whose native object pointer is at +0x18. |
| `target_x` | `float` | Target world X coordinate. |
| `target_z` | `float` | Target world Z coordinate. |
| `speed` | `float` | Magnitude used to set planar velocity. |

## Return value

Returns 1 while moving toward the waypoint, or 0 when at the waypoint or snapped to it.

## Usage example

```c
#include "modding.h"
extern int func_8021BB04_5D6FD4(void *task, float target_x, float target_z, float speed);

int approach_waypoint(void *task, float x, float z)
{
    if (!task) return 0;
    return func_8021BB04_5D6FD4(task, x, z, 2.0f);
}
```

The example shows the verified native call shape. Use it only at a lifecycle point where the documented task and state are valid.

## Notes

- The common actor integration applies twice the stored planar velocity. Speed is not the final per-tick displacement. This helper does not run collision, damage or task retirement.
