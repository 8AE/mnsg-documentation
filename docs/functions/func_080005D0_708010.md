`func_080005D0_708010` · **Function**

Draws a thirty-tick-per-second timer HUD before decrementing its frame counter; a 100-second start passes numeric value 99 on the next draw.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x080005D0` | `0x00708010` | `.file_48` |

Native code size: **328 bytes**.

## Signature

```c
void func_080005D0_708010(void *task, void *object);
```

## How it works

Reads the signed frame counter at task +0x84 and divides it by 30 for the local HUD draw before decrementing that counter. The draw uses the native two-digit number format.

Decrements signed task word +0x84 once per native frame and clamps a negative result to zero. The counter uses thirty ticks per second; the controller initializes 3000 for 100 seconds.

At the native 100-second start, the first draw passes numeric value 100 to the two-digit formatter from 3000 frames. That callback leaves 2999 frames after its decrement; the next draw passes 99 through integer division by 30. The displayed glyphs do not determine the timer duration.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Live native timer task with a signed frame counter at +0x84. |
| `object` | `void *` | Native HUD object supplied by the task scheduler. |

## Return value

No return value.

## Usage example

```c
extern void func_080005D0_708010(void *task, void *object);

typedef void (*NativeTaskCallback)(void *, void *);

NativeTaskCallback documented_timer_callback(void)
{
    return func_080005D0_708010;
}
```

Returns callback identity without drawing or decrementing the timer. The native scheduler runs the callback with valid local resources.

## Notes

- The native timer rate does not define a network update cadence.
- HUD resources and task pointers must remain in the matching local lifecycle.
