## How it works

The native callback saves two scheduler arguments. Its inspected body obtains the task-group pointers from scene globals instead of using those arguments for contact selection.

After scene preparation, invokes func_80033024_33C24 for selected attacker/victim groups. While the player-manager pointer is live, four calls use D_801FC600_5B8510 as the outgoing attacker subtree.

Other pairs test actor and projectile groups against the playable-player group. The callback subsequently processes height, scene-exit and related state; it has effects beyond hit detection.

A nonzero native transition marker redirects the callback into a room-transition lifecycle that tears down the current world tasks and selectively reloads native resource banks.

That selective route invokes the destination room initializer only when the native force-initialization byte is nonzero or the pending room selects a different initializer callback. A request marker alone does not guarantee that destination initialization runs.

The ordinary hot transition passes through func_801F7C14_5B3B24, which removes room-owned task hierarchies and resets the room arena at 0x802F7000 with size 0xA000. It retains the live player task rather than reallocating it. The reload path truncates the dynamic registry to its retained entry prefix before invoking room-resource callbacks.

## Notes

- Observe the normal scheduler invocation. Calling the callback again repeats stateful scene work.
- The callback belongs to its native gameplay overlay and requires initialized scene managers. A hook that ignores the scheduler arguments may declare no parameters.
- The selective scene reload and main system step 12 are different lifecycles. The latter tears down and fully rebuilds the world; do not assume the selective route recreates every destination task or resource.
- Parent custom room tasks beneath the room-owned hierarchy and preserve their storage until native cleanup has finished. Teardown and cache truncation make retained scene pointers invalid.
