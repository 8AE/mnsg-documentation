`func_80003728_4328` · **Function**

Switches the native system execution step and resets transition substate.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80003728` | `0x00004328` | `.main` |

Native code size: **100 bytes**.

## Signature

```c
extern void func_80003728_4328(unsigned char step);
```

## How it works

Writes the main system step, clears its completion byte, marks the transition and resets its substate.

The numeric step selects a state-machine branch, not a room. Step 12 is the live destination/warp sequence; provide a valid prepared destination while ordinary gameplay is safe to leave. It eventually invokes destination preparation and render reset, then selects step 13.

Step 13 is the ordinary world dispatcher. Its separate substate byte at full-system +0x3ADDE selects stage setup (0), ordinary play/pause handling (1), or world teardown (2). Main step 3 uses another overlay and is not an ordinary gameplay readiness test.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `step` | `unsigned char` | Native system-step index; the documented warp path uses 12. |

## Return value

No return value.

## Usage example

```c
extern void func_80003728_4328(unsigned char step);

/* The caller has prepared a valid destination and released native dialog,
 * pause and scripted-movement ownership in an already loaded live world. */
void enter_prepared_warp_step(void)
{
    func_80003728_4328(12);
}
```

The native step controller performs the remaining transition. Preparing a live destination is separate from updating a save-file respawn point.

## Notes

- Step numbers are state-machine selectors, not arbitrary room IDs.
- Jumping to a step without its expected prior initialization can leave invalid render or game state.
