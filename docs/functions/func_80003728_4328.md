`func_80003728_4328` · **Function**

Switches the native system execution step and resets transition substate.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80003728` | `0x00004328` | `.main` |

Native code size: **100 bytes**.

## Signature

```c
extern void func_80003728_4328(unsigned char step);
```

## How it works

Writes g_system stepw, clears stepw_end, marks the transition and resets its substate.

The numeric step selects a state-machine branch, not a room. Step 12 is the documented warp path, but requires prior save, destination, render and control initialization.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `step` | `unsigned char` | Native system-step index; the documented warp path uses 12. |

## Return value

No return value.

/* Requires the native start/load preparation described above.
 * This helper is one step of that sequence, not a complete launch API. */
void enter_prepared_warp_step(void) {
    /* Only after native save/destination/render setup is complete: */
    func_80003728_4328(12);
}

## Notes

- Step numbers are state-machine selectors, not arbitrary room IDs.
- Jumping to a step without its expected prior initialization can leave invalid render or game state.
