`func_80038B98_39798` · **Function**

Queues a 16-bit native audio command with the wrapper default parameters.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80038B98` | `0x00039798` | `.main` |

Native code size: **48 bytes**.

## Signature

```c
extern void func_80038B98_39798(unsigned short cue);
```

## How it works

Masks the cue to 16 bits and forwards it to the underlying audio queue with both additional parameters set to zero.

The queue holds at most eight pending commands and suppresses duplicates only while they remain in that pending queue. A later call can enqueue the same command again.

Congo camera initialization starts unsigned-halfword task timer +0x8A at 30. During its opening callback, the timer value 25 queues music cue 0x003D exactly once before the rest of the intro continues.

Subsequent Congo intro callbacks do not repeat that music command. Advancing directly to a later intro callback can therefore bypass its original music transition.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `cue` | `unsigned short` | Native 16-bit command or cue ID. Congo battle music uses 0x003D. |

## Return value

No return value. The wrapper does not report whether the queue accepted the command.

## Usage example

```c
extern void func_80038B98_39798(unsigned short cue);

/* Call once at the intended battle-music transition. */
void queue_congo_battle_music(void)
{
    func_80038B98_39798(0x003D);
}
```

Queue the verified Congo music command once. The caller supplies the transition lifetime; the native wrapper supplies its default queue parameters.

## Notes

- Invoke at the intended native transition. Repeating a command every frame is not prevented by a persistent already-playing check in this wrapper.
- The void return provides no delivery acknowledgment; preserve the native audio scheduler and queue lifetime.
