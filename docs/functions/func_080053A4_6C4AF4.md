`func_080053A4_6C4AF4` · **Function**

Releases native pickup control, records Moon completion and retires the reward.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x080053A4` | `0x006C4AF4` | `.file_30` |

Native code size: **96 bytes**.

## Signature

```c
extern void func_080053A4_6C4AF4(void *task, void *object);
```

## How it works

Waits until the native scenario program counter is zero. Then releases pickup control, sets packed save flag 0x0A4 through the native flag setter, and sets task status +0x68 remove bit 0x2.

The common native actor post consumes remove bit 0x2 through its normal task cleanup. The completion routine must remain associated with the pickup that acquired player control.

Completion flag 0x0A4 is at save byte +0x14, bit 4, mask 0x10. It is separate from Moon inventory at +0x254 and the Goemon weapon-tier word at +0x0A4.

The actual Congo exit is the file_43 placed actor 0x34B, initialized as 0x23C. Its native wait reads flag 0x0A4, then starts a 120-update opening timer, sound 0x224 and opening animation. The existing portal leads to room 0x28.

The ordinary Congo camera reacts when both 0x0A4 and its separate 0x132 condition are set. It consumes 0x132, views the exit for its native 150-update phase, then waits 20 updates before returning to normal. On later room entry, flag 0x0A4 suppresses the Congo root and skips the camera intro.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Native Moon reward whose pickup scenario has started. |
| `object` | `void *` | The reward task’s native display object. |

## Return value

No return value.

## Usage example

```c
#include "modding.h"

extern void *D_8016DAB4_16E6B4;
static unsigned int completed_moon_pickups;

RECOMP_HOOK_RETURN("func_080053A4_6C4AF4")
void observe_moon_completion(void)
{
    const unsigned char *task = D_8016DAB4_16E6B4;
    if (!task || *(const unsigned short *)(task + 0x5E) != 0x350u)
        return;
    if (*(const unsigned int *)(task + 0x68) & 2u)
        ++completed_moon_pickups;
    /* The normal post callback consumes removal; retain no task pointer. */
}
```

Observe successful completion after native control release and flag mutation, before the ordinary post callback retires the reward. The example does not retain a task pointer or call the completion routine itself.

## Notes

- This routine releases global pickup control. Do not call it to retire an uncollected reward that never started the scenario.
- A saved flag change can activate the exit and camera while a scene is still active; preserve the native completion ordering.
- The Congo exit is not the generic locked doorway or the unrelated file_29 rotating-object callback.
