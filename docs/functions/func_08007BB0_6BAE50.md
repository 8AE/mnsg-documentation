`func_08007BB0_6BAE50` · **Function**

| Runtime address | ROM address | Section |

## Signature


## How it works

Adds four angle units per AI tick and ends the revolution when object yaw returns to 0x360.

At the endpoint, installs func_08007C18_6BAEB8 and a 60-tick wind-down timer. Native behavior performs one revolution per spin sequence.
