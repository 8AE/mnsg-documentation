`func_8003E6C0_3F2C0` · **Function**

Converts scenario choice instructions into selectable native dialog records.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8003E6C0` | `0x0003F2C0` | `.main` |

Native code size: **348 bytes**.

## Signature

```c
extern unsigned int *func_8003E6C0_3F2C0(unsigned int *records);
```

## How it works

Invoked by scenario opcode 0x8011. The following instruction stream contains four-word records of text opcode 0x8010, label pointer, branch opcode 0x800A and branch pointer, terminated by opcode 0x8012.

Constructs five-word (20-byte) runtime records in D_801C7808_1C8408 and stores the selected-record pointer in D_801C7800_1C8400. The usual Yes/No order places Yes first and No second.

Returns a pointer to the 0x8012 instruction that terminates the definitions. A return hook is the boundary after the runtime records exist; selection changes made before parsing completes are overwritten by the parser.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `records` | `unsigned int *` | First four-word text/branch choice definition, with a 0x8012 terminator after the last record. |

## Return value

Pointer to the 0x8012 sentinel in the scenario instruction stream.

## Notes

- The parser expects the scenario window to be allocated. Window allocation failure must be handled before publishing a choice script.
- Only change the selection when the current interpreter and choice records still belong to the intended scenario.
- Runtime storage has capacity for 10 choice records. The native parse loop does not enforce that bound; validate custom instruction streams before publishing them.
