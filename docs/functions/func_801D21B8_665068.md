`func_801D21B8_665068` · **Function**

Runs the file-select options-menu state machine, including the native boss-rush option.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x801D21B8` | `0x00665068` | `.file_15` |

Native code size: **4092 bytes**.

## Interface

A complete callable prototype has not been established. Use the observation or callback-identity pattern in the example rather than guessing the native arguments.

## How it works

In the US file-select overlay, the menu state is a byte at task +0x78. State 0 initializes the menu and tests the saved unlock at D_8015CC18_15D818 and session unlock at 0x8015C564.

The locked builder is state 1. State 6 builds the menu containing Consecutive Fighting! Large Boss. The native selection handler launches that option through func_800370B0_37CB0.

The same state machine owns native navigation and the Sound Mode return path.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Live options-menu task; its one-byte menu state is at +0x78. |

## Usage example

```c
#include "modding.h"

RECOMP_HOOK("func_801D21B8_665068")
void show_native_boss_rush_option(void *task)
{
    unsigned char *state = (unsigned char *)task + 0x78;
    if (*state == 1) *state = 6;
}
```

Redirect only the locked builder state to the existing boss-rush builder. State 0 initialization and the later native navigation/launch states continue normally.

## Notes

- The state layout belongs to this menu task. Assigning builder states during navigation or initialization bypasses required state transitions.
