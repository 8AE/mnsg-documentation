`func_80218C28_5D40F8` · **Function**

Copies inherited actor context into an existing child before the spawning caller assigns its requested entity ID.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80218C28` | `0x005D40F8` | `.file_12` |

Native code size: **340 bytes**.

## Signature

```c
void func_80218C28_5D40F8(void *parent, void *child);
```

## How it works

Receives the parent in the first argument and the allocated child in the second. Copies parent context including the +0x98 field, entity halfwords and generation byte +0x74; it does not allocate the child or rewrite callback +0x0C.

In the func_80217360_5D2830 spawn path, the child object at +0x18 and file ID at +0x28 already exist when this helper is entered. Callback +0x0C can still be the raw segmented address taken from the native callback table.

The spawning caller writes the requested entity ID to child +0x5C/+0x5E only after this helper returns. Those halfwords at helper entry or return are therefore not proof of the requested child identity.

The recompiled scheduler resolves task callback addresses later, before the child's first dispatch. A raw birth-time address and its loaded callback address can represent the same callback. For the verified raw 0x08000000–0x08FFFFFF family, it uses the fixed-base 32-bit unsigned mapping raw_callback - 0x08000000u + (resource_handle & 0xBFFFFFFFu), distinct from func_80014840_15440's native per-file segment conversion.

In the direct Ebisumaru explosion path, task bank +0x28 and resource base +0x2C are both zero on entry. After this helper returns, the allocator writes 0xFFFE and 0xFFFFFFFF as pending-resource sentinels, then the overlay caller installs bank 0x2A and the resident File42 base.

Copies the child entity halfword +0x5C and model halfword +0x5E from the parent independently; equality between those identifiers is not an invariant of this helper.

## Notes

- Requires valid parent and allocated child objects. It is an inheritance stage of construction, not a substitute for allocation or entity-specific initialization.
- At this early boundary, use verified callback/file context for identity checks. For raw callbacks in the verified 0x08000000–0x08FFFFFF family, do not compare func_80014840_15440's per-file segment result with the scheduler-loaded address. If an early comparison is required, validate the corresponding resident resource, reject null and 0xFFFFFFFF handles before clearing tags, then apply the scheduler's fixed-base 32-bit unsigned mapping to a local copy only.
- Do not mutate or run a callback merely to normalize an identity comparison.
- For this direct-child path, the values seen at helper entry are temporary construction state, not the final overlay identity. Do not classify the callback from only those early fields.
