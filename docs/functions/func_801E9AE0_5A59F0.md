## How it works

Creates a head using model 0x49009020, a targeting marker using 0x49009238, and eight link actors using 0x49009348. These models use Goemon broad resource 0x120 and material 0xC006D920.

The head and marker use uniform scale 0.09. Link actors use scale 0.045 and the native 0x8000 rotation markers on all three axes.

The construction path calls the native outgoing-attack setup for the head and links. It creates gameplay collision state as well as visible geometry.

The head stores its playable owner at task +0x5C. Each link stores its owning head at task +0x9C; head and links have distinct update callbacks.
