`func_800106F0_112F0` · **Function**

Appends one 12-byte sprite record to a native sprite queue.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x800106F0` | `0x000112F0` | `.main` |

Native code size: **148 bytes**.

## Signature

```c
extern int func_800106F0_112F0(int queue, short x, short y, unsigned short width, unsigned short height, int texture_handle, short s, short t);
```

## How it works

Appends a fixed 12-byte record containing the supplied position, dimensions, texture handle, and texture coordinates.

Under the o32 ABI, height, texture_handle, s, and t occupy caller stack slots 0x10, 0x14, 0x18, and 0x1C relative to the argument area.

The native registry supports at most 16 live queues. Each queue's record capacity is supplied when it is created.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `queue` | `int` | Queue index returned by native sprite-queue creation. |
| `x` | `short` | Horizontal position supplied for this sprite record. |
| `y` | `short` | Vertical position supplied for this sprite record. |
| `width` | `unsigned short` | Width supplied for this sprite record. |
| `height` | `unsigned short` | Height supplied for this sprite record. |
| `texture_handle` | `int` | Native texture-descriptor handle used by this sprite record. |
| `s` | `short` | S texture coordinate supplied for the record. |
| `t` | `short` | T texture coordinate supplied for the record. |

## Return value

The appended record index, or -1 if the queue cannot accept another record.

## Usage example

```c
extern int func_800106F0_112F0(int queue, short x, short y, unsigned short width, unsigned short height, int texture_handle, short s, short t);

int append_hud_icon(int queue, int texture_handle)
{
    return func_800106F0_112F0(queue, 16, 24, 8, 8, texture_handle, 0, 0);
}
```

Append one sprite using a live texture descriptor and the coordinates required by its image sheet.

## Notes

- Pass a live texture handle returned by native descriptor registration.
- The visual result of adding a sprite during a scene's first introductory animation has not been tested.
