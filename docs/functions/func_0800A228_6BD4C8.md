## How it works

Task +0xE8 bit 0x04000000 gates the health-threshold and zero-health portion. Other effect bits in the same word are processed separately, so skipping the entire routine is broader than disabling that health portion.

For Congo, HP is the unsigned byte at task +0x8D. Exact HP values 25, 20, 15, 10 and 5 produce event pairs (1, 0x0B), (2, 0x0B), (5, 0x0B), (4, 0x0B) and (3, 0x0B), respectively. A different HP value clears transient event 0x0B.

A threshold event can be emitted again on every call while HP remains exactly at that threshold. The routine does not identify a unique physical attack or consume an encounter-wide threshold serial.

At zero HP, when flag 0x12E is clear, Congo handling clears status remove bit 0x2 and attack-capability bit 0x00200000, restores HP to one, sets kill flag 0x1A1 and schedules func_08007D24_6BAFC4 for the victory sequence.

This controller can also run for Tsurami roots. Identify Congo by entity 0x323 at unsigned halfword task +0x5E before interpreting Congo-specific state.

Event 0x0B is an immediate transient event, separate from saved progress flags. The ordinary Congo camera selects its shake callback while that event is set.

Read the actual event bank through func_80023E94_24A94 when its current state matters. Other native callers can clear the event even while HP remains at a threshold, so HP alone is not an equivalent event-state query.

The zero-health transition starts the native victory chain rather than completing it. Later root callbacks create, raise, lower and release a white screen-fade controller; a separate camera continuation eventually restores normal framing and player control.

Congo zero-health handling schedules func_08007D24 as its victory callback. Tsurami roots can also pass through this helper, so identifying Congo requires its entity ID 0x323 at actor+0x5E.

This boundary can run during actor setup before the first main combat update. Capture only the health-bearing root and wait for initialized state before interpreting it.
