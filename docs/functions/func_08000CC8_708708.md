`func_08000CC8_708708` · **Function**

Runs the native held, free, contact, and below-ground lifecycle for an Impact cube.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x08000CC8` | `0x00708708` | `.file_48` |

## Signature

```c
void func_08000CC8_708708(void *task, void *object);
```

## How it works

Phase 0 initializes the throwable with a zero-radius native collider, then enters phase 1. When the held status bit 0x8000 in task +0x68 is set, phase 1 skips the free-object collider installation; that branch does not clear or rewrite the phase-0 collider on each update. When the bit is clear, it installs the free-object collider using helper argument 20, which corresponds to radius scalar 2 after the helper’s divide-by-10 conversion.

The native common update applies gravity from task byte +0x75 as an unsigned value divided by 50 when gravity is enabled. This callback sets that byte to 10, yielding a 0.2 downward velocity adjustment per update. The separate integration flag advances world position by velocity multiplied by 2.

When native contact bits 0x3200 are present, the callback plays its contact response and sets task result byte +0xD1 to zero. It also sets that result byte to zero when object Y is below zero, even without the contact bits. The controller observes a zero result and retires the throwable on a later callback.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | The matching native throwable task. |
| `object` | `void *` | The throwable object supplied by the native scheduler. |

## Return value

No return value.

## Usage example

```c
extern void func_08000CC8_708708(void *task, void *object);
typedef void (*TaskCallback)(void *, void *);

TaskCallback documented_throwable_callback(void)
{
    return func_08000CC8_708708;
}
```

Returns the callback address for inspection. The native scheduler owns invocation and the throwable lifecycle.

## Notes

- Contact, terrain, gravity, and integration are native lifecycle stages. Do not add a second gravity or 2×velocity step when observing an actor that still receives the native update.
- This is a local child task/object pair. The callback’s native hit/contact state and task pointer are not remote actor state.
