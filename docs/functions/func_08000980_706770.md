`func_08000980_706770` · **Function**

Initializes a native collision platform, then updates its rotation and vertical placement.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x08000980` | `0x00706770` | `.file_47` |

Native code size: **300 bytes**.

## Signature

```c
void func_08000980_706770(void *task, void *object);
```

## How it works

Phase 0 initializes the native platform and binds collision. Phase 1 updates its pose and visibility.

Task halfword +0xD2 is the yaw increment; the observed instances use +2 or -2. Task float +0xD4 is the platform Y value.

The object XYZ floats are at +0x08, +0x0C and +0x10; object yaw is the halfword at +0x16.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Live task initialized by the matching native constructor. |
| `object` | `void *` | The task's own native render or collision object, where this callback uses one. |

## Return value

No return value.

This returns the callback address without executing initialization, moving a platform, or advancing the challenge. The callback requires the matching resident overlay and initialized native task graph.

## Notes
