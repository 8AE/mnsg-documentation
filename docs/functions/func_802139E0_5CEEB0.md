`func_802139E0_5CEEB0` · **Function**

Binds the native billboard shine model and looping texture animation for an already-allocated child task.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x802139E0` | `0x005CEEB0` | `.file_12` |

Native code size: **188 bytes**.

## Signature

```c
extern void func_802139E0_5CEEB0(void *task, void *object);
```

## How it works

The effect allocator selects this initializer for its category13 shine branch. The child starts with inherited entity identity and generation.

Sets model1 and task flags0x22A, binds static slot5 and billboard state, and starts texture clip1 at rate0.5 with looping enabled. It sets byte+D5 to1, adds task flags+64 bit2, and installs func_80213A9C_5CEF6C.

The initializer does not clear byte+D0, the continuation termination signal.

## Usage example

```c
#include "modding.h"

static volatile unsigned char observed_value;

RECOMP_HOOK("func_802139E0_5CEEB0")
void observe_native_state(void *task, void *object)
{
    (void)object;
    if (!task) return;
    observed_value = *(volatile unsigned char *)((char *)task + 0xD0);
}
```

Observes the termination byte at entry without clearing it or replaying construction.

## Notes

- Only the native constructor path should initialize this child. Replaying it may rebind resources and reset the local visual state.
- The parent-to-child pointer is local and can become stale after task-slot reuse; entity, generation, object and callback identity must be checked before accessing a linked child.
