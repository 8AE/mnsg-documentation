`func_801FBB30_5B7A40` · **Function**

Creates and initializes the native display object used by the player-heart HUD.

## Interface

## How it works

Creates one child display object through the native kind-1 display allocator.

Initializes the object's texture descriptor, writes 0.5 to the horizontal and vertical scale fields at +0x2C and +0x30, and sets bit 0x04 in the display-object byte at +0x08 to enable those scale values.

The renderer's scale path ignores the floating-point scale fields unless byte +0x08 has bit 0x04 set.

The companion heart updater uses native atlas descriptors for full/current, empty/maximum, base, and half-heart images.
