`func_80221F70_5DD440` · **Function**

Starts a native local-control state by setting the input lock and resetting its player-control fields.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80221F70` | `0x005DD440` | `.file_12` |

Native code size: **64 bytes**.

## Signature

```c
extern void func_80221F70_5DD440(void);
```

## How it works

Writes one to D_800C7AE2, clears the pointed local-player control halfword, and resets four related halfwords in the full system structure.

Sets the companion local-control state byte to one after clearing those fields. The routine takes no task argument, so its effects apply to the current local player and system state.

## Return value

No return value.

## Usage example

```c
#include "modding.h"

static volatile unsigned int local_control_entries;

RECOMP_HOOK("func_80221F70_5DD440")
void observe_local_control_entry(void)
{
    ++local_control_entries;
}
```

Observes entry without invoking the control transition a second time or altering its local-player fields.

## Notes

- This is a client-local control transition, not a portable world-state setter. Do not replay it for a remote actor.
- The function overwrites several local-player control fields. Call it only as part of the native sequence that owns those fields.
