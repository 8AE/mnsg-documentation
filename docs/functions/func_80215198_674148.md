`func_80215198_674148` · **Function**

Updates the dungeon map floor panel and resolves its relative display positions.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80215198` | `0x00674148` | `.file_17` |

Native code size: **732 bytes**.

## Signature

```c
extern void func_80215198_674148(void *task);
```

## How it works

This file_17 callback belongs to the task created by func_802155F4_6745A4. The callback resolves parent-relative positions with func_8001136C_11F6C before drawing the panel.

Task +0x90 is the dungeon index, +0x94 the selected floor and +0x98 the floor count, all 32-bit words. +0x6C/+0x70 are the resolved screen origin.

The floor rows use func_80215150_674100. Existing display-object links and cached panel buffers must remain intact.

## Usage example

```c

static int selected_floor;
RECOMP_HOOK("func_80215198_674148")

{
    selected_floor = *(int *)(task + 0x94);
}
```

The example illustrates the native interface and its required state.

## Notes

- Only access this layout while its owning overlay and task are active. Task-pool addresses can be reused after destruction.
