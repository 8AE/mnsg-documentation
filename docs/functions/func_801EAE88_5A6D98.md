## How it works

The callback integrates child offsets and rotates the effect using func_801EAF50_5A6E60 against the native local target.

Its position and rotation work is tied to the native owner and local target; do not replay the raw callback for a remote player.

Child scale grows from 0.03 to 0.13 by 0.01 per update, then to 0.15 by 0.002 per update before fading.

The child fades alpha by 0x20 per update.

The child object retains 0x8000 in its three rotation halfwords for the smoke model’s camera-facing draw path.

func_801EAF50_5A6E60 separately rotates smoke position offsets toward the local target; that offset rotation is distinct from the object rotation sentinels used for facing.
