`func_8003521C_35E1C` · **Function**

Installs the AI callback of the scheduler current task.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8003521C` | `0x00035E1C` | `.main` |

Native code size: **16 bytes**.

## Signature

```c
extern void func_8003521C_35E1C(void (*update)(void *, void *));
```

## How it works

Writes the supplied callback pointer to D_8016DAB4_16E6B4 +0x0C. The function has no task parameter and performs no null check.

An initializer can use it to schedule the recurring update state. State callbacks also use it to transition to the next native AI state.

Stores the supplied code pointer in the active task callback slot at +0x0C. The scheduler executes it as part of the subsequent native task flow.

A valid active task context and a resident engine-compatible callback are required. Setting the pointer does not immediately invoke the callback.

## Parameters

| --- | --- | --- |
| `update` | `void (*)(void *, void *)` | Callback to run for the current task on subsequent AI updates. |

## Return value

- Requires a valid active native task context.
- Provide an engine-compatible callback that remains resident in the relevant overlay.
