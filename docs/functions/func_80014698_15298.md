`func_80014698_15298` · **Function**

Returns a resource stored ROM length and optionally its ROM address.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80014698` | `0x00015298` | `.main` |

Native code size: **388 bytes**.

## Signature

```c
extern int func_80014698_15298(unsigned int resource_id, void *rom_address_out);
```

## How it works

For file IDs below 0x8000, subtracts the ROM start from the end. For packed resource IDs, resolves the offset within the containing file and determines the next boundary or containing-file end.

A null ROM-address output pointer requests only the size. IDs at or above 0x8770 return zero and write zero when an output pointer is supplied.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `resource_id` | `unsigned int` | Resource ID to inspect. |
| `rom_address_out` | `void *` | Optional pointer to a 32-bit ROM-address output; null is allowed. |

## Return value

Stored byte length as int; zero for an out-of-range ID.

## Usage example

```c
extern int func_80014698_15298(unsigned int resource_id, void *rom_address_out);

/* Queries stored ROM bytes, not decompressed output capacity. */
int query_resource(unsigned int resource_id, unsigned int *rom_address) {
    if (!rom_address) return 0;
    return func_80014698_15298(resource_id, rom_address);
}
```
