`func_800371B4_37DB4` · **Function**

Saves the current player position and facing, then records native transition values for room 0x01E2.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x800371B4` | `0x00037DB4` | `.main` |

Native code size: **208 bytes**.

## Signature

```c
void func_800371B4_37DB4(void);
```

## How it works

Copies the current player XYZ position and facing into native transition state before preparing the minigame entry.

Calls func_801FA4FC_5B640C with room 0x01E2, arrival XYZ (-213, 0, -357), camera value 0x0060, and final argument 1. The helper's nonzero branch writes transition marker 4.

The associated File 98 event scenarios are 0x0178 and 0x0179.

## Return value

No return value.

## Usage example

```c
extern void func_800371B4_37DB4(void);

/* Invoke only from a context with the native player state initialized. */
void enter_sasuke_high_jump_minigame(void)
{
    func_800371B4_37DB4();
}
```

This calls the native launcher, which snapshots the active player's position and prepares the documented room request. It does not demonstrate that an unrelated room-transfer routine recreates this path.

## Notes

- This documents the verified native launch path and its transition-state writes; a generic room transfer is not established as an equivalent replacement.
- The saved transition-state fields are not documented here as general-purpose save data.
