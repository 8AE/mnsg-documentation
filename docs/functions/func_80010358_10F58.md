`func_80010358_10F58` · **Function**

Resets the pending sprite-record count for a native sprite queue.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80010358` | `0x00010F58` | `.main` |

Native code size: **28 bytes**.

## Signature

```c
extern void func_80010358_10F58(int queue);
```

## How it works

Resets the queue's pending record count so a later collection pass can append sprites again.

Resetting a queue does not release its backing buffer; use the queue cleanup routine when its lifetime ends.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `queue` | `int` | Queue index returned by native sprite-queue creation. |

## Return value

No return value.

## Usage example

```c
extern void func_80010358_10F58(int queue);

void begin_sprite_pass(int queue)
{
    func_80010358_10F58(queue);
}
```

Reset the pending sprite list at the start of a collection pass.

## Notes

- Keep the queue allocated for as long as later append and finalize calls use its index.
