`func_8000D060_DC60` · **Function**

Adds a game-font glyph whose record supports native per-glyph palette selection.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8000D060` | `0x0000DC60` | `.main` |

Native code size: **288 bytes**.

## Signature

```c
extern void func_8000D060_DC60(int slot, unsigned int glyph);
```

## How it works

Uses the native window in the selected slot and searches its 120 glyph records for the first free record.

Printable ASCII characters map to glyph indices by subtracting 0x20 from the character byte. The call advances the horizontal cursor by the glyph width plus one pixel.

The glyph record stores its center coordinates relative to the window text layout, scale values, and the current low text-effect mask. The low four bits of the glyph record field at +0x06 select its text palette; preserve the remaining bits when changing the selector because they also carry glyph display effects such as blinking or hiding. In the inspected US text renderer, selectors 6/7 use a blue-violet palette (RGB5551 entries 0x003F, 0x31BF, and 0x633F), while selectors 8/9 use a green palette (0x0401, 0x0701, and 0x07C1).

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `slot` | `int` | Allocated native message-window slot, 0 through 2. |
| `glyph` | `unsigned int` | Native game-font glyph index; printable US ASCII uses character value minus 0x20. |

## Return value

No return value.

## Usage example

```c
extern void func_8000D060_DC60(int slot, unsigned int glyph);

/* Insert the native glyph for the letter A (ASCII 0x41). */
void add_letter_a(int slot)
{
    func_8000D060_DC60(slot, 0x41u - 0x20u);
}
```

Pass a bounded glyph from the game font to an allocated window. The routine selects the first free glyph record and updates the text cursor.

## Notes

- The window has a fixed capacity of 120 glyph records. Do not assume insertion succeeds when all records are occupied.
- Unicode characters and scenario control tokens are not printable ASCII glyph indices.
- When changing a glyph palette, update only the low four bits at record +0x06. The higher bits include display-effect state and must be preserved.
