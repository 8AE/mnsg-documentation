`func_800370E8_37CE8` · **Function**

Saves the current player position and facing, then records native transition values for room 0x01E0.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x800370E8` | `0x00037CE8` | `.main` |

Native code size: **204 bytes**.

## Signature

```c
void func_800370E8_37CE8(void);
```

## How it works

Copies the current player XYZ position and facing into native transition state before preparing the minigame entry.

Calls func_801FA4FC_5B640C with room 0x01E0, arrival XYZ (0, 25, 0), camera value 0, and final argument 1. The helper's nonzero branch writes transition marker 4.

The associated File 98 event scenarios are 0x0172 through 0x0175.

## Return value

No return value.

## Usage example

```c
extern void func_800370E8_37CE8(void);

/* Invoke only from a context with the native player state initialized. */
void enter_goemon_impact_minigame(void)
{
    func_800370E8_37CE8();
}
```

This calls the native launcher, which snapshots the active player's position and prepares the documented room request. It does not demonstrate that an unrelated room-transfer routine recreates this path.

## Notes

- This documents the verified native launch path and its transition-state writes; a generic room transfer is not established as an equivalent replacement.
- The saved transition-state fields are not documented here as general-purpose save data.
