`func_8021A328_5D57F8` · **Function**

A task-entry helper that checks status and spawn-descriptor state before applying its local-player proximity cleanup path.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8021A328` | `0x005D57F8` | `.file_12` |

Native code size: **436 bytes**.

## Signature

```c
extern void func_8021A328_5D57F8(void *task);
```

## How it works

Runs its proximity path only when task status +0x68 has bit 0x08 set and task +0x70 contains a non-null static spawn descriptor.

Compares the descriptor's configured activation bounds with the local player position. Outside those bounds, the helper may create the native disappearance effect, clears the descriptor's active byte at +0x10, clears task +0x70, and sets task status +0x68 to 0x02.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Live task entry passed in the first argument register, with the native status and spawn-descriptor fields expected by this helper. |

## Return value

No public return value is established; the verified helper body is a task-entry routine.

## Usage example

```c
#include "modding.h"
extern void func_8021A328_5D57F8(void *task);

typedef void (*NativeTaskEntry)(void *);

NativeTaskEntry documented_proximity_helper(void)
{
    return func_8021A328_5D57F8;
}
```

Returns the verified task-entry identity without executing proximity cleanup. The native scheduler owns invocation and lifecycle timing.

## Notes

- Dynamic child inheritance clears task +0x70. The studied blast-parent initialization path does not repopulate it, so this descriptor branch remains inactive there; its separate effect child and unrelated constructors are not covered by that observation.
- The helper depends on local-player position and mutates task/descriptor lifecycle state. Do not replay it as a general visual-motion step or assume the proximity path is active for every task.
