`func_8021ADD0_5D62A0` · **Function**

Maps an X/Z direction to the game's 10-bit yaw scale and returns the raw result as a zero-extended 16-bit value.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8021ADD0` | `0x005D62A0` | `.file_12` |

Native code size: **612 bytes**.

## Signature

```c
extern unsigned int func_8021ADD0_5D62A0(float delta_x, float delta_z);
```

## How it works

Converts an X/Z direction using a native lookup table. The cardinal results are +Z 0, +X 256, -Z 512 and -X 768; equal-magnitude diagonals return 128, 384, 640 or 896 according to quadrant.

For an exact zero vector, the equal-magnitude path returns 128. Some callers avoid updating yaw when planar velocity is zero so an idle actor keeps its current facing.

The native function masks its result to 16 bits, not 10. Near +Z, a small negative X can produce raw value 1024 when the lookup-table angle quantizes to zero. Mask with 1023 at the call site when a normalized 10-bit yaw is required.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `delta_x` | `float` | Finite planar X direction component. |
| `delta_z` | `float` | Finite planar Z direction component. |

## Return value

Raw yaw value zero-extended from the low 16 bits; one full turn uses 1024 yaw units.

## Usage example

```c
#include "modding.h"
extern unsigned int func_8021ADD0_5D62A0(float delta_x, float delta_z);

unsigned int direction_yaw(float x, float z, unsigned int current_yaw)
{
    if (x == 0.0f && z == 0.0f) return current_yaw;
    return func_8021ADD0_5D62A0(x, z) & 1023u;
}
```

Preserves the current facing for an idle direction and normalizes the helper's raw result before storing a 10-bit yaw.

## Notes

- Use finite, validated inputs; NaN behavior is not established. The helper is a scalar conversion and does not update an actor or check whether a zero direction should preserve facing.
- Do not assume every raw return is in the range 0 through 1023. Apply the native 10-bit mask where the receiving field or operation requires it.
