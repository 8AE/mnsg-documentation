`func_80034EF8_35AF8` · **Function**

Runs native teardown and removal for a specified task handle.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80034EF8` | `0x00035AF8` | `.main` |

Native code size: **40 bytes**.

## Signature

```c
extern void func_80034EF8_35AF8(void *actor);
```

## How it works

Forwards the supplied task through native teardown helpers. Use it for an exactly identified owned task, then clear every retained handle referencing that task.

Task removal does not substitute for boss damage, reaction, reward or completion callbacks. Those require the encounter own state-machine path.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `actor` | `void *` | Engine task handle to tear down. |

## Return value

No return value.

## Usage example

```c
extern void func_80034EF8_35AF8(void *actor);

/* Only for a verified child this caller owns, at a safe native boundary.
 * Any other actor trackers referencing this child must also be cleared. */
void destroy_owned_child(void **owned_child) {
    if (!owned_child || !*owned_child) return;
    func_80034EF8_35AF8(*owned_child);
    *owned_child = 0;
}
```

Complete C syntax example using the documented native declarations. Integrate it only at the described engine lifecycle boundary; the game supplies symbol definitions and resident resources.

## Notes

- Only destroy a validated task that this owner controls. Shared render pointers and trackers become stale immediately.
- Do not use generic destruction to simulate boss victory: damage, animation, reward and terminal callbacks still need to run.
