`func_8021B808_5D6CD8` · **Function**

Integrates native actor velocity into object position.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8021B808` | `0x005D6CD8` | `.file_12` |

Native code size: **96 bytes**.

## Signature

```c
extern void func_8021B808_5D6CD8(void *task);
```

## How it works

When task flags at +0x60 contain 0x200, adds task velocities +0x78/+0x7C/+0x80 multiplied by 2.0f to object xyz at +0x08/+0x0C/+0x10.

If the movement flag is clear, position is unchanged. This helper does not by itself perform collision handling.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Live task with object pointer and native velocity fields initialized. |

## Notes

- The native step scale is 2.0. Do not also apply the same velocity manually.
