`func_080008B8_6F0AC8` · **Function**

Stores a seconds value as signed native frames at the HUD task timer field.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x080008B8` | `0x006F0AC8` | `.file_42` |

## Signature

```c
void func_080008B8_6F0AC8(void *hud_task, int32_t seconds);
```

## How it works

Stores seconds × 30 as a signed 32-bit word at HUD task +0x80. The setter performs no range validation.

The normal challenge setup uses 99 seconds, producing an initial value of 2970 frames.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `hud_task` | `void *` | HUD task with signed timer word at +0x80. |
| `seconds` | `int32_t` | Seconds value multiplied by the native 30-frame-per-second unit. |

## Return value

No return value.

## Usage example

```c
#include <stdint.h>

extern void func_080008B8_6F0AC8(void *, int32_t);

void set_hud_countdown(void *hud_task, int32_t seconds)
{
    if (hud_task) func_080008B8_6F0AC8(hud_task, seconds);
}
```

Sets the timer through the native seconds-to-frames helper; the caller must supply the live HUD task.

## Notes

- Pass a live HUD task in its native lifecycle. This setter does not clamp or validate the supplied seconds value.
