`func_80219CA0_5D5170` · **Function**

Selects an actor task owner/list and checks native capacity limits.

## Signature

```c
extern int *func_80219CA0_5D5170(int *, unsigned char);
```

## How it works

Checks the total cap at 0x8015CCFC against live counts, records the requested category and chooses a native scheduler list root.

Categories 6, 8, 9, 10 and 12 also receive category-count checks. Category 13 returns the supplied task. A rejected capacity check returns null.

Checks total actor limits, records the selected category, chooses the corresponding manager list and counts existing members for capped categories. Category 0x0D returns the caller-supplied task.

Returns an owner/list for subsequent task creation. It does not allocate the new actor itself.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `int *` | Existing task used by category-specific routing; category 13 returns this input. |
| `actor_type` | `unsigned char` | Native category, distinct from actor ID and model ID. |

## Return value

Owner/list pointer suitable for native allocation, or null when capacity/routing fails.

## Notes

- This routine selects a list/owner; it does not allocate an actor.
- A category is distinct from actor ID and model ID.
- This selects a list; it does not allocate the enemy itself.
- The function has shared actor-manager side effects. Preserve native spawning order and validate actor IDs before table access.
