`func_801CB824_587734` · **Function**

Advances player animation and processes input, invulnerability, damage and action transitions before the player update callback.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x801CB824` | `0x00587734` | `.file_11` |

Native code size: **680 bytes**.

## Signature

```c
extern void func_801CB824_587734(void *player, void *render_object);
```

## How it works

Expects the scheduler's real playable task and its render object. Player work byte +0x69 gates the main body while character resources change.

Updates animation frame and input-derived state, then runs normal control and invulnerability maintenance when the low control bits permit it.

Calls func_801D9E9C_595DAC only when D_800C7AE2 and D_800C7AE3 are both zero and D_800C7AE0 equals 0 or 4. Calls func_801E8E24_5A4D34(player, 1) after a nonzero intake result.

An entry hook runs before these native updates. A return hook sees their resulting state; it cannot be treated as the same timing boundary.

## Usage example

```c
#include "modding.h"

extern void *D_801FC604_5B8514;
static unsigned char observed_invulnerability;

RECOMP_HOOK("func_801CB824_587734")
void observe_player_before_update(void *player, void *object)
{
    (void)object;
    if (player && player == D_801FC604_5B8514)
        observed_invulnerability = ((unsigned char *)player)[0xD4];
}
```

The example illustrates the native interface and its required state.

## Notes

- Do not apply this playable callback to a remote visual object or call it twice to obtain a collision query.
- Damage availability is narrower than the late collision callback's low-bit gate. Preserve the individual native byte checks instead of substituting a guessed action blacklist.
