`func_801FB2D0_5B71E0` · **Function**

Resolves floors in vertical dungeon rooms and updates native exploration state.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x801FB2D0` | `0x005B71E0` | `.file_11` |

Native code size: **1636 bytes**.

## Interface

A complete callable prototype has not been established. Use the observation or callback-identity pattern in the example rather than guessing the native arguments.

## How it works

The file_0C updater switches on the room's special-floor rule. Its vertical comparisons are strict greater-than tests against local world Y.

Rules 1..9 respectively use thresholds -150, -80, 130, 120, 305, 392, (-115 and -372), -120, and 100. Rule seven selects floor two above -115, floor one above -372, otherwise floor zero.

Other branches also distinguish subrooms using X or Z and update visited-room flags. Replaying this routine to locate another player would alter local exploration state.
