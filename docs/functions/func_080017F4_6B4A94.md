## How it works

The native encounter uses room 0x71. This health-bearing root does not initialize the usual entity field at +0x5E; actor ID 0xCB identifies its separate visual components and attacks.

The root later installs private post func_08000388_6B3628, distinguishing it from the separate persistent model and attack children.

Its invocation identifies a fresh root instance even if the engine reused a task address from an earlier encounter.

Health may not yet be initialized at entry. The authoritative initialized update is func_08000388; nearby entity 0xCB actors can be visual components.
