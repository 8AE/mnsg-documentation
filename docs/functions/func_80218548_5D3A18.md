## How it works

Entered only from the common health-zero path after func_80218350_5D3820 has consumed the final health point. Room unloads and distance culls do not call it.

Performs the generic death handling for an ordinary actor, including the reaction, counters, effects and removal bookkeeping.

The synthetic fast-hit bit 0x00040000 at actor +0x68 reaches this path after subtracting one health point, which lets an external source drive the real death without a native attacker pointer.
