`func_080002B4_72BB04` · **Function**

Renders the waterfall challenge countdown and height meter, then decrements the signed 30 Hz countdown with a zero clamp.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x080002B4` | `0x0072BB04` | `.file_69` |

Native code size: **608 bytes**.

## Signature

```c
void func_080002B4_72BB04(void *task);
```

## How it works

HUD task +0x84 is the signed 32-bit raw countdown in 30 Hz ticks. The displayed integer seconds are raw ticks divided by 30.

HUD task +0x90 is the signed 32-bit climbed-height value supplied by the controller from integer(swimmer Y+440). The meter calculation uses a total range of 820 native height units.

Computes the unfilled height with signed integer arithmetic as empty=((820-height)*150)/820, truncating division toward zero. It applies no native height clamp. func_800115E0_121E0 positions the marker at relative X=30 and Y=empty+56; func_8001136C_11F6C then updates the attached render-object transforms.

The local marker is the kind-2 render object at HUD +0x80. Its material pointer at object +0x30 selects the first 16 bytes of buffer HUD +0x78, tagged with 0x20000000. That wrapper calls the resolved File 69 display list 0x08002610 and ends; the countdown and meter display list begins separately at buffer+16.

Draws a 12-unit-wide black rectangle with alpha 160 at absolute HUD X+26, Y+48 and height empty, followed by a green rectangle with alpha 160 at Y+48+empty and height 150-empty. Both rectangles use the single local height field at HUD +0x90.

The callback draws the local display lists, text and progress meter before subtracting one from +0x84. Negative results are clamped to zero.

The native controller initializes the countdown through func_0800058C_72BDDC(HUD,50). It tests the getter's truncated integer seconds for expiry, so the final low-second boundary follows the native division.

## Usage example

```c
extern void func_080002B4_72BB04(void *task);

typedef void (*NativeTaskCallback)(void *);

{
    return func_080002B4_72BB04;
```

This exposes callback identity without running initialization, rendering, movement, collision handling or result cleanup a second time. The resident overlay and native task lifetime remain required.

## Notes

- This is a HUD task layout, not an entity task layout. Its display buffers, sprite handles and resource pointers must remain local and live.
- Suppressing the whole callback also suppresses rendering. If controlling the countdown separately, preserve the native draw operation and avoid decrementing the same timer a second time.
- During a hidden preparation interval, this callback still decrements the timer. Preserve the intended 1500-tick start value until visible gameplay begins while allowing the native HUD to initialize and render normally.
- Validate or clamp a separately supplied height to [0,820] before using the meter formula; the callback itself does not prevent negative or excessive fill lengths. A displayed player-object Y coordinate is 15 units above the swimmer proxy, so the corresponding climbed height is integer(player Y+425), not integer(player Y+440).
- A marker-only visual can share the live local icon wrapper without sharing or rebuilding the countdown and fill display list. The owning HUD, its buffer, the File 69 icon and the marker model resource must all remain live. Replaying the complete callback would also decrement the countdown.
