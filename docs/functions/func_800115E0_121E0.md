`func_800115E0_121E0` · **Function**

Writes signed X and Y offsets into an attached HUD render object without drawing it.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x800115E0` | `0x000121E0` | `.main` |

Native code size: **24 bytes**.

## Signature

```c
void func_800115E0_121E0(void *object, int x, int y);
```

## How it works

Returns without writing when object is null. Otherwise stores X at object +0x80 and Y at +0x84 as signed 32-bit integers.

These are relative coordinates. A later func_8001136C_11F6C call resolves them against the owning HUD position and updates attached render transforms.

The Mermaid training HUD uses X=30 and Y=56+((820-height)*150)/820 for its local character marker. This setter does not change the timer or the progress fill.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `object` | `void *` | Live attached render object with signed offsets at +0x80 and +0x84; null is accepted. |
| `x, y` | `int` | Signed 32-bit relative HUD coordinates. |

## Return value

No return value.

## Usage example

```c
extern void func_800115E0_121E0(void *object, int x, int y);

/* The caller retains ownership of a live compatible HUD object. */
void position_hud_icon(void *object, int x, int y)
{
    func_800115E0_121E0(object, x, y);
}
```

Updates only the native relative offsets. The normal owning HUD update resolves transforms and the renderer draws the object.

## Notes

- A non-null pointer still must belong to a live compatible native render record. The setter does not validate ownership, kind or lifetime.
- Setting offsets alone does not submit a draw or refresh world-space transforms. Keep the owning HUD update and native renderer lifecycle.
