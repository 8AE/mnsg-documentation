`func_8021664C_5D1B1C` · **Function**

Selects and restarts an actor animation, including playback state and resource binding.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8021664C` | `0x005D1B1C` | `.file_12` |

Native code size: **492 bytes**.

## Signature

```c
extern void func_8021664C_5D1B1C(void *, unsigned int, float, unsigned int);
```

## How it works

Uses the task entity/model ID at +0x5E and animation index to select animation data. Stores playback flags at object +0x7C and floor(rate * 256) at +0x7E.

Required animation/model files are looked up and loaded if absent. The frame at object +0x28 is reset to zero for forward playback or clip length minus one for reverse playback.

Congo model parts use distinct spin clips numbered 12 through 17. Each index is local to the corresponding entity/model animation table.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Live task with valid object and entity/model ID. |
| `animation` | `unsigned int` | Animation index within this model, not a global animation ID. |
| `rate` | `float` | Playback rate converted to fixed-point storage by multiplying by 256. |
| `flags` | `unsigned int` | Low byte initializes model playback flags; observed 0 for nonlooping Congo parts. |

## Usage example

```c
extern void func_8021664C_5D1B1C(void *, unsigned int, float, unsigned int);

/* part must be one of Congo's validated six native model tasks. */
void restart_congo_part_clip(void *part, unsigned int part_index)
{
    if (!part || part_index >= 6) return;
    func_8021664C_5D1B1C(part, 12 + part_index, 0.05f, 0);
}
```

Restart the appropriate spin clip for one of the six Congo model tasks. The caller must establish the correct part identity and a valid loaded model.

## Notes

- An animation index from one model is not valid for arbitrary actors.
- This call restarts the clip and can load resources. Use func_80216AB8_5D1F88 to advance an already selected animation.
