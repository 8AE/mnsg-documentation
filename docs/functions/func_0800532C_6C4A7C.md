`func_0800532C_6C4A7C` · **Function**

Starts the Moon acquisition scenario and its native player-control ownership.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x0800532C` | `0x006C4A7C` | `.file_30` |

Native code size: **120 bytes**.

## Signature

```c
extern void func_0800532C_6C4A7C(void *task, void *object);
```

## How it works

The idle reward selects this callback when pickup begins. Native callback selection writes task +0xC immediately; execution occurs on its scheduled actor update.

Starts scenario 0x71 and acquires the native pickup control state. That scenario writes 1 to the signed 32-bit Miracle Moon inventory field at save +0x254 before its final scene completion.

The later completion callback waits for the scenario to end, releases pickup control and records saved flag 0x0A4.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Initialized native Miracle Moon reward task. |
| `object` | `void *` | The reward task’s native display object. |

## Return value

No return value.

## Usage example

```c
#include "modding.h"

static unsigned int moon_pickup_starts;

RECOMP_HOOK("func_0800532C_6C4A7C")
void observe_moon_pickup(void *task, void *object)
{
    if (!task || !object ||
        *(const unsigned short *)((const char *)task + 0x5E) != 0x350u)
        return;
    ++moon_pickup_starts;
    /* Leave the native scenario and control ownership intact. */
}
```

Observe the exact native pickup entry without replacing the scenario or changing its player-control state.

## Notes

- Preserve an already selected pickup callback, even before its entry hook executes.
- Do not remove the active reward or set completion flag 0x0A4 while its local scenario still owns player control.
- Do not invoke this callback on an idle task merely to grant inventory.
