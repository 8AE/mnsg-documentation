`func_800102E0_10EE0` · **Function**

Clears a registered texture descriptor by its runtime handle.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x800102E0` | `0x00010EE0` | `.main` |

Native code size: **56 bytes**.

## Signature

```c
extern void func_800102E0_10EE0(int handle);
```

## How it works

The routine clears the texture-descriptor entry selected by the supplied handle.

The stock overlay invokes this cleanup for each handle it previously registered. The registry contains 40 descriptor slots.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `handle` | `int` | Runtime handle returned by texture-descriptor registration. |

## Return value

No return value is used by the inspected native caller; whether the routine returns an ignored value is unconfirmed.

## Usage example

```c
extern void func_800102E0_10EE0(int handle);

void release_image(int handle)
{
    func_800102E0_10EE0(handle);
}
```

Release a descriptor using the handle saved when the image was registered.

## Notes

- Pass a handle returned for a live registration. The routine does not establish ownership or lifetime for the caller's pixel memory.
