`func_80219448_5D4918` · **Function**

Updates the seeded ellipse phase and writes planar velocity for the common actor integration step.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80219448` | `0x005D4918` | `.file_12` |

## Signature

```c
extern void func_80219448_5D4918(void *task);
```

## How it works

Advances the unsigned 10-bit phase at task +0xD0 by the signed-byte step at +0xD6, then computes the ellipse point from unsigned radii +0xD4/+0xD5 and rotation +0xD2.

Stores the new planar point in +0xD8/+0xDC and writes X/Z velocities to +0x78/+0x80 as half the point delta. The normal common integration applies twice those velocities.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Live native task with the expected initialized fields. |

## Return value

No return value.

## Usage example

```c
#include "modding.h"
extern void func_80219448_5D4918(void *task);

void advance_seeded_orbit(void *task)
{
    if (task) func_80219448_5D4918(task);
}
```

The example shows the verified native call shape. Use it only at a lifecycle point where the documented task and state are valid.

## Notes

- The task must have valid orbit phase, angle, radii, signed step, rotation and prior-point fields. Calling this helper does not seed them or run actor collision, damage or scheduler callbacks.
