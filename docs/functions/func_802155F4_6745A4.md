`func_802155F4_6745A4` · **Function**

Creates the dungeon pause-map floor panel, floor labels and the local character head.

## How it works

The file_17 constructor creates a child task whose update callback is func_80215198_674148 and finalizer is func_80215474_674424. Allocation failure returns null after cleanup.

The character, dungeon index and actual floor are stack arguments at entry offsets 0x1C, 0x20 and 0x24. Arguments at 0x10 through 0x18 are unused by the inspected implementation.

Task words +0x90, +0x94 and +0x98 hold dungeon index, selected floor and floor count. The selected floor can change independently of the local character head.

The local head is a kind-2 display record using model 0x48000040 + character*0xE0, animation 0xA0216AE0, file 0x04D1, scale 3.0 and rotation sentinels 0x8000. Its layer is the panel layer plus two.

The head uses relative screen X 53 and Y 53 + (112/(floor_count+1))*(floor_count-floor). Integer division occurs before multiplication. func_800115E0_121E0 writes the relative position into the record at +0x80/+0x84.

## Notes

- Only access this layout while its owning overlay and task are active. Task-pool addresses can be reused after destruction.
- Keep display records owned by this task so native cleanup can reclaim them. Do not retain their pointers across panel creation.
