`func_80216AB8_5D1F88` · **Function**

Advances the animation frame of each object in an actor object chain.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80216AB8` | `0x005D1F88` | `.file_12` |

Native code size: **552 bytes**.

## Signature

```c
extern void func_80216AB8_5D1F88(void *task);
```

## How it works

Returns unless task flags at +0x60 contain mask 0x01. For each active object, changes frame +0x28 by the unsigned rate at +0x7E multiplied by 2/256, using the reverse direction when requested.

Playback flag mask 0x02 marks stopped/completed clips, 0x01 controls looping and 0x04 records a loop crossing. Nonlooping clips clamp at their endpoint.

## Parameters

| --- | --- | --- |
| `task` | `void *` | Native actor task with initialized model objects and animation state. |
