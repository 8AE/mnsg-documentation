`func_08000000_72B850` · **Function**

Allocates a native Mermaid training child and records File 69 resource identity for its scheduled callback.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x08000000` | `0x0072B850` | `.file_69` |

Native code size: **96 bytes**.

## Signature

```c
void *func_08000000_72B850(void *parent, void (*callback)(void *, void *), unsigned char priority);
```

## How it works

Forwards parent, callback and the low unsigned 8 bits of priority to the native task constructor.

On success, stores 0x0045 (File 69) at task halfword +0x28 and the resource handle returned for File 69 at task word +0x2C.

The verified root subsequently initializes the returned child object position. The child callback's own phase 0 performs its model, collision and gameplay initialization on the native schedule.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `parent` | `void *` | Live native parent task. The verified waterfall root is the parent of swimmers and obstacles. |
| `callback` | `void (*)(void *, void *)` | Resident native child callback. The verified root uses the swimming proxy callback or obstacle callback. |
| `priority` | `unsigned char` | Unsigned 8-bit priority forwarded to the native allocator. The root uses 2 for its swimmer and 5 for an obstacle. |

## Return value

New native task pointer, or null on allocation failure.

## Usage example

```c
typedef void (*NativeTaskCallback)(void *, void *);
typedef void *(*NativeChildConstructor)(void *, NativeTaskCallback, unsigned char);

extern void *func_08000000_72B850(void *parent, NativeTaskCallback callback, unsigned char priority);

/* Expose the verified interface without allocating a task. */
NativeChildConstructor documented_constructor(void)
{
    return func_08000000_72B850;
}
```

Shows the constructor's register-argument interface without duplicating a native child allocation or bypassing phase-0 initialization.

## Notes

- The returned task pointer and the opaque resource handle stored at +0x2C are different kinds of values. Do not dereference the resource handle as an actor pointer.
- Construction requires the matching native resource and parent lifecycle. A successful allocation is not proof that the child callback has finished initialization.
- The scheduled callback may be represented initially as a raw 0x08 address and later as the resident File 69 base plus offset after native callback preparation. Preserve the constructor and scheduler lifecycle rather than normalizing the field through a legacy segment resolver.
