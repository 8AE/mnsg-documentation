`func_0800126C_708CAC` · **Function**

Increments the byte phase at task +0xD0 by one.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x0800126C` | `0x00708CAC` | `.file_48` |

## Signature

```c
void func_0800126C_708CAC(void *task);
```

## How it works

Adds one to the byte at task +0xD0. The rising-target callback uses it for the local balloon phase when consuming result byte 4.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | The matching local minigame task with inline phase byte at +0xD0. |

## Return value

No meaningful return value.

## Usage example

```c
extern void func_0800126C_708CAC(void *task);
typedef void (*PhaseIncrement)(void *);

PhaseIncrement documented_phase_increment(void)
{
    return func_0800126C_708CAC;
}
```

Returns the helper address without advancing a live task.

## Notes

- The function changes lifecycle state. Do not call it repeatedly to reproduce a result event; the balloon pop path includes allocation and other native side effects.
