`func_801DC554_598464` · **Function**

Writes native material commands into a task-owned display list and invokes the native data-cache writeback routine.

## Interface

A complete callable prototype has not been established. Use the observation or callback-identity pattern in the example rather than guessing the native arguments.

## How it works

Writes a material call, primitive and environment color commands, and an end command to the material list.

Native effect callbacks can refresh task-owned material data during updates.

After writing, the routine calls osWritebackDCache with the material-list address and byte length. This records the native sequence; it does not establish whether a recompiled runtime requires an equivalent cache operation.
