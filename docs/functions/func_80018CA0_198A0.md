`func_80018CA0_198A0` · **Function**

Recursively renders model node geometry and linked child/sibling branches.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80018CA0` | `0x000198A0` | `.main` |

Native code size: **668 bytes**.

## Signature

```c
extern void func_80018CA0_198A0(const void *model_node, void *cache_record);
```

## How it works

Builds per-node transforms, resolves segmented nested model references, submits geometry and materials, and traverses relative +0x04/+0x05 node branches.

Traversal uses the native temporary matrix stack and final graphics-bank matrix/display-list cursors. Those graphics resources are distinct from CPU kind-2 cache records.

Native child/sibling cache lookup can allocate records during this render traversal.

## Notes

- Requires native segment/material context, valid acyclic model data, and sufficient matrix/display-list storage. Increasing CPU record capacity does not increase graphics-bank capacity.
