`func_08001CC4_6EAE14` · **Function**

Advances the platform yaw by two native angle units in its configured direction.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x08001CC4` | `0x006EAE14` | `.file_40` |

Native code size: **56 bytes**.

## Signature

```c
extern void func_08001CC4_6EAE14(void *task, void *object);
```

## How it works

Reads immutable task word+D0. Zero subtracts2 from yaw; nonzero adds2. The result is masked to0x3FF. The complete callback makes no calls.

All five placements are in room0x3F and use direction0 or1. Initial yaw is0 or0x200.

The constructor binds static slot0 of model0x366 with primary0x1EA, secondary0x168 and common0x152, command0x48000258 and uniform scale0.1. No animation clock drives the motion.

Both mechanism constructors set task flags+64 bit0x4000. The separately scheduled native common post owns support/contact behavior and moves only the local player whose support pointer names this object.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Initialized File40 entity 0x366 task. |
| `object` | `void *` | Native object pointer from task +0x18. |

## Return value

No return value.

## Usage example

```c
#include "modding.h"

static volatile unsigned short observed_value;

RECOMP_HOOK("func_08001CC4_6EAE14")
void observe_native_state(void *task, void *object)
{
    if (!object) return;
    observed_value = *(volatile unsigned short *)((char *)object + 0x16);
}
```

Samples yaw at the normal callback boundary; native motion and local contact remain scheduled once.

## Notes

- Use the full File40 ROM-qualified symbol and initialized resident resources. A static model still owns local command/resource pointers.
- Each invocation advances motion. Observation hooks must not call the continuation again or replay the constructor.
- Do not duplicate the common post or copy another player's support pointer.
