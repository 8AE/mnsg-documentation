`func_8021B610_5D6AE0` · **Function**

Runs the common actor’s fall-effect and below-world removal tests.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8021B610` | `0x005D6AE0` | `.file_12` |

## Signature

```c
extern int func_8021B610_5D6AE0(void *task);
```

## How it works

When task flags +0x60 bit 0x40000000 is set and vertical velocity +0x7C is above -3.0, attempts the native fall effect and sets removal-pending status bit 0x02 at +0x68.

When flags +0x60 bit 0x00000400 is set and the object Y coordinate at task object +0x0C is below -1000.0, writes status +0x68 to exactly 0x02 and returns 1. Otherwise it returns 0.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Live native task with the expected initialized fields. |

## Return value

Returns 1 when the below-world removal condition is met; otherwise returns 0. The fall-effect branch can independently set removal-pending status.

## Usage example

```c
#include "modding.h"
extern int func_8021B610_5D6AE0(void *task);

int check_actor_fall(void *task)
{
    if (!task) return 0;
    return func_8021B610_5D6AE0(task);
}
```

The example shows the verified native call shape. Use it only at a lifecycle point where the documented task and state are valid.

## Notes

- This helper is part of the native common actor finalizer. Its below-world branch overwrites status +0x68 with 0x02; do not call it a second time just to advance visual motion.
