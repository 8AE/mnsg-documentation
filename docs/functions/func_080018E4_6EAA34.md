## How it works

Adds4 to yaw halfword+0x16 and masks to0x3FF. Subtypes0/1 set X=originX+cos(phase)*radius; subtypes2/3 set Z=originZ+cos(phase)*radius. It then adds the signed low halfword of step to phase and masks to0x3FF.

Task words+D0/+D4/+D8 hold immutable subtype/radius/step. Floats+DC/+E0 hold initial X/Z. Unsigned halfword+E4 holds the travel phase. The constructor starts phase0 for subtypes0/2 and0x200 for1/3.

All seven placed tops use subtype/radius/step (2,160,1), (3,160,1), (0,130,2) or (0,80,4). The first two occur in room0x3E and the latter two in room0x3F.

The constructor binds static slot0 of model0x365 with primary0x1E9, secondary0x168 and common0x152, command0x48000348 and uniform scale0.1. No animation clock drives the motion.

The only called helper is native cosine. This continuation has no child allocation, player mutation, sound, reward or damage dispatch.

Both mechanism constructors set task flags+64 bit0x4000. The separately scheduled native common post owns support/contact behavior and moves only the local player whose support pointer names this object.
