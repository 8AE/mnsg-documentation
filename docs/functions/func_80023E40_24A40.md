`func_80023E40_24A40` · **Function**

Clears an event bit in the native transient event array.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80023E40` | `0x00024A40` | `.main` |

Native code size: **84 bytes**.

## Signature

```c
extern void func_80023E40_24A40(unsigned int event);
```

## How it works

For a valid nonnegative event ID, the byte index is (event / 8) & 0xFF and the bit index is event % 8. The bit is cleared in storage beginning at 0x80168E90.

Congo damage-threshold reactions use event 0x0B. This event array is distinct from the persistent save-flag array accessed by func_800240DC_24CDC.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `event` | `unsigned int` | Transient event identifier; Congo damage event is 0x0B. |

## Usage example

```c
extern void func_80023E40_24A40(unsigned int event);

/* After proving this damage threshold was consumed. */
void clear_consumed_congo_spin_event(void)
{
    func_80023E40_24A40(0x0B);
}
```

Clear the Congo damage event only after the corresponding threshold reaction has been consumed. The event is transient and separate from persistent save flags.

## Notes

- Clear an event only when its consumer has handled it; clearing a pending reaction can suppress native behavior.
