`func_8021A978_5D5E48` · **Function**

When its task flags and object identity match the local carrier case, transforms a local-player-relative offset into traversal displacement.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8021A978` | `0x005D5E48` | `.file_12` |

Native code size: **360 bytes**.

## Signature

```c
extern void func_8021A978_5D5E48(void *task);
```

## How it works

Runs only when task flags +0x64 include bit 0x4000 and the task object pointer at +0x18 equals the local player task's object pointer at +0xA0.

Transforms the local player's position relative to the matching object and writes the resulting displacement to local player task fields +0xC0, +0xC4 and +0xC8.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Live task entry passed in the first argument register, with an initialized object pointer at +0x18. |

## Return value

No public return value is established; the verified helper body is a task-entry routine.

## Usage example

```c
#include "modding.h"
extern void func_8021A978_5D5E48(void *task);

typedef void (*NativeTaskEntry)(void *);

NativeTaskEntry documented_carrier_helper(void)
{
    return func_8021A978_5D5E48;
}
```

Returns the verified task-entry identity without changing local player displacement. The native scheduler owns invocation.

## Notes

- This helper can change local traversal state. The native Ebisumaru actor families examined do not establish a carry role, and this behavior is conditional on matching the local player's object pointer.
- The entry is documented as a task helper; broader callable semantics and use outside the native scheduler lifecycle are not established.
