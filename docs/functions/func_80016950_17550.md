`func_80016950_17550` · **Function**

Resets the matrix cursor and lighting state for the selected native graphics bank.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80016950` | `0x00017550` | `.main` |

Native code size: **340 bytes**.

## Signature

```c
extern void func_80016950_17550(void);
```

## How it works

Selects one of the two graphics banks using the signed16 index D_800C7A72. Each bank starts at the full system pointer plus index × 0x1D6D8.

Sets D_80168504 to that bank’s matrix region and clears D_801684F8 and D_801684FC to zero.

This is the native bank-initialization boundary. Graphics submission toggles the selected bank; world-frame parity does not identify bank ownership when submission is skipped.

## Usage example

```c
extern void func_80016950_17550(void);

#include "modding.h"

RECOMP_HOOK_RETURN("func_80016950_17550")
void after_native_graphics_bank_init(void) {
    /* Native cursors and lighting state now belong to the selected bank. */
}
```

The example illustrates the native interface and its required state.

## Notes

- Do not call this to reclaim buffers while rendering or submitted work still owns them.
- Resetting a cursor does not enlarge either graphics command or matrix storage.
