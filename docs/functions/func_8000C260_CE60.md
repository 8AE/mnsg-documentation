`func_8000C260_CE60` · **Function**

Allocates one message-window slot and configures its position, style and animation.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8000C260` | `0x0000CE60` | `.main` |

Native code size: **180 bytes**.

## Signature

```c
extern void func_8000C260_CE60(int slot, int x, int y, int target_x, int target_y, int style, int animation);
```

## How it works

Creates a 0x1818-byte native window allocation and stores its pointer in the selected entry of D_80167C48_168848. The three established slots are 0 through 2.

Style definitions come from the initialized table referenced by D_80167C54_168854. The ordinary US save sign uses slot 0, position and target (24,24), style 8 and animation 0.

The function has no success return. Inspect the selected window pointer after the call. Native choice parsing assumes the window exists and can dereference null if allocation failed.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `slot` | `int` | Validated native window slot, 0 through 2. |
| `x, y` | `int` | Initial native screen position. |
| `target_x, target_y` | `int` | Native target screen position. |
| `style` | `int` | Resident window-style table index. Style 8 is used by the ordinary save sign. |
| `animation` | `int` | Native animation/configuration argument. The established stationary dialog call uses 0. |

## Return value

No return value; a nonnull selected slot is the allocation-success check.
