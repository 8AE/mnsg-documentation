`func_80034734_35334` · **Function**

Walks the native task hierarchy and executes each eligible task callback sequence.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80034734` | `0x00035334` | `.main` |

Native code size: **344 bytes**.

## Signature

```c
extern void func_80034734_35334(void);
```

## How it works

Starts at the root task list and updates D_8016DAB4_16E6B4 as it visits tasks. A live task carries its next pointer at +0x00, an unsigned 16-bit hierarchy depth at +0x20 and unsigned 16-bit execution flags at +0x22.

The execution gate tests task flags against the unsigned 16-bit system mask at full-system +0x3AE24, limited to the low three bits: (task_flags & system_mask & 7) != 0 skips the task. A skipped task also suppresses every following descendant whose depth is greater; iteration resumes at a peer or ancestor.

For an eligible task, the scheduler restores its resource context, then invokes non-null enabled callbacks at task +0x08, +0x0C and +0x10 in order. Each callback receives the current task and its object pointer from task +0x18. Callback addresses carrying bit 0x00800000 are inhibited.

The native Start pause sequence adds mask bit 0x0001 to suspend matching gameplay task subtrees. The separate unsigned 16-bit field at full-system +0x3AE26 selects the Start menu state machine; setting it is not a generic way to pause an unrelated dialog.

This function does not stop the game loop, input sampling, rendering, VI counter or frame counter. Systems outside its task hierarchy require their own pause policy.

## Return value

No return value.

## Usage example

```c
#include "modding.h"

extern unsigned char *D_8015C5C8_15D1C8;

/* Observe the scheduler mask without changing native ownership. */
static unsigned short last_task_mask;

RECOMP_HOOK("func_80034734_35334")
void observe_task_execution_mask(void)
{
    if (D_8015C5C8_15D1C8)
        last_task_mask = *(unsigned short *)(D_8015C5C8_15D1C8 + 0x3AE24);
}
```

The entry hook reads the established native mask while leaving task execution and ownership to the engine.

## Notes

- Do not recurse into this scheduler from one of its callbacks; it depends on a shared current-task global and mutable linked hierarchy.
- A pause mask can suppress entire subtrees, including a desired interface task. Verify the selected task flags and ancestor relationships before changing it.
- Restore only state owned by the caller. A replacement native pause or scene can change the same mask during a callback.
