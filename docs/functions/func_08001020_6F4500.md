`func_08001020_6F4500` · **Function**

Updates native doorway interaction and padlock-removal state.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x08001020` | `0x006F4500` | `.file_43` |

Native code size: **544 bytes**.

## Interface

A complete callable prototype has not been established. Use the observation or callback-identity pattern in the example rather than guessing the native arguments.

## How it works

The door stores its lock flag at +0xD4, interaction latch at +0xDA and state word at +0xEC. State bit 0x1 requests unlocking, 0x2 marks unlocked completion and 0x4 belongs to interaction state.

After key/save accounting is complete, an active padlock can be asked to run its native disappearance by clearing the interaction latch/bit and setting the unlocking bit. Keep the original parent callback so child completion and normal doorway interaction retain their native flow.

## Usage example

```c
#include "modding.h"
#include "recomputils.h"

extern unsigned short D_800C7AB2;
extern unsigned char D_8015C608_15D208[];

static unsigned short observed_room;
static unsigned short observed_lock = 0xFFFFu;
static unsigned int previous_state = 0xFFFFFFFFu;

/* Select a known room and its exact native LOCK flag before observing. */
void observe_door(unsigned short room, unsigned short lock_flag) {
    observed_room = room;
    observed_lock = lock_flag;
    previous_state = 0xFFFFFFFFu;
}

RECOMP_HOOK("func_08001020_6F4500")
void before_locked_door_update(void *actor, void *unused) {
    (void)unused;
    if (!actor || observed_lock >= 0x1800u ||
        D_800C7AB2 != observed_room)
        return;

    /* This adjacent runtime field is positive while a save is loaded. */
    if (*(const signed int *)(D_8015C608_15D208 - 0x28) <= 0)
        return;

    /* This callback identifies the door class; room and lock flag identify
     * the selected door. Retain no actor pointer beyond its native update. */
    unsigned short lock_flag =
        *(const unsigned short *)((const char *)actor + 0xD4);
    if (lock_flag != observed_lock) return;

    unsigned int state =
        *(const unsigned int *)((const char *)actor + 0xEC);
    if (state != previous_state) {
        recomp_printf("Door lock 0x%X: unlocking=%u unlocked=%u\n",
                      (unsigned int)lock_flag, state & 1u, (state >> 1) & 1u);
        previous_state = state;
    }
    /* The original native callback continues with interaction/animation. */
}
```

Registers an entry hook using the observed two-pointer callback arguments. After observe_door selects a known room and lock flag, it logs state changes only for that initialized door while a save is loaded. The original native callback retains control of interaction, padlock animation and cleanup.

## Notes

- The lock save bit and key accounting must already be applied exactly once before the live animation.
- Leave the parent callback intact so the update does not pull the local player through the doorway.
- Only use this layout for the native door actor matched by this callback.
