`func_801CBAF8_587A08` · **Function**

Native player post-update callback that runs collision, contact handling and final transform maintenance.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x801CBAF8` | `0x00587A08` | `.file_11` |

Native code size: **240 bytes**.

## Signature

```c
extern void func_801CBAF8_587A08(void *player_task, void *render_object);
```

## How it works

When player work +0x69 is zero, first runs the normal player update helper at 0x801DABDC.

If (D_800C7AE0 & 3) is zero, calls the native world collision handler, resolves a pending rotation value, updates collision-dependent movement state, and handles player contacts. Either low control bit skips this block.

After the gated block, refreshes the player transform and associated state, clears task +0x34/+0x38 contact pointers, and advances selected input-history fields.

A return hook observes position after the native collision block for this scheduler update, while an entry hook observes the proposed position before it.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `player_task` | `void *` | Live, fully initialized playable-player task supplied by the native scheduler. |
| `render_object` | `void *` | Second native callback argument. The inspected implementation saves it but does not use it to drive its collision calls. |

## Return value

No return value.

## Usage example

```c
#include "modding.h"

extern void *D_801FC604_5B8514;
static float observed_player_x;

RECOMP_HOOK_RETURN("func_801CBAF8_587A08")
void observe_player_after_collision(void)
{
    const unsigned char *task = D_801FC604_5B8514;
    if (!task) return;
    const unsigned char *object = *(const unsigned char *const *)(task + 0x18);
    if (!object) return;
    observed_player_x = *(const float *)(object + 0x08);
}
```

The return hook reads the current player position after native processing. It leaves the original callback and its stateful behavior in control.

## Notes

- This is a playable-player callback. It expects initialized player work, animation, camera and contact state and must not be applied to a standalone visual actor.
- The function has native stateful side effects even when its collision block is skipped. A second direct call does not provide an isolated collision query.
- The low-bit gate does not cover every scripted movement path; D_800C7AE3 tracks separately supplied scripted player input.
