`func_800105AC_111AC` · **Function**

Marks the end of a native sprite queue's pending display records.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x800105AC` | `0x000111AC` | `.main` |

Native code size: **260 bytes**.

## Signature

```c
extern void func_800105AC_111AC(int queue);
```

## How it works

Writes the native 0x8000 end marker after the queue's pending records so the display consumer can stop at the end of the list.

Finalization does not free the queue buffer; call the queue cleanup routine when its lifetime ends.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `queue` | `int` | Queue index returned by native sprite-queue creation. |

## Return value

No return value is used by the inspected native caller; whether the routine returns an ignored value is unconfirmed.

## Usage example

```c
extern void func_800105AC_111AC(int queue);

void finish_sprite_pass(int queue)
{
    func_800105AC_111AC(queue);
}
```

Close the current record list after all desired sprites have been appended.

## Notes

- Finalize after appending the records for the current collection pass.
