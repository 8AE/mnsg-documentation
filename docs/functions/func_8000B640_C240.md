`func_8000B640_C240` · **Function**

Initializes native save memory for a new adventure.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8000B640` | `0x0000C240` | `.main` |

Native code size: **160 bytes**.

## Signature

```c
extern void func_8000B640_C240(void);
```

## How it works

Clears 0x304 bytes at D_8015C608, seeds default control/stat/item/recruitment fields, chooses room 0x1D1 (Goemon house), writes its initial spawn values and mirrors the block into backup storage.

A return hook can adjust validated new-adventure defaults before later activation/mirroring. Calling this routine on an existing live save resets that in-memory progress.

## Return value

No return value in the established declaration.

## Usage example

```c
extern void func_8000B640_C240(void);

#include "modding.h"

RECOMP_HOOK_RETURN("func_8000B640_C240")
void after_fresh_save(void) {
    /* Apply selected new-game defaults before save mirroring. */
}
```

## Notes

- Calling the initializer resets save memory; do not use it to edit an already loaded adventure.
