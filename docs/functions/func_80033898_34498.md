`func_80033898_34498` · **Function**

Applies the native three-axis rotation transform to caller-owned X/Y/Z floats.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80033898` | `0x00034498` | `.main` |

Native code size: **420 bytes**.

## Signature

```c
extern void func_80033898_34498(unsigned short rx, unsigned short ry, unsigned short rz, float *x, float *y, float *z);
```

## How it works

Receives three unsigned 16-bit angle values followed by three writable float pointers. The vector is updated in place; there is no return value.

Native contact code masks object rotation halfwords to 0x03FF before this call. A full turn spans 1024 angle units.

This helper rotates only. Callers separately apply component scale before rotation and translation afterward.

## Usage example

```c
extern void func_80033898_34498(unsigned short rx, unsigned short ry, unsigned short rz, float *x, float *y, float *z);

void rotate_object_offset(const void *render_object, float *x, float *y, float *z)
{
    const unsigned char *object = render_object;
    if (!object || !x || !y || !z) return;
    func_80033898_34498(*(const unsigned short *)(object + 0x14) & 0x03FF,
                       *(const unsigned short *)(object + 0x16) & 0x03FF,
                       *(const unsigned short *)(object + 0x18) & 0x03FF, x, y, z);
}
```

The example illustrates the native interface and its required state.

## Notes

- The three float pointers must be valid writable storage. Do not pass task fields in place unless modifying that native state is intended.
- This is the forward rotation used for attacker-local offsets. Victim-space conversion uses a different inverse helper.
