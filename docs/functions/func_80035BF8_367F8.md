`func_80035BF8_367F8` · **Function**

Rebuilds the stock kind-2 free list and resets its active count.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80035BF8` | `0x000367F8` | `.main` |

Native code size: **132 bytes**.

## Signature

```c
extern void func_80035BF8_367F8(void);
```

## How it works

Links exactly 192 records of stride 0x98 in native system storage, terminates the final next pointer, and sets the signed 16-bit kind-2 active counter to zero.

This replaces the free head at D_8016DAC0[2]. It does not discover separately allocated storage and does not copy the record reset template; native template initialization is a separate operation.

## Usage example

```c
extern void func_80035BF8_367F8(void);

#include "modding.h"

RECOMP_HOOK_RETURN("func_80035BF8_367F8")
void after_kind2_list_reset(void) {
    /* The stock free head and active count have been replaced. */
}
```

The example illustrates the native interface and its required state.

## Notes

- A lifecycle reset invalidates outstanding record ownership. It is not a routine way to free a live model.
