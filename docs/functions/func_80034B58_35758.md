`func_80034B58_35758` · **Function**

Pops a native task record and inserts it into an existing task list.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80034B58` | `0x00035758` | `.main` |

Native code size: **244 bytes**.

## Signature

```c
typedef void (*NativeChildTaskUpdate)(void *task, void *object);
extern void *func_80034B58_35758(void *parent, NativeChildTaskUpdate update, unsigned short flags);
```

## How it works

Returns null when the task free head is empty. Otherwise increments the unsigned 16-bit active count, pops a free record, and resets it through func_80034A10.

Inserts the task after the parent list word, assigns a backlink at +0x04, sets depth +0x20 to parent depth plus one, installs update at +0x0C and flags at +0x28, and captures native resource context.

The higher-level func_80034E08 additionally applies native depth-order placement after this allocation.

## Return value

New linked task, or null when no free record is available.

## Usage example

```c
typedef void (*NativeChildTaskUpdate)(void *task, void *object);
extern void *func_80034B58_35758(void *parent, NativeChildTaskUpdate update, unsigned short flags);

void *new_child(void *parent, NativeChildTaskUpdate update) {
    if (!parent || !update) return 0;
    return func_80034B58_35758(parent, update, 0);
}
```

The example illustrates the native interface and its required state.

## Notes

- The parent must be a live native list owner. This function does not initialize an actor-specific work layout or allocate a display object.
