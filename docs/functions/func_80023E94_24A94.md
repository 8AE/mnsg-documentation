`func_80023E94_24A94` · **Function**

Returns the masked bit for an event in the immediate transient-event bank.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80023E94` | `0x00024A94` | `.main` |

Native code size: **80 bytes**.

## Signature

```c
extern int func_80023E94_24A94(int event_id);
```

## How it works

Reads the immediate byte-backed event bank also used by func_80023DF0_249F0 and func_80023E40_24A40.

Event 0x0B occupies bit 0x08 in the second byte. Native camera code tests the raw return for zero before entering or leaving the Congo shake callback.

Congo health processing may set event 0x0B repeatedly while HP is exactly 25, 20, 15, 10 or 5. Other event consumers can clear it, so a current bank read can differ from an HP-based inference.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `event_id` | `int` | Immediate event identifier, distinct from a saved progress-flag ID. Congo camera shake reads event 0x0B. |

## Return value

The stored masked bit, not a normalized Boolean. Event 0x0B returns zero or 0x08; compare the result with zero.

## Usage example

```c
extern int func_80023E94_24A94(int event_id);

int congo_camera_shake_event_is_set(void)
{
    return func_80023E94_24A94(0x0B) != 0;
}
```

Normalize the raw event mask at the read boundary. This queries the live event without changing it or deriving it from health.

## Notes

- Use result != 0 rather than result == 1. A set event can return a different power-of-two mask.
- This bank is transient and has separate set/clear functions. Do not substitute saved progress-flag readers or infer its lifetime from boss HP.
