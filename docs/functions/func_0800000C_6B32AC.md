`func_0800000C_6B32AC` · **Function**

Runs Congo root post-processing, including damage recovery and health transitions.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x0800000C` | `0x006B32AC` | `.file_29` |

Native code size: **892 bytes**.

## Signature

```c
extern void func_0800000C_6B32AC(void *task, void *object);
```

## How it works

Congo root initialization installs this callback in task +0x10. The root has entity ID 0x323 and starts at 30 HP; its six animated model-part tasks are separate actors.

Calls the common contact/damage path func_80218E7C_5D434C, then the health-threshold controller func_0800A228_6BD4C8. Replaying this post can therefore repeat health, sound and transition bookkeeping.

Root fields include unsigned-byte HP at +0x8D, unsigned-byte recovery/flicker timer at +0x8C, unsigned-halfword AI timer at +0x8A, and a float hit-sound cooldown at +0xDC. Model yaw is the unsigned halfword at object +0x16.

The recovery branch depends on status bit 0x1 at task +0x68. Victim-contact pointer +0x38 is cleared only inside that branch; removing its trigger can also skip that cleanup.

The six model parts carry their root pointer at task +0xDC and their animation frame as a float at object +0x28. This differs from the root float at task +0xDC; the same byte offset is not a common actor-field type.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Live native root task; Congo is entity 0x323 at unsigned halfword +0x5E. |
| `object` | `void *` | The root model/object supplied by the scheduler; this post consumes both native callback arguments. |

## Return value

No return value is used by the documented task-callback convention.

## Usage example

```c

{
    if (!task || !object) return;
    if (*(volatile unsigned short *)((char *)task + 0x5E) != 0x323u) return;
    observed_congo_health = *(volatile unsigned char *)((char *)task + 0x8D);
```

Observe a live root at its native post entry. Both scheduler callback arguments are preserved and the original routine continues; no extra post invocation is introduced.

## Notes

- Use the health-bearing root when reading HP. The six model parts do not own the boss health field.
- Preserve native contact ownership: victim pointer +0x38 and attacker pointer +0x34 have different roles. Suppressing recovery processing does not automatically consume the pending victim contact.
- A constructor can enqueue children that initialize on a later scheduler pass. Its return does not prove that all six model parts exist.
- Re-entering this post can repeat damage or state bookkeeping.
- Resolve the full ROM-qualified overlay symbol; a shared 0x080... address alone does not identify the loaded routine.
- Use a live task of the documented family. Task pointers and callback slots follow the 32-bit target ABI.
