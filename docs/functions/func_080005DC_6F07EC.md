`func_080005DC_6F07EC` · **Function**

Draws the HUD countdown from signed remaining-frame state, then decrements that state once per eligible native task update.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x080005DC` | `0x006F07EC` | `.file_42` |

## Signature

```c
void func_080005DC_6F07EC(void *hud_task, void *object);
```

## How it works

Reads the signed 32-bit remaining-frame word at HUD task +0x80, converts it to whole seconds by signed division by 30, and draws that number before changing the timer.

After drawing, decrements the raw frame word by one. A negative result is clamped to zero.

The callback has no challenge-phase or result-state test. Its countdown pauses when the native task is not admitted to an update; it is invoked once per eligible task pass, before the main loop camera processing.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `hud_task` | `void *` | Live HUD task whose signed timer word is stored at +0x80. |
| `object` | `void *` | Scheduler-supplied HUD object; this callback body does not use it. |

## Return value

No return value.

## Usage example

```c
#include <stdint.h>

extern void func_080005DC_6F07EC(void *, void *);
typedef void (*NativeTaskCallback)(void *, void *);

/* Observe the callback identity; the native scheduler owns invocation. */
NativeTaskCallback documented_timer_hud_callback(void)
{
    return func_080005DC_6F07EC;
}
```

Returns the verified scheduled callback identity without advancing the countdown.

## Notes

- This is a scheduled stateful callback, not a read-only timer query. Let the native task scheduler control its cadence and pause admission.
- The pause-mask bit combination is not fully decoded by this record; do not infer every pause reason from the observed task skip test.
