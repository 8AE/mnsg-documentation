`func_801F11F0_5AD100` · **Function**

Creates the native visual children used for the Mini Ebisumaru and Yae Mermaid transformation effect.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x801F11F0` | `0x005AD100` | `.file_11` |

Native code size: **448 bytes**.

## Signature

```c
void func_801F11F0_5AD100(void *effect_manager, uint8_t selector);
```

## How it works

Selector 0x22 creates four visual child effects.

The corresponding child callback is func_801F14BC_5AD3CC.

Stores the selector as an eight-bit task kind at task +0x64; child state byte +0x65 starts at zero.

Each child object uses a task-local material list at child task +0xA4, passed to the renderer as (task +0xA4) | 0x60000000.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `effect_manager` | `void *` | Native effect manager that owns the allocated tasks. |
| `selector` | `uint8_t` | Effect selector; selector 0x22 creates four transformation children. |

## Return value

No value.

## Usage example

```c
#include <stdint.h>

extern void func_801F11F0_5AD100(void *effect_manager, uint8_t selector);

/* This native constructor owns task allocation and callback lifetime. */
```

The example illustrates the native interface and its required state.

## Notes

- The child appearance has not been verified in a live scene.
- The native initializer and visual children depend on the owner actor state.
- The constructor allocates native tasks and owns their callback lifetimes; its declaration is not a safe arbitrary-call interface.
- The RSP material list must resolve within original 8 MiB RDRAM. A valid CPU task outside that range does not prove its material bytes are GPU-readable.
