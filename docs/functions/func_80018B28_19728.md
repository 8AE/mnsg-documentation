`func_80018B28_19728` · **Function**

Sets up the root cache and traverses native child and sibling nodes.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80018B28` | `0x00019728` | `.main` |

Native code size: **376 bytes**.

## Signature

```c
extern void func_80018B28_19728(const void *model_node, void *context_argument, void *cache_record);
```

## How it works

When cache_record is null, allocates a kind-2 root, sets its parent +0x94 to null, and stores it in the current render object at +0x78.

Writes the root model key at +0x2C, submits nonzero model geometry, and resolves child/sibling caches through func_80018F3C and func_8001904C before recursive rendering. Removes stale child/sibling caches when the corresponding model-node index is zero.

The second argument is saved but not consumed in the inspected implementation. The current object comes from D_801684A0.

The stock initial allocation is dereferenced without a null check. The apparent replacement branch at 80018B68 is unreachable: a boolean 0/1 value is ANDed with 0x8FFFFFFE.

## Notes

- Requires a valid native render context and bound model segments. It is not safe to call from arbitrary gameplay code.
- A null cache may require many subsequent child/sibling allocations; reserving one root record is insufficient.
