`func_80030730_31330` · **Function**

Computes horizontal wall separation at two heights against registered dynamic collision geometry.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80030730` | `0x00031330` | `.main` |

Native code size: **7032 bytes**.

## Signature

```c
extern void *func_80030730_31330(
    void *out, float x, float low_y, float high_y, float z, float radius);
```

## How it works

Samples twelve horizontal directions at each of two elevations, for 24 radial collision queries against registered dynamic geometry. It passes radius +2 to its ray helper, which adds another 2 world units before invoking the dynamic nearest-hit scan.

Accepts hits whose squared distance is at most radius squared and whose surface-normal Y component is less than 0.5. It preserves nearest-hit metadata and accumulates horizontal corrections from opposing directions.

On a hit, floats at output +0x18 and +0x20 contain the X/Z correction to add to the queried center. The float at +0x1C is set to 0. These output fields are body corrections, unlike the point displacement returned by a single ray query.

The normal remains at +0x24/+0x28/+0x2C and the hit field at +0x38. The function copies the full 0x48-byte record to out.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `out` | `void *` | Writable, four-byte-aligned storage for the complete 0x48-byte collision record. |
| `x, z` | `float` | World-space horizontal center of the body. |
| `low_y, high_y` | `float` | Two absolute world-space elevations at which to sample radial wall clearance. |
| `radius` | `float` | Positive horizontal clearance radius. |

## Return value

Returns the out pointer. Read the unsigned 16-bit hit field at out +0x38; 0x7FFF indicates a correction and 0 indicates none.

## Usage example

```c
#include <stdint.h>

typedef struct NativeWallCorrection {
    float query_prefix[6];
    float delta[3];
    float normal[3];
    uint8_t opaque_30[8];
    uint16_t hit;
    uint16_t opaque_3a;
    float distance_squared;
    void *dynamic_object;
    void *dynamic_task;
} NativeWallCorrection;

_Static_assert(sizeof(void *) == 4, "Native pointers require MIPS32");
_Static_assert(sizeof(NativeWallCorrection) == 0x48, "Native query layout");

extern void *func_80030730_31330(
    void *out, float x, float low_y, float high_y, float z, float radius);

/* Call only with valid scene resources and caller-selected dimensions. */
int correct_wall_position(float *x, float *z,
                          float low_y, float high_y, float radius)
{
    NativeWallCorrection result = {0};
    if (!x || !z || radius <= 0.0f) return 0;
    func_80030730_31330(&result, *x, low_y, high_y, *z, radius);
    if (result.hit != 0x7FFFu) return 0;
    *x += result.delta[0];
    *z += result.delta[2];
    return 1;
}
```

The example preserves the MIPS32 output size and checks the native hit field before applying the horizontal correction.

## Notes

- Its dynamic ray helper uses the same nearest squared-distance threshold of 2000 as the combined world ray query. At large world-space radii, collision hits farther than approximately 44.72 units from a sample origin can be omitted; a larger radius alone does not remove that native limit.
- Only use while the active scene collision resources are loaded. Dynamic collision lists and pointers are native scene-owned state.
- On a miss, only the hit state is established; other record contents can be uninitialized. Do not read or apply correction fields unless hit is 0x7FFF.
- The query measures clearance at the supplied center and two elevations. It does not sweep the full path between previous and target positions, so fast movement still needs a path constraint.
