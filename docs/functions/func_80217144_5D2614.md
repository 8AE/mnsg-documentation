`func_80217144_5D2614` · **Function**

Writes a fixed initial image of attack, collision and actor scalar fields into an existing task.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80217144` | `0x005D2614` | `.file_12` |

Native code size: **100 bytes**.

## Signature

```c
void func_80217144_5D2614(void *task);
```

## How it works

Sets task word +0x48 to 0xFFFFFFFF, byte +0x4C to 1, and halfwords +0x4E/+0x50/+0x52 to 2/40/0.

Clears task words +0x34 and +0x38. Writes halfwords +0x3C/+0x3E/+0x40 as 100/160/0 and byte +0x44 as 0.

Writes bytes +0x98/+0x99/+0x9A/+0x9B as 10/5/5/0 and byte +0x8D as 1. The routine makes no calls.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Writable initialized task storage containing the native actor fields through +0x9B. |

## Return value

No return value.

## Usage example

```c
extern void func_80217144_5D2614(void *task);

/* Use only at an actor initialization boundary. */
void initialize_actor_scalars(void *task)
{
    if (task) func_80217144_5D2614(task);
}
```

This resets the documented fields on existing native task storage. Repeating it on a live actor can overwrite mutable collision state.

## Notes

- These are initial scalar values, not a complete actor constructor or a collision pass.
- Byte +0x4C is separate from the shape halfword at +0x4E. The cleared word at +0x38 does not establish contact-source identity for every actor callback.
