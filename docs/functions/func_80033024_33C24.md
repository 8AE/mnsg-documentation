`func_80033024_33C24` · **Function**

Decodes active native attack spheres and tests them against a selected victim-task group.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80033024` | `0x00033C24` | `.main` |

Native code size: **992 bytes**.

## Signature

```c
extern void func_80033024_33C24(void *attackers, void *victims);
```

## How it works

Walks linked tasks beginning at attackers, stopping when a subsequent task priority at +0x20 is no greater than the starting priority. The links therefore delimit the native task subtree.

Requires a kind-2 render object at task +0x18, a nonzero attack descriptor at +0x48, an empty incoming contact pointer at +0x38, and outgoing collision bit 0x02 at byte +0x30.

Descriptor 0xFFFFFFFF selects a fixed sphere: unsigned radius at task +0x4E, signed Y/Z offsets at +0x50/+0x52, and zero X offset. Other descriptors resolve through the render object segment bindings and interpolate the sphere data using object animation frame +0x28.

Before each call to func_80033404_34004, writes local sphere X/Y/Z/radius to D_80168F80_169B80 through D_80168F8C_169B8C. One task can supply several spheres, and the scene coordinator can visit the same sphere again for another victim group.

    scanning_player_attacks = 0;

The example illustrates the native interface and its required state.

## Notes

- Both list pointers must describe initialized live native task groups. The implementation reads starting priority before its null check.
- This is a stateful contact scan, not an isolated geometry query. Do not run it a second time merely to observe attacks.
- A descriptor or action ID alone does not establish an active hit. Observe the decoded sphere at its native call boundary and avoid counting repeated victim-group scans as new attacks.
