`func_8021A310_5D57E0` · **Function**

Assigns 0x8000 to all three rotation fields of a task object.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8021A310` | `0x005D57E0` | `.file_12` |

Native code size: **24 bytes**.

## Signature

```c
extern void func_8021A310_5D57E0(void *task);
```

## How it works

Loads the object pointer from task +0x18, then writes 16-bit values at object +0x14/+0x16/+0x18.

The native Ryo popup setup uses this orientation. This function alone does not establish a universal billboard or camera-facing interpretation for every renderer.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Task whose live object receives the orientation fields. |
