`func_8000B4A0_C0A0` · **Function**

Clears three resident player-control state bytes during a system reset.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8000B4A0` | `0x0000C0A0` | `.main` |

Native code size: **60 bytes**.

## Signature

```c
extern void func_8000B4A0_C0A0(void);
```

## How it works

Clears D_800C7AE3, D_800C7AE2 and D_800C7AE0 to zero.

This resident system routine resets the three bytes together. It is broader than releasing one conversation or interaction lock.

## Return value

No return value.

## Usage example

```c
#include "modding.h"

static volatile unsigned int control_resets;

RECOMP_HOOK("func_8000B4A0_C0A0")
void observe_control_reset(void)
{
    ++control_resets;
}
```

Observes the native system reset while leaving all three control-byte writes to the original routine.

## Notes

- Do not call this routine as a convenient unlock helper. It also clears other player-control and scripted-state bytes.
- Observe the native reset lifecycle rather than using one cleared byte as proof that a particular actor sequence completed.
