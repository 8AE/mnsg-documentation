`func_80215150_674100` · **Function**

Calculates a dungeon floor row Y coordinate using native integer spacing.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80215150` | `0x00674100` | `.file_17` |

Native code size: **72 bytes**.

## Signature

```c
extern int func_80215150_674100(int ordinal, int floor_count);
```

## How it works

Returns 37 + (112/(floor_count+1))*ordinal, with integer division. The top row has ordinal one.

For a zero-based gameplay floor, ordinal is floor_count-floor. The native character head adds 16 to this return value.

The five dungeon definitions contain 3, 4, 4, 4 and 2 floors, respectively.

## Usage example

```c
extern int func_80215150_674100(int ordinal, int floor_count);

int floor_head_y(int floor, int floor_count)
{
    if (floor_count < 1 || floor_count > 4 || floor < 0 || floor >= floor_count)
        return -1;
    return func_80215150_674100(floor_count - floor, floor_count) + 16;
}
```

The example illustrates the native interface and its required state.

## Notes

- The function belongs to file_17. A floor_count of -1 divides by zero.
