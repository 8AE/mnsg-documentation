`func_8021928C_5D475C` · **Function**

Performs the same current-player target-pointer copy as func_8021927C_5D474C.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8021928C` | `0x005D475C` | `.file_12` |

## Signature

```c
extern void func_8021928C_5D475C(void *task);
```

## How it works

Copies the pointer stored in D_8015CD60 to task +0x84.

It neither chooses among players nor transforms coordinates; a later call overwrites any different target pointer previously stored at +0x84.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Live native task with the expected initialized fields. |

## Return value

No return value.

## Usage example

```c
#include "modding.h"
extern void func_8021928C_5D475C(void *task);

void refresh_native_target(void *task)
{
    if (task) func_8021928C_5D475C(task);
}
```

The example shows the verified native call shape. Use it only at a lifecycle point where the documented task and state are valid.

## Notes

- Use only with a live task and a valid current-player object. The copied pointer is runtime state and must not be serialized.
