`func_8001136C_11F6C` · **Function**

Resolves a HUD position and updates its attached sprite and model records from their relative offsets.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8001136C` | `0x00011F6C` | `.main` |

Native code size: **332 bytes**.

## Signature

```c
void func_8001136C_11F6C(void *hud);
```

## How it works

Computes absolute HUD X and Y at task +0x6C and +0x70 from base coordinates +0x64 and +0x68. When a native parent is present, its position at +0x10 and +0x14 contributes to the result.

Walks the attached render-object chain from task +0x18 through each record +0x00. It updates the supported kind-1 sprite records and kind-2 model records.

For exact kind byte +0x04 equal to 2, reads signed relative offsets at object +0x80 and +0x84 and writes model X=(absoluteX+offsetX)*5/8-100+0.3, Y=65-(absoluteY+offsetY)*5/8+9.7 and Z=-200. The transform maps native HUD coordinates into its model rendering space.

The Mermaid training HUD invokes this after setting its local marker offsets. The function refreshes transforms without constructing display lists, drawing objects or decrementing the countdown.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `hud` | `void *` | Live native HUD task with compatible position fields and an intact attached render-object chain. |

## Return value

No return value.

## Usage example

```c
extern void func_8001136C_11F6C(void *hud);

/* The caller has validated the live native HUD and its attached list. */
void refresh_hud_layout(void *hud)
{
    if (hud) func_8001136C_11F6C(hud);
}
```

Refreshes the native HUD transforms after compatible relative offsets change, without running a gameplay or countdown callback.

## Notes

- The function expects a live compatible HUD and intact native links. It performs no public lifetime or ownership validation.
- It updates every attached compatible record. Do not call it on a generic actor task or a partially torn-down HUD.
