`func_80019160_19D60` · **Function**

Walks ancestor model caches looking for a matching recyclable subtree.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80019160` | `0x00019D60` | `.main` |

Native code size: **108 bytes**.

## Signature

```c
extern int func_80019160_19D60(void *record, unsigned int model_command);
```

## How it works

Walks parent links at +0x94. For an ancestor with a sibling cache at +0x74, searches for model_command and frees a matching subtree through the native cache reclamation path.

The caller passes the complete cache command key, including its model-type tag. Child and sibling cache constructors invoke this before requesting a new record.

## Return value

One when a matching cache was reclaimed, otherwise zero.

extern int func_80019160_19D60(void *record, unsigned int model_command);

## Notes

- record must be valid and nonnull. This mutates a live native cache tree and must run only in its renderer lifecycle.
