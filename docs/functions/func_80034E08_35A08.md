`func_80034E08_35A08` · **Function**

Creates and inserts a native scheduler task with an update callback.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80034E08` | `0x00035A08` | `.main` |

Native code size: **48 bytes**.

## Signature

```c
extern void *func_80034E08_35A08(void *task_list, void (*update)(void *, void *),
                                 unsigned short flags);
```

## How it works

Calls the task allocation helper, then adjusts the scheduler links through an insertion helper. The second helper returns the task pointer and assembly preserves that value in v0 through return.

The new task belongs under the supplied engine owner/list. Its update callback is independent of playable-character behavior; attaching a model object later creates visual state without creating player input or AI.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task_list` | `void *` | Engine task owner/list used for insertion. |
| `update` | `void (*)(void *, void *)` | Native scheduler-compatible update callback. |
| `flags` | `unsigned short` | Task flags; zero is the documented basic creation pattern. |

## Return value

Created/inserted task pointer, or null on allocation failure.

## Usage example

```c
extern void *func_80034E08_35A08(void *task_list, void (*update)(void *, void *),
                                 unsigned short flags);

static void model_update(void *task, void *object) {
    (void)task;
    (void)object;
}

void *make_model_task(void *owner) {
    if (!owner) return 0;
    return func_80034E08_35A08(owner, model_update, 0);
}
```

Complete C syntax example using the documented native declarations. Integrate it only at the described engine lifecycle boundary; the game supplies symbol definitions and resident resources.

## Notes

- Keep the owner valid and check allocation failure.
- A non-null pointer alone does not prove a retained task is still linked after pool reuse.
