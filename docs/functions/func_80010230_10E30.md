`func_80010230_10E30` · **Function**

Registers image metadata in the native texture-descriptor table and returns its runtime handle.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80010230` | `0x00010E30` | `.main` |

Native code size: **176 bytes**.

## Signature

```c
extern int func_80010230_10E30(unsigned short width, unsigned short height, unsigned char format, unsigned char flags, void *pixels, unsigned short palette);
```

## How it works

The native registry has 40 texture-descriptor slots. Registration records image dimensions, format and flags bytes, a pixel pointer, and a palette value.

The returned handle identifies a registered descriptor for native sprite commands. A handle is runtime state and is not a resource ID.

The format-byte and flags-byte encodings are not established by this interface description.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `width` | `unsigned short` | Image width supplied to the descriptor. |
| `height` | `unsigned short` | Image height supplied to the descriptor. |
| `format` | `unsigned char` | Format byte stored for the descriptor; individual values are not established here. |
| `flags` | `unsigned char` | Flags byte stored for the descriptor; individual bits are not established here. |
| `pixels` | `void *` | Pixel-data pointer recorded for the descriptor. |
| `palette` | `unsigned short` | Palette value supplied to the descriptor. |

## Return value

A runtime descriptor handle on success, or -1 when registration cannot allocate a descriptor.

## Usage example

```c
extern int func_80010230_10E30(unsigned short width, unsigned short height, unsigned char format, unsigned char flags, void *pixels, unsigned short palette);

int register_image(void *pixels)
{
    return func_80010230_10E30(64, 32, 0, 0, pixels, 0);
}
```

This example shows the native argument shape only. Format, flags, palette, and pixel-buffer requirements must match the image data and caller context.

## Notes

- Unregister descriptors with the matching handle when their owning image data or scene lifetime ends.
- A newly registered sprite's visibility during a scene's first introductory animation has not been tested.
