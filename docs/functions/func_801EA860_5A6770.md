## How it works

Creates six children using model 0x490024F0 and material 0xC006D920 at child offset +0xB8.

The effect uses segment 0x152. Texture setup calls func_801E8820_5A4730 with model slot 10 and an entry from D_80204A10.

The six children select texture resources in the order 0x802047A0, 0x802047E0, 0x802047E0, 0x802047A0, 0x802047E0, 0x802047A0.

Their grayscale values are 0xFF, 0x80, 0x90, 0xFF, 0xC0, and 0xFF in the same order.

For the character-switch smoke children, the constructor passes 0x8000 in all three object rotation halfwords.

This smoke model uses the 0x40000000 model branch, which builds a camera-facing alignment matrix from the active camera direction. This is a verified path for this smoke model, not a rule for every native renderer object.

The 0x8000 rotation values act as sentinels in this path; the renderer preserves them rather than reducing them to 10-bit angles.
