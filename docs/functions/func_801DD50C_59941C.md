`func_801DD50C_59941C` · **Function**

Searches recruited characters and performs a native player character cycle.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x801DD50C` | `0x0059941C` | `.file_11` |

Native code size: **180 bytes**.

## Signature

```c
extern int func_801DD50C_59941C(void *arg0);
```

## How it works

Starts with current character+1 and checks recruitment words beginning at save+0x94. Candidates greater than 3 are reset to zero by the native search. It makes a bounded search and keeps the current character when no candidate is found.

On selection, writes task+0x60 and global current character, marks the control mirror dirty, then invokes func_801DD5C0. The native search wrapping should not be replaced conceptually with a modulo loop: those are different implementations.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `arg0` | `void *` | Live player task. |

## Return value

0 after selecting a character, 1 when the bounded native search found none.

## Notes

- The native search resets out-of-range candidates to zero; do not assume a replacement modulo search has identical behavior.
- Only call on the actual live player task; selection changes global character state.
