`func_8022075C_5DBC2C` · **Function**

Tests a local NPC interaction and, when accepted, transfers the task into the native conversation sequence.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8022075C` | `0x005DBC2C` | `.file_12` |

Native code size: **208 bytes**.

## Signature

```c
extern int func_8022075C_5DBC2C(void *task, int value_x, int value_z);
```

## How it works

Calls the native local-contact acceptance helper first. A rejected contact returns zero without installing the conversation handoff.

On acceptance, stores the two integer arguments as floating-point conversation scalars, sets D_800C7AE2 to one, saves the task's current +0x0C callback at +0xB4, and clears velocity at +0x78, +0x7C and +0x80.

The accepted path also records the local facing value, configures the conversation animation, stores the next conversation continuation at task +0xBC, and schedules the native follow-up through the current-task scheduler.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Live NPC task participating in the local interaction. |
| `value_x` | `int` | Signed scalar converted to float and stored for the accepted conversation sequence. |
| `value_z` | `int` | Second signed scalar converted to float and stored for the accepted conversation sequence. |

## Return value

One when the native contact test accepts the interaction; zero otherwise.

## Usage example

```c
#include "modding.h"

static volatile unsigned short observed_entity;

RECOMP_HOOK("func_8022075C_5DBC2C")
void observe_alternate_npc_talk(void *task, int value_x, int value_z)
{
    (void)value_x;
    (void)value_z;
    if (task)
        observed_entity = *(volatile unsigned short *)((char *)task + 0x5C);
}
```

Observes the interaction attempt at entry and leaves acceptance, control ownership and callback installation to the original native routine.

## Notes

- This routine acquires client-local player control and stores live task pointers. Do not call it to reconstruct a remote NPC or a shared world checkpoint.
- A set D_800C7AE2 byte does not identify which native sequence owns the lock. Observe the accepted transition that acquired it before treating a later clear as its release.
- Use a live compatible NPC task in its scheduler slot. The saved callbacks and conversation fields are local pointers.
