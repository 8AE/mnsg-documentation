## How it works

The visible actor owns movement, attack state, animation and projectile spawning. This callback is its private task post at +0x10.

At entry, reads native flag 0x16C. While the flag is set, this post ORs bit 0 into the word at D_8015CC30_15D830 +0xD4 and takes its paused branch. After the flag clears, a root with a live object pointer clears that bit before ordinary movement and post-processing.

The common actor pre func_80218FE8_5D44B8 treats task +0x64 bit 0x2 as an exemption from the shared bit-0 gate. This lets the Dharumanyo root reach its private post and release the derived gate after flag 0x16C clears. The normal scheduler order remains pre, AI, then post.

The linked carrier uses func_08003F84_6CC194 for actual collision, damage, lives and death processing.

## Notes

- Visible-root state and carrier state have different responsibilities; neither task can substitute for the other.
- Treat D_8015CC30_15D830 +0xD4 bit 0 as derived runtime pause state. Do not clear it while native flag 0x16C remains set.
- Do not suppress this root's private post through the same pause gate or remove its task +0x64 bit-0x2 exemption; the post owns the native release path.
- Resolve the full ROM-qualified overlay symbol; a shared 0x080... address alone does not identify the loaded routine.
