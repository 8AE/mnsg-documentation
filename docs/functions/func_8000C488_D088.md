`func_8000C488_D088` · **Function**

Clears the current text effect so subsequently inserted glyphs use the default effect.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8000C488` | `0x0000D088` | `.main` |

Native code size: **64 bytes**.

## Signature

```c
extern void func_8000C488_D088(int slot);
```

## How it works

Clears the effect mask applied to glyphs inserted afterward. Glyph records already created retain the effect value copied when they were inserted.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `slot` | `int` | Allocated native message-window slot, 0 through 2. |

## Return value

No return value.

## Usage example

```c
extern void func_8000C488_D088(int slot);

void insert_steady_text_after_effect(int slot)
{
    func_8000C488_D088(slot);
    /* Subsequent glyph insertions use the default text effect. */
}
```

Clear the insertion effect before adding glyphs that should remain steady.

## Notes

- This affects subsequent glyph insertions only; it does not change window ownership or control gameplay input.
