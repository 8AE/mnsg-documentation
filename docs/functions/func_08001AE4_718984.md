`func_08001AE4_718984` · **Function**

Configures the native transition to room 0x01E1 and queues the common continuation used by the sweets minigame path.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x08001AE4` | `0x00718984` | `.file_57` |

Native code size: **96 bytes**.

## Signature

```c
void func_08001AE4_718984(void);
```

## How it works

Calls func_801FA420_5B6330 with room 0x01E1, arrival XYZ (0, 0, 0), camera value 0, setup value 0x50, and final option 0.

Queues scheduler callback 0x800354B4 after preparing the transition state.

The associated File 98 event scenarios are 0x017A and 0x017B. In the one-shot route, save flag 0x007D is cleared before this entry handler is queued.

## Return value

No return value.

## Usage example

```c
extern void func_08001AE4_718984(void);

/* Invoke only from the native event path that has prepared this transition. */
void enter_ebisumaru_sweets_minigame(void)
{
    func_08001AE4_718984();
}
```

This invokes the native entry handler. The handler configures the room request and queues the game's continuation callback.

## Notes

- The documented behavior is this native start sequence; it does not establish that a generic room transfer reproduces the transition state or scheduler continuation.
- Only the observed setup value 0x50 and final option 0 are documented for this route; the full meanings and valid ranges of those fields are not established.
