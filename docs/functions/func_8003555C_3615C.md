## How it works

Calls FUN_80034E98(owner, entry, 2, model_id), then passes the other setup values to FUN_80035964. The resulting native task handle is returned.

The room actor manager uses flags 0xC006D920, zero initial transform, uniform native scale and the actor metadata model ID. It then applies a room instance through func_80218A54_5D3F24.

The meanings of arg2, arg13 and arg14 are not established. Their observed room-spawn values are zero.

Calls the native task allocator with owner, entry, kind 2 and model ID. Then forwards remaining transform/render arguments to an initialization helper and returns the task handle.

Room actors subsequently use func_80218A54 to apply their instance definition and placement. The example demonstrates this first construction step; allocation alone does not finish actor initialization.

## Notes

- Preserve the mixed integer, short and float parameter ABI.
- Allocation is only one phase of room-actor setup. The wrapper contains no explicit null guard before configuration, so native allocator/setup failure behavior remains relevant.
- Several arguments retain unresolved source names; do not infer that the argument named flags is a generic bitmask just from its name.
- The imported signature uses int for x/y/z. Preserve that exact ABI until validated; a similar display-object API uses floats.
- A task allocation alone does not perform room actor initialization.
