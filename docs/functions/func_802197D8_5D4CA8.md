`func_802197D8_5D4CA8` · **Function**

Steps an actor yaw toward the position of the target object stored at task +0x84.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x802197D8` | `0x005D4CA8` | `.file_12` |

Native code size: **56 bytes**.

## Signature

```c
extern int func_802197D8_5D4CA8(void *task, int turn_step);
```

## How it works

Dereferences the target-object pointer at task +0x84 and reads its float X, Y and Z at object +0x08, +0x0C and +0x10. It forwards those values and turn_step to the coordinate-based turning routine.

The coordinate routine obtains the moving actor object from task +0x18 and computes direction from the X/Z difference. Yaw is the unsigned halfword at that object +0x16, wrapped with mask 0x3FF.

If the shortest angular difference is strictly smaller than twice turn_step, it snaps to the target angle and returns zero. Otherwise it takes a signed step of twice turn_step and returns 1 or 2 for its direction.

The Congo turn callback invokes this helper with turn_step 1 and uses its return value to decide when the next native state may begin.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Live actor task with its own model/object at +0x18 and a valid target object at +0x84. |
| `turn_step` | `int` | Native angular step parameter; the stepping amount is twice this value in the 0..1023 yaw space. Congo passes 1. |

## Return value

0 when the yaw is snapped to the target direction, 1 after a positive yaw step, or 2 after a negative yaw step. Congo checks zero before advancing its turn state.

## Usage example

```c
#include "modding.h"

extern int func_802197D8_5D4CA8(void *task, int turn_step);

/* Call from a live actor update with file_12 resident. */
int turn_actor_toward_current_target(void *task)
{
    if (!task) return -1;
    void *object = *(void **)((char *)task + 0x18);
    void *target = *(void **)((char *)task + 0x84);
    if (!object || !target) return -1;
    return func_802197D8_5D4CA8(task, 1);
}
```

Forward the native result while advancing a live actor toward its current target. The wrapper rejects null pointers; the caller remains responsible for their native lifetime and loaded resources.

## Notes

- Both task +0x18 and task +0x84 must identify initialized live objects. The native helper does not test either pointer for null before dereferencing it.
- Invoke only with the file_12 code and the actor resources resident, normally from the actor native update context. Calling again advances yaw again.
- The target field is an object pointer, not a player-task pointer. A temporary target substitution must have object-compatible float coordinates and stay valid for the entire call; do not replace unrelated global player pointers.
- Preserve the native return value in hooks and wrappers; treating this as a void helper loses the turn-completion signal.
