## Signature

## How it works

Writes the float at 0x8023A510 to object scale fields +0x1C/+0x20/+0x24, then calls FUN_80216CE0(task, object, mode).

For the native Ryo popup model, the setup sequence uses task flags 0x220, entity/model ID 0x2C4 and mode 2. Other mode meanings are not established here.

## Parameters

| --- | --- | --- |
| `task` | `void *` | Valid task with an object and initialized model/entity ID. |
| `mode` | `int` | Model-setup mode passed through to FUN_80216CE0; observed 2 for the popup. |
