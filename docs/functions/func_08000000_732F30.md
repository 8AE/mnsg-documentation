`func_08000000_732F30` · **Function**

Creates the controller that presents Tsurami’s Miracle Star and following story scene.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x08000000` | `0x00732F30` | `.file_73` |

Native code size: **144 bytes**.

## Signature

```c
extern void func_08000000_732F30(void *task, void *object);
```

## How it works

Checks packed save flag 0x040. When set, immediately destroys the current task and returns; an observer must not dereference that task after return.

Otherwise allocates a 0x34-byte controller state block, stores its pointer at task +0xD0, initializes its phase word to zero, and installs func_08000090_732FC0.

The controller belongs to room 0x0071, Tsurami’s Arena. Its reward is the Miracle Star at save +0x250. The Miracle Flower at +0x258 belongs to a different reward scene.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Native file 73 controller task. |
| `object` | `void *` | Native task display object supplied by the scheduler. |

## Return value

No return value.

## Usage example

```c
#include "modding.h"

static unsigned int reward_controller_starts;

RECOMP_HOOK("func_08000000_732F30")
void observe_tsurami_reward_constructor(void *task, void *object)
{
    (void)object;
    if (task)
        ++reward_controller_starts;
    /* Entry observation only: the native function may destroy this task. */
}
```

Observe constructor entry without retaining a pointer that the native saved-state branch can destroy.

## Notes

- Keep a living Tsurami encounter’s required reward controller available; a persistent progression bit is distinct from the lifetime of a local boss and its story actors.
- Do not directly call this constructor or treat task +0xD0 as inline storage.
