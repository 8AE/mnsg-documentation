`func_080002B4_7060A4` · **Function**

Draws the high-jump HUD and decrements its raw timer toward zero; the initial displayed 99 uses 3960 ticks at forty ticks per unit.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x080002B4` | `0x007060A4` | `.file_47` |

Native code size: **244 bytes**.

## Signature

```c
void func_080002B4_7060A4(void *task, void *object);
```

## How it works

The HUD task uses private sprite data beginning at +0x5C. Words +0x64 and +0x68 hold UI coordinates, +0x78 is the text buffer pointer, and +0x7C is the sprite handle.

Task word +0x80 is the raw timer. Initializing the displayed value to 99 produces raw 3960: forty raw ticks per displayed unit.

The draw callback performs a saturating timer decrement; zero does not wrap into a positive timer.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Live task initialized by the matching native constructor. |
| `object` | `void *` | The task's own native render or collision object, where this callback uses one. |

## Return value

No return value.

## Usage example

```c
extern void func_080002B4_7060A4(void *task, void *object);

typedef void (*NativeTaskCallback)(void *, void *);

/* Observe callback identity; the native scheduler owns execution. */
NativeTaskCallback documented_callback(void)
{
    return func_080002B4_7060A4;
}
```

This returns the callback address without executing initialization, moving a platform, or advancing the challenge. The callback requires the matching resident overlay and initialized native task graph.

## Notes

- This is a sprite task. World-actor interpretations of +0x68 or +0x74 must not be applied to this private HUD layout.
- Keep text buffers, sprite handles and screen coordinates in the local HUD lifecycle.
