Allocates a single kind-2 model/display pool record.

| Runtime address | ROM address | Section |

Native code size: **180 bytes**.

## Signature

```c
extern void *func_80036448_37048(void);
```

## How it works

Increments D_8016DAB0 and updates its peak before checking capacity. If D_8006D320 is present, recycles one existing record from that owner; otherwise checks the kind-2 capacity against D_8016DADC.

Finally pops kind 2 through func_80035D8C. The returned bare record still requires appropriate initialization, attachment and eventual native release.

## Return value

Kind-2 record pointer or null on failure.

## Notes

- This returns a bare pool record; it does not initialize a complete render object or attach it to your task.
- Telemetry is incremented even when allocation fails, so it is not identical to the active kind-2 counter.
