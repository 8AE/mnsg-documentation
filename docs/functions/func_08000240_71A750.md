## How it works

The opening camera starts with the RDP scissor rectangle (left 8, top 38)-(right 312, bottom 202). A later camera state reaches (8, 16)-(312, 224).

The main display routine func_80017D8C_1898C emits the RDP scissor from camera fields +0x48 through +0x4E.

The native kind-1 sprite path through func_800087C4_93C4, func_800086F0_92F0 and func_80008920_9520 does not replace the camera scissor rectangle.
