`func_080005A8_72BDF8` · **Function**

Reads the waterfall HUD's signed raw timer and returns integer seconds using division by 30.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x080005A8` | `0x0072BDF8` | `.file_69` |

Native code size: **24 bytes**.

## Signature

```c
int func_080005A8_72BDF8(void *hud_task);
```

## How it works

Reads HUD task +0x84 and performs signed integer division by 30. It does not mutate the timer.

The active waterfall controller uses a result of zero or less as its timeout condition. Positive raw values below 30 therefore already display as zero.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `hud_task` | `void *` | The matching live File 69 waterfall HUD task. |

## Return value

Signed integer result of the 32-bit timer at HUD +0x84 divided by 30.

## Usage example

```c
extern int func_080005A8_72BDF8(void *hud_task);

/* The caller supplies the currently live waterfall HUD. */
int waterfall_seconds_remaining(void *hud_task)
{
    return func_080005A8_72BDF8(hud_task);
}
```

Reads the same whole-second timer value used by the native controller, without advancing its state.

## Notes

- This helper performs no task/lifetime validation. A pointer to a player, obstacle or expired HUD does not satisfy its layout contract.
