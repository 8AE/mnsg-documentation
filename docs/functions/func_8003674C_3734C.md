`func_8003674C_3734C` · **Function**

Detaches and releases one cached model subtree.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8003674C` | `0x0003734C` | `.main` |

Native code size: **76 bytes**.

## Signature

```c
extern int func_8003674C_3734C(void *record);
```

## How it works

Detaches the tree rooted at record +0x78 by clearing that link, recursively returns its descendant cache records through the native kind-2 free path, then releases the detached root.

Native recursive cleanup has an internal 32-entry traversal stack; it is not an unbounded generic tree destructor. Record reset preserves each newly installed free-list link.

## Return value

One for an empty or successfully released subtree; zero if native recursive cleanup fails.

## Usage example

```c
extern int func_8003674C_3734C(void *record);

void release_detached_child_cache(void *record) {
    if (record) (void)func_8003674C_3734C(record);
}
```

The example illustrates the native interface and its required state.

## Notes

- record must remain live. Only release caches whose ownership and native lifecycle are known.
