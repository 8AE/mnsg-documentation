`func_8000C454_D054` · **Function**

Sets the native message-window text effect copied into subsequently inserted glyph records.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8000C454` | `0x0000D054` | `.main` |

Native code size: **52 bytes**.

## Signature

```c
extern void func_8000C454_D054(int slot);
```

## How it works

Enables the native blink effect for glyphs inserted afterward. The window renderer toggles the glyph title-hidden bit every two rendered frames.

The effect mask is copied into each glyph record at insertion time; changing the window effect does not retroactively mark existing glyphs.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `slot` | `int` | Allocated native message-window slot, 0 through 2. |

## Return value

No return value.

## Usage example

```c
extern void func_8000C454_D054(int slot);
extern void func_8000D060_DC60(int slot, unsigned int glyph);
extern void func_8000C488_D088(int slot);

void insert_blinking_a(int slot)
{
    func_8000C454_D054(slot);
    func_8000D060_DC60(slot, (unsigned int)('A' - 0x20));
    func_8000C488_D088(slot);
}
```

Enable the effect before inserting glyphs that should blink, then clear it before inserting steady text.

## Notes

- This changes text-effect state on the selected native window; it does not start the scenario interpreter or handle input.
