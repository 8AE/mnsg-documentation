`func_801F4C20_5B0B30` · **Function**

Services the native chain-pipe pull and transitions the real player to a supplied release action when the head completes or world contact stops travel.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x801F4C20` | `0x005B0B30` | `.file_11` |

Native code size: **372 bytes**.

## Signature

```c
extern void func_801F4C20_5B0B30(void *player, unsigned char release_action);
```

## How it works

Finds the owned category-2 chain helper through the playable task's native child manager and reads its phase. The ordinary ground action 0x73 calls this update with release action 0x74; airborne action 0x7A supplies 0x7B.

A missing chain clears stored movement and selects the release action. Head phase 3, nonzero player wall-contact halfword +0x96, or the native object world probe also ends the pull.

The completion path requests removal of the owned chain helper, clears signed 16-bit private work +0x30 and float work +0x04, clears the native movement fields and selects the supplied release action.

While pulling, it increments signed 16-bit work +0x30. On the first tick, when the prior value was zero, it obtains the owned chain head and calls func_801EA5E4_5A64F4 using the selected target pointer at private work +0x88.

The inspected update clears bit 0 of player byte +0x30 during this native action. It owns native collision and action state and is not a generic movement helper.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `player` | `void *` | Real playable task with complete private work and owned chain-manager state. |
| `release_action` | `unsigned char` | Native continuation action: 0x74 for ground pull or 0x7B for airborne pull. |

## Return value

No return value.

## Usage example

```c
#include "modding.h"

static unsigned char observed_release_action;

RECOMP_HOOK("func_801F4C20_5B0B30")
void observe_chain_pull(void *player, unsigned char release_action)
{
    (void)player;
    observed_release_action = release_action;
}
```

Observe the native continuation chosen by the existing ground or airborne action. The hook allows the original update, collision checks and action transition to run once.

## Notes

- Use only with the real playable owner and a fully initialized native pull. Replaying it on visual tasks can traverse invalid native managers and change gameplay state.
- On its first tick, the selected target at private work +0x88 must be valid unless the pull was already initialized and its first-tick counter was advanced consistently.
- Native movement uses stored heading and speed. Changing only the chain endpoint does not make the playable player steer toward a moving target.
- Do not run this updater twice for the same native action tick merely to force a release; retain its ordinary action and lifecycle ordering.
