`func_80218990_5D3E60` · **Function**

A task-entry helper that can restore actor position and velocity from native pre-physics state when an overlap flag is enabled.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80218990` | `0x005D3E60` | `.file_12` |

Native code size: **196 bytes**.

## Signature

```c
extern void func_80218990_5D3E60(void *task);
```

## How it works

Runs only when task flags +0x60 include bit 0x10000000. It compares planar distance from the task object to the local player against the squared radius formed from local-player scale X times 50 plus the actor byte at +0x99.

When the overlap test succeeds, restores the actor object's X/Y/Z and task X/Y/Z velocities from native pre-physics scratch values.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Live task entry passed in the first argument register, with an initialized object pointer at +0x18. |

## Return value

No public return value is established; the verified helper body is a task-entry routine.

## Usage example

```c
#include "modding.h"
extern void func_80218990_5D3E60(void *task);

typedef void (*NativeTaskEntry)(void *);

NativeTaskEntry documented_overlap_helper(void)
```

Returns the verified task-entry identity without running the local-player overlap test or restoring movement state.

## Notes

- The test uses local-player state and can roll back actor motion on one participant. The examined authored Ebisumaru actor flags do not set bit 0x10000000; this is not a reason to mask unrelated finalizer flags.
- The entry is documented as a task helper; broader callable semantics and use outside the native scheduler lifecycle are not established.
