## How it works

The zero-health branch of func_0800A228_6BD4C8 schedules this entry. It clears root recovery status bit 0x1 at task +0x68, sets root +0xE8 bit 0x80 and progress flag 0x12D, emits immediate events 1 through 5, sets unsigned-halfword timer +0x8A to 120, and schedules the native victory continuation.

Later callback func_0800820C_6BB4AC creates a white screen-fade controller. Its pointer is stored at full system +0x3B018; red, green and blue are controller bytes +0x0D, +0x0E and +0x0F, and opacity is controller byte +0x10. These fields belong to a separate render object, not the root task.

Callback func_08008280_6BB520 increases fade opacity by four per update until 255, then schedules func_080082F8_6BB598. Its audio cue 0x181 is emitted only when the pre-decrement root timer is zero.

Callback func_080082F8_6BB598 decreases opacity by five per update. At zero it releases the owned fade controller through the native object-removal path before scheduling the next callback.

Only after that release does func_0800833C_6BB5DC clear root capability word +0x60, set progress flags 0x12B and 0x12E, and clear the byte at D_8015C562_15D162. The final root callback is inert.

The camera has an independent continuation: it waits for progress flag 0x12E, waits 90 updates, closes the letterbox, and releases player control. That camera chain does not release the white screen-fade controller.

## Notes

- A later callback address, timer or progress flag does not represent all earlier side effects. Jumping over the fade-out callback can leave a live white overlay even after the root and camera otherwise reach their final states.
- Preserve the native continuation once victory begins. Re-entering the initial callback restarts its timer and emits its part events again; skipping ahead can bypass render-object cleanup.
- Root task +0xDC remains its float hit-sound cooldown. It is not the fade-controller opacity or an RGBA field.
- Clearing D_8015C562_15D162 or setting progress flag 0x12E does not substitute for releasing the fade controller.
- Do not call this callback manually to bypass Congo damage and teardown.
- Example shows the recovered call pattern hook boundary, not a full recovered native function prototype.
