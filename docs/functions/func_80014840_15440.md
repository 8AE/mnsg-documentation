`func_80014840_15440` · **Function**

Resolves a segmented address using a resident file without changing a task; a missing file can fault.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80014840` | `0x00015440` | `.main` |

Native code size: **128 bytes**.

## Signature

```c
void *func_80014840_15440(void *raw_address, uint32_t file_id);
```

## How it works

If the input address interpreted as signed 32 bits is zero or negative, returns it unchanged. This includes ordinary loaded KSEG0 addresses.

For a positive input, looks up the file through func_800141C4_14DC4, clears the stored resource-base tag 0x40000000, subtracts the file segment number shifted left by 24 from the input, and adds the loaded base.

Reads native resource state without rewriting task callbacks. Its native file-segment conversion is distinct from the recompiled scheduler's loaded callback mapping for raw 0x08000000–0x08FFFFFF actor-table addresses; do not use this function's result as the scheduler-loaded identity for that family.

For that verified raw callback family, the recompiled scheduler maps the callback with 32-bit unsigned arithmetic: loaded_callback = raw_callback - 0x08000000u + (resource_handle & 0xBFFFFFFFu). This fixed-base mapping is separate from the per-file segment subtraction performed here.

A registry lookup result of 0xFFFFFFFF enters an intentional native fault path. The resolver does not turn that condition into null.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `raw_address` | `void *` | Native 32-bit address to resolve. Addresses whose signed 32-bit interpretation is nonpositive pass through unchanged. |
| `file_id` | `uint32_t` | Native file ID supplying the resident resource base and segment number. |

## Return value

Resolved loaded address, or the input unchanged when its signed 32-bit value is nonpositive. Missing-file lookup is a fault path, not a normal failure return.

## Usage example

```c
#include <stdint.h>

extern void *func_800141C4_14DC4(unsigned int file_id);
extern void *func_80014840_15440(void *raw_address, uint32_t file_id);

/* raw_address is an untagged native address; file_id is validated. */
void *resolve_resident_address(void *raw_address, uint32_t file_id)
{
    if ((int32_t)(uintptr_t)raw_address <= 0)
        return raw_address;
    void *base = func_800141C4_14DC4(file_id);
    if (!base || base == (void *)(uintptr_t)UINT32_MAX)
        return 0;
    return func_80014840_15440(raw_address, file_id);
}
```

Preflights the dynamic registry before resolving a positive segmented address, while preserving the native pass-through for loaded or null addresses. It does not modify a task.

## Notes

- Before resolving a positive address, establish that the correct file is resident; reject both null and 0xFFFFFFFF from func_800141C4_14DC4. This dynamic-registry precondition applies to the file used for resolution.
- Before this function resolves a positive address, validate that the corresponding resource is resident; the native resolver faults on a missing file. Its result is not interchangeable with the recompiled scheduler's loaded callback mapping for raw 0x08000000–0x08FFFFFF actor-table addresses. For that family, use the scheduler mapping on a local copy only after validating the file context and resource handle; preserve callback inhibition policy and never dispatch or rewrite an early child callback to compare identities.
- The result has the resource's native lifetime. Reacquire after resource teardown or reload.
