## Interface

A complete callable prototype has not been established. Use the observation or callback-identity pattern in the example rather than guessing the native arguments.

## How it works

Installs entity 0x7E before the first common actor post pass. The parent emitter supplies resource file 0x1D, an owner pointer at task +0xD0 and flame flags at +0xE8.

Congo model parts use a different root link at +0xDC and separate constructors.
