`func_80217360_5D2830` · **Function**

Selects an actor owner list, allocates the requested entity, copies owner context, and increments the shared actor count.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80217360` | `0x005D2830` | `.file_12` |

Native code size: **504 bytes**.

## Signature

```c
void *func_80217360_5D2830(void *owner, uint16_t entity_id, uint8_t group);
```

## How it works

Uses func_80219CA0_5D5170 to select the native owner list, then allocates the entity using callback and model tables indexed by entity_id.

If the owner has an object at +0x18, copies its XYZ and rotation into the allocation request. Otherwise requests zero position and rotation. The initial scale is 0.1 on all three axes.

Copies native owner context through func_80218C28_5D40F8, writes entity_id at task +0x5C and +0x5E, and increments the shared actor count only after allocation succeeds.

Allocation stores the callback table value unchanged at child +0x0C and establishes the object at +0x18 and file ID at +0x28 before func_80218C28_5D40F8. The requested entity ID at +0x5C/+0x5E is assigned only after that inheritance helper returns.

For direct Ebisumaru explosion children, func_80218C28_5D40F8 is entered while task bank +0x28 and resource base +0x2C are both zero. The allocator later writes the 0xFFFE/0xFFFFFFFF pending-resource sentinels; the File42 caller then installs bank 0x2A and its resident resource base before the first scheduled update.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `owner` | `void *` | Valid owner task. A null object at owner +0x18 selects a zero-transform spawn; the owner task itself must be valid. |
| `entity_id` | `uint16_t` | Validated native entity ID used to index callback and model tables. |
| `group` | `uint8_t` | Native actor category passed to the owner-list selector. |

## Return value

New task pointer on success, or null when owner-list selection or task allocation fails.

## Usage example

```c
#include <stdint.h>

extern void *func_80217360_5D2830(void *, uint16_t, uint8_t);

/* The caller validates the owner, entity tables and native category. */
void *spawn_native_child(void *owner, uint16_t entity_id, uint8_t group)
{
    if (!owner) return 0;
    return func_80217360_5D2830(owner, entity_id, group);
}
```

The result can be null. The native scheduler must still execute the child's own initialization; callers must not fabricate a task graph from a copied pose.

## Notes

- Validate entity_id against the resident native tables before calling; this routine does not establish a bounds-checking contract.
- Check for null before initializing the returned task. Child creation alone does not finish the entity-specific initialization callback.
- An early child-construction hook can observe a raw segmented callback before scheduler relocation. Do not compare it directly with a loaded callback address or assume the requested entity halfwords are already final. For verified raw callback addresses from 0x08000000 through 0x08FFFFFF, an early identity comparison must use the recompiled scheduler's 32-bit unsigned mapping, raw_callback - 0x08000000u + (resource_handle & 0xBFFFFFFFu), on a local copy after validating the child file and resource handle; func_80014840_15440 uses native per-file segment mapping instead.
- At the context-copy entry boundary, bank/resource identity is not final. Do not classify a direct child solely from those entry fields; preserve the native construction order and confirm the later caller-installed values.
