`func_8000607C_6C7C` · **Function**

Writes the engine destination room, transform and related loading fields.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8000607C` | `0x00006C7C` | `.main` |

Native code size: **88 bytes**.

## Signature

```c
extern void func_8000607C_6C7C(unsigned short room, short x, short y, short z,
                              short camera_rot, short player_rot,
                              short field90, int field91);
```

## How it works

Writes the destination room at full-system offset +0x3AFE0, player rotation at +0x3AFE2, X/Y/Z at +0x3AFE4/+0x3AFE6/+0x3AFE8 and camera rotation at +0x3AFEA. It also sets the destination-transition byte at +0x3AE29 to 1 and stores the seventh and eighth arguments at +0x3AE3A and +0x3AE3C.

This prepares a destination without immediately changing the current room. During an ordinary live world transition, main system step 12 later calls func_8000B364_BF64 to consume these fields, resets rendering, and enters world step 13.

The live step-12 route consumes the prepared destination directly; it does not read the saved respawn transform. Save-file loading has a separate spawn-reading route. Preserve saved respawn fields when requesting an ordinary live warp unless changing the saved return point is also intended.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `room` | `unsigned short` | Destination room/stage identifier. |
| `x, y, z` | `short` | Destination player coordinates. |
| `camera_rot, player_rot` | `short` | Native signed-angle rotations. |
| `field90` | `short` | Additional load field; the documented start sequence uses zero. |
| `field91` | `int` | Additional load field; the documented start sequence uses zero. |

## Return value

No return value.

## Usage example

```c
extern short D_8006B780_6C380[];
extern void func_8000607C_6C7C(unsigned short room, short x, short y, short z,
                              short camera_rot, short player_rot,
                              short field90, int field91);
extern void func_80003728_4328(unsigned char step);

/* Call only from a loaded ordinary world after all native dialogs, pause,
 * scripted movement and an existing transition have finished. */
void request_congo_destination(void)
{
    const unsigned short room = 0x0016;
    const short *start = &D_8006B780_6C380[room * 5u];
    func_8000607C_6C7C(room, start[0], start[1], start[2],
                     start[3], start[4], 0, 0);
    func_80003728_4328(12);
}
```

The validated Congo room selects its native default transform. The existing world transition consumes the destination; this example does not alter saved respawn data or assign the current-room field early.

## Notes

- This queues destination state; it does not alone execute a complete warp.
- field90/field91 names in the recovered call pattern are unresolved; the documented call pattern passes zero rather than assigning unsupported meanings.
- Do not request a second warp while a native transition, pause, conversation or scripted movement owns the player. A loaded save and a live ordinary-world player are prerequisites for this call sequence.
