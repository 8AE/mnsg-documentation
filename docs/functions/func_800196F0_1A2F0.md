`func_800196F0_1A2F0` · **Function**

Emits native segment, material, matrix and geometry commands.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x800196F0` | `0x0001A2F0` | `.main` |

Native code size: **1616 bytes**.

## Signature

```c
extern void func_800196F0_1A2F0(unsigned int model_command);
```

## How it works

Uses D_801684A0 segment bases and material context to append graphics commands. Context tag bits select direct material calls or an inline material-command copy.

Depending on native transform mode, may emit a matrix and geometry commands using current graphics-bank cursors. CPU model records are not the storage for those submitted matrices.

Generic inline material data can produce a variable number of commands. A fixed command budget requires a constrained verified material/model path.

## Usage example

```c
extern void func_800196F0_1A2F0(unsigned int model_command);

#include "modding.h"

RECOMP_HOOK("func_800196F0_1A2F0")

    (void)command;
}
```

The example illustrates the native interface and its required state.

## Notes

- Only call under the native renderer with bound segments and valid graphics cursors. Segmented command values are not arbitrary native pointers.
