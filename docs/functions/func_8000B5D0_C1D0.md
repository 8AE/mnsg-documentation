`func_8000B5D0_C1D0` · **Function**

Activates prepared save state and copies its runtime/backup mirrors.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8000B5D0` | `0x0000C1D0` | `.main` |

Native code size: **112 bytes**.

## Signature

```c
extern void func_8000B5D0_C1D0(void);
```

## How it works

Clears a system field, marks native state at 0x8015C698, copies 0x30 bytes from 0x8015C66C to D_8015C5D8, mirrors 0x304 bytes from D_8015C608 to backup storage, and sets the runtime first word to one.

This is an in-memory start/load operation, not a request to write a save to disk.

## Return value

No return value in the established declaration.
