`func_8020D848_5C8D18` · **Function**

Selects the current room's actor-data wave and stages its static actor spawn definitions.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8020D848` | `0x005C8D18` | `.file_12` |

Native code size: **1072 bytes**.

## Interface

A complete callable prototype has not been established. Use the observation or callback-identity pattern in the example rather than guessing the native arguments.

## How it works

Indexes the per-room metadata table at D_80231300_5EC7D0 with the current room id and resolves the actor-data file that supplies the room's actor instances.

Runs before the static actor initializers and is retried while the actor-data wave is still loading. A hook here precedes every static actor initialization for the room.

Each metadata record exposes the normal actor-instance array, the partitioned/proximity actor lists and the actor-data file id. A zero instance definition terminates a list.

The stage only reads the room tables; the per-instance actor initialization is performed later by func_80218A54_5D3F24.

The entry hook observes the actor-data staging step and checks that the current room's actor-data record is present before the native spawn uses it.

## Notes

- The actor-data resources can be absent on early passes; retry from a later invocation instead of resolving segmented pointers before the file is loaded.
- Read-only observation is safe. Mutating the room tables without the native list and backlink rules corrupts actor spawning.
