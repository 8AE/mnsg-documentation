`func_8001904C_19C4C` · **Function**

Resolves a cached sibling record for one native model node.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8001904C` | `0x00019C4C` | `.main` |

Native code size: **276 bytes**.

## Signature

```c
extern void *func_8001904C_19C4C(const void *model_node, void *record);
```

## How it works

Reads the signed byte at model_node +0x05 as a relative node index with 0x18-byte stride, then derives the referenced model command key.

Searches the cache chain rooted at record +0x74. An existing match is retained or moved to the front; a missing match invokes native ancestor-cache reclamation and allocates a kind-2 record.

New nodes store a model key at +0x2C, sibling link at +0x74, child link at +0x78, and parent link at +0x94. Sibling nodes inherit the existing record parent; child nodes point to the existing record.

The stock implementation does not test the allocator result before writing +0x94. Exhausting the shared kind-2 pool can therefore crash inside native drawing.

## Return value

Existing or newly allocated cache record; stock allocation failure is unsafe.

## Usage example

```c
extern void *func_8001904C_19C4C(const void *model_node, void *record);

RECOMP_HOOK("func_8001904C_19C4C")

    /* Observe only while native rendering owns this context. */

```

The example illustrates the native interface and its required state.

## Notes

- This is an internal render traversal operation, not a standalone model constructor.
- Kind-2 capacity includes cached skeleton nodes as well as task-attached root display records.
