`func_800145B4_151B4` · **Function**

Loads a resource ID into a supplied destination and returns its output end pointer.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x800145B4` | `0x000151B4` | `.main` |

Native code size: **228 bytes**.

## Signature

```c
extern unsigned char *func_800145B4_151B4(unsigned int resource_id, void *dst);
```

## How it works

IDs below 0x8000 use the general file loader. IDs 0x8000 through 0x876F identify packed raw resource slices: the routine resolves ROM address and length, then copies the slice with synchronous DMA. IDs at or above 0x8770 leave the destination unchanged.

This routine has no capacity argument. Validate the asset and output size before use. Timed face/part animation can load into an alternate buffer and then rebind the corresponding object segment.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `resource_id` | `unsigned int` | General-file or packed-resource ID. |
| `dst` | `void *` | Caller-owned writable output buffer. |

## Return value

Pointer just past the loaded data; unchanged dst for an out-of-range resource ID.

## Usage example

```c
extern unsigned char *func_800145B4_151B4(unsigned int resource_id, void *dst);

extern int func_80014698_15298(unsigned int resource_id, void *rom_address_out);

unsigned char *load_aux(unsigned int id, unsigned char *buffer) {
    /* This bounded example accepts packed raw resources only. */
    if (!buffer || id < 0x8000u || id >= 0x8770u) return 0;
    int size = func_80014698_15298(id, 0);
    if (size <= 0 || size > 0x1000) return 0;
    unsigned char *end = func_800145B4_151B4(id, buffer);
    return end > buffer && end <= buffer + 0x1000 ? end : 0;
}
```

## Notes

- The API has no destination-capacity parameter; caller validation is required.
- Stored ROM size is not generally the decompressed output size for IDs below 0x8000; only use the fixed-buffer pattern for assets whose output is known to fit.
- Texture/display-list buffers used by this renderer must stay in original 8 MiB RDRAM; an extended recomp heap address can be truncated by graphics commands.
