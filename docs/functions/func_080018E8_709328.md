`func_080018E8_709328` · **Function**

Runs the native introduction, six targets and 100-second (3000-frame) Impact challenge, including carrying, throwing, result and exit phases.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x080018E8` | `0x00709328` | `.file_48` |

Native code size: **2748 bytes**.

## Signature

```c
void func_080018E8_709328(void *task, void *object);
```

## How it works

Task word +0xD0 points to its 60-byte work area. Work byte +0x00 is the phase, halfword +0x02 is yaw modulo 1024, signed halfword +0x04 is the phase frame, halfword +0x06 is the held-button repeat count, and word +0x08 is the previous held-button mask.

Work words +0x0C and +0x10 are native visual pointers; +0x14 is the timer HUD task pointer. Six target task pointers occupy +0x18 through +0x2C; three throwable task pointers occupy +0x30 through +0x38.

Phase 0 performs setup. Phase 3 starts introduction scenario 0x0173. Phase 4 waits for the instruction VM to be idle, then constructs the timer and six targets.

Phases 1 and 2 implement local carrying/aiming and throwing. The timer starts at 100 seconds, represented by 3000 native frames. Timer zero selects timeout phase 5; all six target completion bytes equal to 1 select success phase 6. Phase 7 handles exit.
