`func_801E0944_59C854` · **Function**

Updates the native player transition while retaining the same task and object.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x801E0944` | `0x0059C854` | `.file_11` |

Native code size: **692 bytes**.

## Signature

```c
void func_801E0944_59C854(void *task, void *object);
```

## How it works

In transition case 4, clears player-work byte +0x69 while keeping action +0xCC at 0xBA.

A later case advances the player to its idle state; the task and object remain the same through the observed transition.

Player-work byte +0x69 is transition state in this path, not a general alive/dead marker.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | The existing player task. |
| `object` | `void *` | The existing player object supplied by the scheduler. |

## Return value

No value.
