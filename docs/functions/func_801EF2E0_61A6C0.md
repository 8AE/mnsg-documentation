`func_801EF2E0_61A6C0` · **Function**

Initializes the Thaisamba task in the dedicated Impact-battle overlay.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x801EF2E0` | `0x0061A6C0` | `.file_13` |

Native code size: **332 bytes**.

## Interface

A complete callable prototype has not been established. Use the observation or callback-identity pattern in the example rather than guessing the native arguments.

## How it works

The shared battle state is obtained from D_8020EED0_63A2B0 and contains the boss task, model task, health and combat-pause state.

This initialization belongs to file_13 Impact battles rather than ordinary room actor creation.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `task` | `void *` | Thaisamba native task supplied to the initializer hook. |

## Usage example

```c
#include "modding.h"

static void *thaisamba_object;
RECOMP_HOOK("func_801EF2E0_61A6C0")
void observe_thaisamba_initialization(void *task)
{
    if (!task) return;
    thaisamba_object = *(void **)((char *)task + 0x18);
}
```

Capture the Impact boss task object at its native initializer entry. The pointer is only valid for the active battle and must be revalidated before later use.
