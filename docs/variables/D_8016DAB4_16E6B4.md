`D_8016DAB4_16E6B4` · **Variable**

Pointer to the task currently executing in the native scheduler.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8016DAB4` | — | `ABSOLUTE_SYMS` |

## Signature

```c
extern void *D_8016DAB4_16E6B4;
```

## How it works

Several helpers obtain their target implicitly from this global. func_8003521C_35E1C writes its AI callback at +0x0C, and func_80034ED4_35AD4 deletes this current task.

Code that invokes task callbacks outside their normal scheduler invocation must preserve the original context, set the intended task, detect deletion or context changes and restore the previous value.

## Usage example

```c
extern void *D_8016DAB4_16E6B4;

int is_current_native_task(void *task)
{
    return task && task == D_8016DAB4_16E6B4;
}
```

The example shows the documented native data layout or call sequence. Use it only while the relevant game state and resources are valid.

## Notes

- A native callback can delete its task or replace the current-task pointer. Do not continue using stale task storage after such a change.
- Task addresses can be reused. Object pointer, actor ID and generation provide additional identity checks.
