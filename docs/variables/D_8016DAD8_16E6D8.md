## Known values

### Known pool-count index {#pool-count-indices}

The array contains signed 16-bit active-allocation counts. Pool-kind indices must not be confused with the actor-owner categories in D_802297D6_5E4CA6.

| Array index (hex) | Array index (decimal) | Meaning |
| --- | --- | --- |
| `0x02` | `2` | Active model/display records. This element is also exported as D_8016DADC_16E6DC. |
