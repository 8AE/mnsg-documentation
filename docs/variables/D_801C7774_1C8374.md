## How it works

Stores an instruction-stream address, not a choice index or Boolean result. During native typing/text-wait handling, B branches to a nonzero address in this field; zero invokes the general native cancel path.

The choice-list B path is separate: it resumes four words after the 0x8012 choice terminator. Provide an explicit safe branch at that continuation when creating a custom Yes/No script.

Keep the continuation inside a persistent instruction stream owned by the current scenario.
