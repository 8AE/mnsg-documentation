`D_8015C5E4` · **Variable**

A 32-bit player-state value that gates Tsurami root processing.

## Signature

```c
extern unsigned int D_8015C5E4;
```

## How it works

Tsurami private post callback func_08000388_6B3628 skips its body when this value is zero. A nonzero value allows that native processing path to proceed.

The broader meaning and units of this counter are not established. It should be treated as a documented nonzero gate without assuming it represents health or elapsed time.
