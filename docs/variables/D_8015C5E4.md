`D_8015C5E4` · **Variable**

The runtime current-health word, also tested by Tsurami’s root post-update callback.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8015C5E4` | — | `ABSOLUTE_SYMS` |

## Signature

```c
extern int D_8015C5E4;
```

## How it works

This 32-bit word is the same storage as D_8015C608_15D208 - 0x24. The native save-start copy mirrors the saved current-health field into it; health uses half-heart units.

Tsurami private post callback func_08000388_6B3628 skips its body when this value is zero. Its test is nonzero, not positive: every nonzero bit pattern allows that native processing path to proceed.

Read the word only while player state is loaded. A nonzero health value alone does not identify a current Tsurami encounter.

## Known values

### Health units {#current-health-values}

The native field is a signed 32-bit health count measured in half-hearts. These rows show the unit conversion; they are numeric quantities rather than distinct state-enum entries. Native new-save health is ten half-hearts and is copied into this runtime word during save activation.

| Raw value (hex) | Raw value (decimal) | Meaning |
| --- | --- | --- |
| `0x00000000` | `0` | Zero health. |
| `0x00000001` | `1` | Half a heart. |
| `0x00000002` | `2` | One heart. |
| `0x0000000A` | `10` | Five hearts; native new-save current health after activation. |

### Current health and Tsurami gate {#gate-values}

This native current-health word is located at save-base offset -0x24; see the [save field layout](./D_8015C608_15D208.md#save-field-layout). Tsurami uses the word as a zero/nonzero gate before its private post-update body, rather than testing whether health is positive.

| Stored value | Meaning |
| --- | --- |
| `0x00000000` (`0`) | Current health is zero; skip the gated Tsurami private post-update body. |
| Nonzero 32-bit value | Current health is nonzero; the gate allows the private post-update body. The native test is != 0, not > 0, and other callback conditions still apply. |

## Notes

- The gate does not identify a live Tsurami encounter by itself. The room, root task, health and active state must also match.
