`D_80204048_5BFF58` · **Variable**

Table of native player-model display-pointer replacements.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80204048` | `0x005BFF58` | `.file_11` |

## Signature

```c
extern void *D_80204048_5BFF58[];
```

## How it works

Known Goemon entries are index 1 for applying Sudden Impact hair pointers and index 2 for restoring the original pointers. Apply a table with func_8001C3E0_1CFE0.

Only those entries have an established purpose here; other indices should not be assigned guessed meanings.

## Known values

### Known appearance replacement tables {#known-replacement-tables}

These are indices of a pointer array, not appearance-flag bits or character IDs. The pointed-to replacement data is overlay resident.

| Array index (hex) | Array index (decimal) | Stored native pointer | Meaning |
| --- | --- | --- | --- |
| `0x01` | `1` | `0x80204030` | Replace Goemon’s normal hair display pointers with Sudden Impact variants. |
| `0x02` | `2` | `0x8020403C` | Reverse the substitution and restore Goemon’s normal hair display pointers. |
