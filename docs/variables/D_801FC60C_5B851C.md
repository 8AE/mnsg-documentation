`D_801FC60C_5B851C` · **Variable**

Pointer to the current player object and transform.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x801FC60C` | `0x005B851C` | `.file_11` |

## Signature

```c
extern PositionObject *D_801FC60C_5B851C;
```

## How it works

The partial object layout contains float x/y/z at offsets +0x08/+0x0C/+0x10. These coordinates locate player-centered effects and spatial sounds.

The object pointer differs from the player task pointer at D_801FC604_5B8514.

Assigned from the player task primary object at task+0x18. The display layout contains position floats at +0x08/+0x0C/+0x10, signed rotations at +0x14/+0x16/+0x18 and animation frame at +0x28.

Use this object for model transforms and animation inspection. It is distinct from the player task pointer D_801FC604_5B8514.

## Usage example

```c
typedef struct { unsigned char pad[8]; float x, y, z; } PositionObject;
extern PositionObject *D_801FC60C_5B851C;

int copy_player_position(float out[3])
{
    PositionObject *p = D_801FC60C_5B851C;
    if (!p) return 0;
    out[0] = p->x; out[1] = p->y; out[2] = p->z;
    return 1;
}
```

The example shows the documented native data layout or call sequence. Use it only while the relevant game state and resources are valid.

## Notes

- The object can be absent during transitions and non-gameplay system states.
- PlayerObject is a partial native layout containing only the displayed fields.
- Do not confuse this display object with D_801FC604, the task pointer.
