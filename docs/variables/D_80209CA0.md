`D_80209CA0` · **Variable**

Six 16-byte texture descriptors supply the room minimap, compass and local marker.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80209CA0` | `0x005C5BB0` | `.file_0C` |

## Signature

```c
extern unsigned char D_80209CA0[6][16];
```

## How it works

Each entry stores u16 width at +0, u16 height at +2, format byte at +4, texture address at +8 and file ID at +0x0C.

Entry three is a 64 by 32 RGBA5551 sheet: format 0x10, segmented address 0x0A000000 and file 0x007F. It supplies the round position dot and some directional markers.

Entries four and five use the same dimensions and file, at 0x0A00B000 and 0x0A00D000. Their resources are 0x800F and 0x8011. Entries one and two are modified when a room map is initialized.

File zero means a direct texture pointer. A nonzero file requires the file's loaded base and segment mapping; do not interpret a segmented address as a CPU pointer.

## Usage example

```c
extern unsigned char D_80209CA0[6][16];

unsigned int minimap_marker_file(void)
{
    return *(unsigned short *)(D_80209CA0[3] + 12);
}
```

The example illustrates the native interface and its required state.

## Notes

- Only access this layout while its owning overlay and task are active. Task-pool addresses can be reused after destruction.
- The table stores texture descriptors, not the opaque texture handles used by the pause-menu image system.
