`D_80231300_5EC7D0` · **Variable**

Per-room metadata for resident actor instances, wave-backed normal instances and proximity partitions.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80231300` | `0x005EC7D0` | `.file_12` |

## Signature

```c
extern void *D_80231300_5EC7D0[];
```

## How it works

Indexed by the raw room id (D_800C7AB2), with 800 slots in the US table. Each non-null record supplies an already-resident actor-instance list at +0x00, normal instances at +0x08, proximity partitions at +0x0C and the actor-data file id at +0x14.

func_8020D848_5C8D18 first walks the resident list and then the normal list. Partition-based spawning is handled by func_8020D36C_5C883C. A zero definition pointer terminates each 0x14-byte source list.

The +0x00 list and its definition pointers are used directly by the manager. Wave-backed +0x08/+0x0C/+0x10 pointers resolve through the record's own actor-data file. A resident list must not be mistaken for a segmented pointer.

The US ROM has seven resident-list placements: two 0x1FC platforms in room 0x30 and five 0xFC/0xFE enemies in room 0x131. A scan of all three lists finds 3,888 unique placements across 292 nonempty rosters; 333 records select actor-data waves, and 374 table slots contain metadata.

## Known values

### Room actor source lists {#room-actor-source-lists}

Partial native 32-bit room metadata and source layouts used by the resident, normal and partition spawn paths.

| Record offset | Native storage | Meaning |
| --- | --- | --- |
| +0x00 | ActorInstance * | Already-resident source list; source and definition pointers are read directly by the actor manager. |
| +0x04 | const char ** | Actor-definition names. |
| +0x08 | ActorInstance * | Normal source list, resolved through the actor-data file. |
| +0x0C | ActorPartition * | Partition grid whose entries resolve to proximity source lists. |
| +0x10 | ActorPartitionConfiguration * | Partition dimensions and cell counts; resolved through the actor-data file. |
| +0x14 | unsigned short | Actor-data file id used for segmented resolution. |
| Source +0x0C | ActorDefinition * | Definition pointer; zero terminates the 0x14-byte source list. Distinct source descriptors may share a definition. |

## Usage example

```c
#include "modding.h"

extern unsigned short D_800C7AB2;
extern void *D_80231300_5EC7D0[];

/* Look up the current room's actor-data record. */
void *room_actor_metadata(void)
{
    return D_80231300_5EC7D0[D_800C7AB2];
}
```

The table is indexed by the raw current-room id; a null entry means the room has no actor-data record.

## Notes

- Index only with a valid room id below 800; the native table has no bounds checking.
- Resolve segmented pointers with the record's own loaded file. Already-resident lists and definitions have different pointer semantics.
- Actor task +0x70 is not a universal placement backlink: the resident/normal initialization clears it, while partition spawning explicitly assigns the source afterward. Observe the source argument of func_80218A54_5D3F24 when identifying every placed actor.
