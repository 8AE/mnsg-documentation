`D_80231300_5EC7D0` · **Variable**

Table of per-room records that describe each room's static actor-data wave.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80231300` | `0x005EC7D0` | `.file_12` |

## Signature

```c
extern void *D_80231300_5EC7D0[];
```

## How it works

Indexed by the raw room id (D_800C7AB2). Each entry describes a room's normal actor-instance array, its partitioned/proximity actor lists and the actor-data file id that supplies the instances.

Read by the actor-data spawn stage func_8020D848_5C8D18. A null record or a not-yet-resolved actor-data file means the room's actor wave is unavailable and spawning is deferred.

The instance and list pointers are segmented and must be resolved through the active actor-data file id; they are not raw RAM addresses.

## Usage example

```c
#include "modding.h"

extern unsigned short D_800C7AB2;
extern void *D_80231300_5EC7D0[];

/* Look up the current room's actor-data record. */
void *room_actor_metadata(void)
{
    return D_80231300_5EC7D0[D_800C7AB2];
}
```

The table is indexed by the raw current-room id; a null entry means the room has no actor-data record.

## Notes

- Index only with a valid room id; the table has no bounds checking.
- Resolve the record's segmented pointers with its own actor-data file id. Resolving them with an unrelated or unloaded file faults.
