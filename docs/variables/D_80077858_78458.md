`D_80077858_78458` · **Variable**

Pointer to the next instruction in the shared native scenario VM.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80077858` | `0x00078458` | `.main` |

## Signature

```c
extern unsigned int *D_80077858_78458;
```

## How it works

A null pointer indicates no current instruction stream. The native VM advances this pointer through 32-bit instructions and follows text, callback and branch operands.

Text operands address 16-bit glyph/control streams, not C strings. The US font maps printable ASCII 0x20 through 0x7E to glyph indices 0 through 94 by subtracting 0x20.

Publishing a custom stream transfers execution to shared native interpreter state. Allocate its window first, hold every referenced array/callback for the full lifetime, and detect replacement ownership before cancellation or cleanup.

## Known values

### Established scenario instructions {#scenario-instructions}

Each instruction and operand occupies one 32-bit word in the US scenario VM. Text operands point to separate 16-bit glyph/control streams. This is a task-relevant subset, not the full instruction set.

| Opcode | Meaning | Following words |
| --- | --- | --- |
| `0x8008` | End the scenario | None |
| `0x800A` | Branch to another instruction stream | One instruction pointer |
| `0x800B` | Invoke a native callback | One callback pointer; the established callback has void return and no arguments |
| `0x8010` | Process native text | One pointer to a 16-bit glyph/control stream |
| `0x8011` | Parse a choice list | Four-word text/branch records, ending at 0x8012 |
| `0x8012` | End choice-list definitions | The B continuation begins four words after this terminator |

### Established native text controls {#scenario-text-controls}

These values belong to the 16-bit text stream, not the 32-bit scenario instruction stream. Printable US ASCII glyphs are encoded as character value minus 0x20.

| 16-bit value | Meaning |
| --- | --- |
| `0x0000`–`0x005E` | Printable ASCII glyphs 0x20–0x7E |
| `0xFFB9` | Close the message window |
| `0xFFBA` | Open the message window |
| `0xFFC4` | New line |
| `0xFFDF` | Yellow text |
| `0xFFE0` | White text |
| `0xFFFF` | End the text stream |

## Notes

- This is a pointer variable, not instruction storage or a byte offset.
- Network or user text must be converted to bounded native glyphs. Never reinterpret arbitrary text bytes as 16-bit controls or 32-bit instructions.
