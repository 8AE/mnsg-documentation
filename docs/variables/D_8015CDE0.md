`D_8015CDE0` · **Variable**

Scratch pointer to the current resolved room actor definition.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8015CDE0` | — | `ABSOLUTE_SYMS` |

## Signature

```c
extern ActorDefinition *D_8015CDE0;
```

## How it works

The definition begins with unsigned short actor ID and parameters, followed by three 32-bit data words.

The native actor manager resolves definitions through the active actor-data file. func_80218A54_5D3F24 also replaces this pointer from its supplied instance before copying definition data into the task.

The partial definition layout begins with 16-bit actor ID and parameters, followed by three 32-bit payload words. Native initialization resolves the instance definition and updates this shared pointer.

Do not retain it as stable per-actor state across nested spawns or stage teardown.
