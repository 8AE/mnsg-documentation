`D_800657CC_663CC` · **Variable**

Pairs of resource IDs and destination addresses populate native loaded file 0x007F.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x800657CC` | `0x000663CC` | `.main` |

## Signature

```c
extern unsigned int D_800657CC_663CC[];
```

## How it works

This list maps image resources 0x8004 through 0x8019 to decoded 0x1000-byte slots beginning at segmented address 0x0A000000.

The first pair is (0x8004, 0x0A000000), resource 0x800F maps to 0x0A00B000 and 0x8011 maps to 0x0A00D000. A zero resource ID ends the list.

The native resource loader decodes each PIC image into the loaded file's destination. File 0x007F therefore refers to the populated runtime allocation, not a single packed texture at the same file-table index.

## Usage example

```c
extern unsigned int D_800657CC_663CC[];

unsigned int hud_image_destination(unsigned int resource)
{
    const unsigned int *pair = D_800657CC_663CC;
    for (; pair[0]; pair += 2)
        if (pair[0] == resource) return pair[1];
    return 0;
}
```

The example illustrates the native interface and its required state.
