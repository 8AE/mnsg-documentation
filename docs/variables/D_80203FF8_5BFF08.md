`D_80203FF8_5BFF08` · **Variable**

Timed face/part segment descriptors for two auxiliary channels.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80203FF8` | `0x005BFF08` | `.file_11` |

## Signature

```c
extern unsigned short D_80203FF8_5BFF08[];
```

## How it works

The low byte of each 16-bit descriptor selects the object segment to rebind when a timed auxiliary resource changes during an action.

The high byte meaning is not established here. Load the replacement buffer before rebinding its segment.

## Known values

### Timed auxiliary descriptors {#timed-descriptor-values}

The array stores 16-bit descriptors. The low byte selects the object base slot using +0x38 + selector × 8; the meaning of the upper byte is not established.

| Channel index | Stored descriptor (hex) | Stored descriptor (decimal) | Low-byte selector | Meaning |
| --- | --- | --- | --- | --- |
| `0` | `0x0003` | `3` | `3` | Object base slot +0x50; upper byte is zero. |
| `1` | `0x0004` | `4` | `4` | Object base slot +0x58; upper byte is zero. |
