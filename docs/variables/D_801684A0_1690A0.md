`D_801684A0_1690A0` · **Variable**

Pointer to the object whose segments and material context are active during native drawing.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x801684A0` | — | `ABSOLUTE_SYMS` |

## Signature

```c
extern void *D_801684A0_1690A0;
```

## How it works

Native model traversal temporarily changes this pointer while binding nested render context, then restores the previous object.

Root cache allocation attaches its cached tree at current_object +0x78. Geometry submission reads segment pairs starting at +0x34 and material/context at +0x30.

## Usage example

```c
extern void *D_801684A0_1690A0;

void *current_native_render_object(void) {
    return D_801684A0_1690A0;
}
```

The example illustrates the native interface and its required state.

## Notes

- Only meaningful at the corresponding renderer boundary. Do not retain it as an actor owner or replace it during unrelated gameplay code.
