`D_8016DAC0_16E6C0` · **Variable**

Pointer table of free display records indexed by native kind.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8016DAC0` | — | `ABSOLUTE_SYMS` |

## Signature

```c
extern void *D_8016DAC0_16E6C0[];
```

## How it works

Each entry is a native 32-bit head pointer. Entry 2 is the kind-2 model/display free list at address 8016DAC8.

Free records link through their first word. The low seven bits of byte +0x04 identify the kind; bit7 marks the retired state and is cleared by allocation.

Kind-2 stock storage comprises 192 records of stride 0x98. Allocation/free updates the separate signed 16-bit active-counter table. Increasing a capacity scalar without provisioning this linked storage does not create records.

## Usage example

```c
extern void *D_8016DAC0_16E6C0[];

void *kind2_free_head(void) {
    return D_8016DAC0_16E6C0[2];
}
```

The example illustrates the native interface and its required state.

## Notes

- This is pointer storage, not a contiguous array of model records. Do not change a live free list without preserving reset/release semantics.
