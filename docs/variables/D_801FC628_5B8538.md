`D_801FC628_5B8538` · **Variable**

Pointer to the active world-camera render record containing the tagged projection-descriptor address.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x801FC628` | `0x005B8538` | `.file_11` |

## Signature

```c
extern void *D_801FC628_5B8538;
```

## How it works

This global stores a pointer to the native world-camera presentation record. It is a pointer variable, not inline descriptor storage and not the local player object or local camera task.

The Mermaid waterfall controller reads the unsigned 32-bit word at record +0x2C and decodes the active projection-descriptor address with mask 0x8FFFFFFE. That decoded pointer identifies a separate 96-byte descriptor.

The descriptor begins with six floats: eye XYZ at +0x00/+0x04/+0x08 and look XYZ at +0x0C/+0x10/+0x14. Its rounded unsigned 16-bit distance is at +0x1A. The waterfall intro uses eye (0,-354,-110), look (0,-404,190), and distance 0x0A00.

The waterfall controller copies the local camera descriptor into this world descriptor through its common update tail. Immediate camera setters change scalar fields first; descriptor contents establish whether the scheduled camera update and world commit have produced the intended presentation.

Waterfall setup at phase 4 frame 20 writes 1 to this record byte +0x64. This is a field of the world-camera presentation record, not the local Yae body.

## Usage example

```c
extern void *D_801FC628_5B8538;

/* Consumers validate scene ownership and lifetime before dereferencing. */
void *current_world_camera_record(void)
{
    return D_801FC628_5B8538;
}
```

Reads the pointer variable without treating its storage as a descriptor or changing native camera state.

## Notes

- Validate the global pointer, decoded descriptor pointer, current scene and native owner lifetime before reading record fields or the 96-byte descriptor. A nonzero global does not prove that the target still belongs to the current camera.
- Preserve the native tagged-word mask 0x8FFFFFFE. Do not replace it with an unrelated physical-address mask or treat the encoded word itself as a plain pointer.
- Reading this pointer does not initialize a camera, update its scheduled descriptor, commit world projection state, or grant ownership of either record. These observations do not establish a general camera-control API for arbitrary writes.
