`D_800C7AE2` · **Variable**

A live control-state byte whose nonzero value blocks normal playable-player damage intake.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x800C7AE2` | — | `ABSOLUTE_SYMS` |

## Signature

```c
extern unsigned char D_800C7AE2;
```

## How it works

Byte storage at g_system +0x3AE22. The exported symbol has no ROM suffix.

The native playable pre-update requires this byte to be zero before calling damage intake. It separately requires D_800C7AE3 to be zero and D_800C7AE0 to equal 0 or 4.

Other native paths also read and write this byte; the inspected damage gate does not establish a complete semantic enumeration for all of its values.

## Usage example

```c
extern unsigned char D_800C7AE0;
extern unsigned char D_800C7AE2;
extern unsigned char D_800C7AE3;

int native_damage_control_gate_is_open(void)
{
    return D_800C7AE2 == 0 && D_800C7AE3 == 0 &&
           (D_800C7AE0 == 0 || D_800C7AE0 == 4);
}
```

The example illustrates the native interface and its required state.

## Notes

- This reproduces only the native control-byte gate. It does not validate a player, save, contact, resource transition or invulnerability timer.
- Do not replace the one-byte declaration with a word or a pointer.
