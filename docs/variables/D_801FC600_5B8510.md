`D_801FC600_5B8510` · **Variable**

Pointer to the native player-manager task used as the root of player contact scans.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x801FC600` | `0x005B8510` | `.file_11` |

## Signature

```c
extern void *D_801FC600_5B8510;
```

## How it works

The scene contact coordinator passes this pointer as the root attacker or victim list. Linked tasks with greater priority belong to the scanned subtree.

This root is distinct from D_801FC604_5B8514, the current playable-player task. An outgoing player-group scan can include owned projectile children as well as the playable actor.

Inspected projectile constructors store the owning playable-player task at projectile +0x5C. For a playable task itself, +0x5C instead points to player work; those layouts must not be confused.

## Usage example

```c
extern void *D_801FC600_5B8510;

int is_player_contact_group(const void *group)
{
    return D_801FC600_5B8510 && group == D_801FC600_5B8510;
}
```

The example illustrates the native interface and its required state.

## Notes

- Validate the current gameplay scene and task lifetime. A retained pointer is not a durable identity across scene transitions.
- Group membership alone does not identify an individual attack owner; use the live playable task and verified projectile ownership fields when attribution matters.
