`D_8015C5CC_15D1CC` · **Variable**

Pointer to the next native 8-byte graphics command.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8015C5CC` | — | `ABSOLUTE_SYMS` |

## Signature

```c
extern unsigned int *D_8015C5CC_15D1CC;
```

## How it works

Native render writers append two 32-bit words per Gfx command and advance this pointer. A stock bank contains 10,640 commands at its beginning.

The pointer is live mutable cursor state; the bank base comes from the full system pointer and current bank index. The writers do not enforce the bank’s command-array bound.

Commands and every referenced matrix or data range must retain storage until the owning graphics bank is reusable. Redirecting CPU pointers alone does not make extended-heap addresses valid for RSP data.

## Usage example

```c
extern unsigned int *D_8015C5CC_15D1CC;

unsigned int *native_graphics_cursor(void) {
    return D_8015C5CC_15D1CC;
}
```

The example illustrates the native interface and its required state.

## Notes

- This is pointer storage, not a Gfx array symbol. Do not insert commands or redirect it without preserving renderer context, address encoding, capacity and submission lifetime.
