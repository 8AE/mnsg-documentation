`D_80168F84_169B84` · **Variable**

Float scratch storage for the current attack sphere y offset in attacker-local units.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80168F84` | — | `ABSOLUTE_SYMS` |

## Signature

```c
extern float D_80168F84_169B84;
```

## How it works

The native attack scanner writes this value immediately before func_80033404_34004 tests the decoded sphere. Animated descriptors use the render object animation frame; descriptor 0xFFFFFFFF supplies a fixed task sphere.

Scale the three local offsets by their respective object scales, rotate with the native object transform, then add object world position to obtain the sphere center.

This mutable scratch value is overwritten for every sphere and victim-group scan. It is not a persistent property of the current player.

## Notes

- Read at the native sphere-test entry boundary and copy the value before using it elsewhere.
- The address holds one float, not a pointer or an enumerated flag.
