`D_80167C54_168854` · **Variable**

Pointer to the native message-window style table, including entries with green and zero-alpha panel settings.

## Signature

## How it works

Generic native setup initializes the table; opening a save sign first is not a prerequisite.

The US table at runtime 0x800627F0 uses records of 0x24 bytes. Style 8 supplies the ordinary save-sign background and palette with width 256 pixels and a height of nine 8-pixel strips, or 72 pixels.

In the US style table at runtime address 0x800627F0, style 0 maps to a 256 by 72 pixel panel using pattern data at 0x8005BB70, the green palette at 0x80062770, and primitive RGBA (192, 192, 192, 170). This records the style-table mapping; it does not identify the style selected by any particular scene. Styles 10 and 11 are byte-for-byte identical across their nine 32-bit fields at 0x80062958 and 0x8006297C; they use the same 256 by 72 pixel geometry and primitive RGBA (192, 192, 192, 0). The zero panel alpha is consistent with text displayed over the scene without a filled green panel, but the particular style index used by that scene has not been traced.

## Notes

- The symbol stores a table pointer; it is not the first style record itself.
- Keep native setup/teardown and style-index validity separate from window allocation success.
- The style 10 and style 11 records are identical, so table contents alone cannot distinguish which index a scene selected. No scene-specific allocator call has been traced for the transparent-panel example.
