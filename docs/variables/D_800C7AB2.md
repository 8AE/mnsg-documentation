`D_800C7AB2` · **Variable**

The game’s 16-bit current room identifier. Read it to limit behavior to a particular room or invalidate cached actor state after a transition.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x800C7AB2` | — | `ABSOLUTE_SYMS` |

## Signature

```c
extern unsigned short D_800C7AB2;
```

## How it works

Compare this value with a known room constant before applying room-specific behavior. Store it alongside cached actors or pending effects and revalidate that state when the value changes.

Room identity does not establish that actor initialization has completed. Loaded resources, task generation, and encounter phase need their own checks.

The storage is accessed as a 16-bit short. Use unsigned short for room identifiers and keep declarations consistent within your project. The complete surrounding system structure is not required for a read-only room check.

## Usage example

```c
#include "modding.h"

extern unsigned short D_800C7AB2;

static unsigned short last_room;
static int have_room;
static unsigned int room_generation;

RECOMP_HOOK_RETURN("func_80002040_2C40")
void track_game_room(void)
{
    unsigned short room = D_800C7AB2;
    if (!have_room || room != last_room) {
        last_room = room;
        have_room = 1;
        ++room_generation;
        /* Invalidate your room-scoped caches here. */
    }
}
```

Tracks room transitions after the system update and increments a local generation counter. Discard or revalidate cached native actors when that generation changes.

## Notes

- Reading a new room ID does not prove that its actor data has finished loading. Check native lifecycle and resource readiness separately.
- Writing the variable directly is not a supported room-transition recipe. The engine manages additional transition state.
