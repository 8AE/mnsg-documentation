`D_802287BC_5E3C8C` · **Variable**

Table of native actor-entry callbacks indexed by actor ID, including the common save sign and its scenario interaction lifecycle.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x802287BC` | — | `ABSOLUTE_SYMS` |

## Signature

```c
extern void *D_802287BC_5E3C8C[];
```

## How it works

The native room actor manager supplies D_802287BC_5E3C8C[actor_id] to func_8003555C_3615C as the new task entry callback.

Companion metadata supplies task category and model ID. Actor-data resources and room-instance initialization complete the spawn path.

Actor ID 0x08B is the common model-bearing save sign. Its native entry initializes the task, binds model slot 0x08B, and installs the sign interaction callback; its talk path selects the player and dispatches the scenario ID stored on the task.

An alternate conversation initiation call with interaction mode 0 can begin a scenario without setting object +0x7C bit 0x08. It marks task +0x68 bit 0x100, sets the selected player task state at +0xCD to 1, and sets a global interaction state. The player update advances that state to 3; the scenario coordinator waits for the selected player, advances it to 4, dispatches the scenario ID at sign task +0xA4, and installs a cleanup callback. This interaction mode is separate from model setup mode 0.

After the scenario virtual machine becomes inactive, cleanup clears task +0x68 bit 0x100, sets task flags to (flags & ~0x100) | 0x4400, and restores the callback saved at task +0xB4.

An entry supplies the actor callback/entry value passed to func_8003555C during task creation.

The table is exposed as void pointers; a fuller entry layout or callable function prototype is not established by that lookup alone.

## Notes

- Validate the actor ID against the native roster before indexing. A callback entry alone is not a complete spawn configuration.
- A follow-up player recovery path appears to clear transition state after the scenario ends, but its control-flow gate is not fully confirmed.
- This is native scene/overlay state. Validate actor IDs and resource lifetime; do not assume an unsized extern provides bounds.
