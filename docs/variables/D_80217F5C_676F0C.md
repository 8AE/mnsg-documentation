## How it works

The pause-menu initializer func_80211870_670820 stores the return from the native texture registration routine at 0x80217F5C. The matching recomp data symbol is D_80217F5C_676F0C.

The registered image is resource 0x86A3, stored at ROM address 0x013F9C50. Its decoded RGBA5551 sheet is 32 × 64 pixels.

This word holds an opaque runtime texture handle, not pixel bytes or a ROM pointer. The named storage is beyond the file-backed pause overlay; the numeric suffix in its symbol name does not identify the packed image resource.

Observe this value while the pause-menu overlay is active and its texture initialization has completed. Pass handles only to native interfaces that expect them.

## Notes

- The runtime address is reused by other overlays. Do not read or write this variable when the pause overlay is inactive.
- Texture handles are assigned at runtime; no fixed handle value or enum meaning is established.
