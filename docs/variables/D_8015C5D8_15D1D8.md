`D_8015C5D8_15D1D8` · **Variable**

Native runtime save/control mirror.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8015C5D8` | — | `ABSOLUTE_SYMS` |

## Signature

```c
extern unsigned int D_8015C5D8_15D1D8[];
```

## How it works

func_8000B5D0 copies 0x30 bytes of prepared control state here and marks its first word active. Element 1 is current character; word at +0x2C is the dirty flag set by the native character cycler.

The current-character word aliases address 0x8015C5DC. Updating that word alone does not execute the live character-swap state transition.

## Known values

### Character values {#character-values}

These values belong to the current-character word at array index 1 (byte offset +0x04). The word is an ID, not a character-unlock bitmask.

| Raw value (hex) | Raw value (decimal) | Meaning |
| --- | --- | --- |
| `0x00` | `0` | Goemon |
| `0x01` | `1` | Ebisumaru |
| `0x02` | `2` | Sasuke |
| `0x03` | `3` | Yae |

### Runtime mirror fields {#runtime-fields}

The declaration is a 32-bit-word array. Multiply the array index by four to obtain a byte offset; the symbol itself is the storage base.

| Array index | Byte offset | Storage type | Meaning |
| --- | --- | --- | --- |
| `0` | `+0x00` | `uint32_t` | Activation marker: the native save-start path writes 1 after copying the 0x30-byte runtime block. Other values are not assigned an enum meaning here. |
| `1` | `+0x04` | `uint32_t` | Current character ID; see Character values above. This word also resides at native address 0x8015C5DC. |
| `3` | `+0x0C` | 32-bit word, native signed health interpretation | Current health in half-heart units. Also exported as [D_8015C5E4](./D_8015C5E4.md); the unsigned array declaration does not change the underlying health field. |
| `11` | `+0x2C` | `uint32_t` | Character-change/dirty marker: the character-switch path writes 1. The complete reset protocol is not established here. |
