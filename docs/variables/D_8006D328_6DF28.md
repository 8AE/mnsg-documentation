`D_8006D328_6DF28` · **Variable**

Storage containing native active-list and free-list task pointers.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8006D328` | `0x0006DF28` | `.main` |

## Signature

```c
extern unsigned char D_8006D328_6DF28[];
```

## How it works

The verified pointer words at offsets 0x00,0x04 and0x08 hold the root/list pointers and free head; unsigned 16-bit at 0x0C is the active task count.

Native initialization builds 79 free 0xF0-byte task records plus the separate root. The allocator resets popped tasks, sets their +0x04 backlinks, and the free path returns them to the same linked free head.

## Usage example

```c
extern unsigned char D_8006D328_6DF28[];

void *native_task_free_head(void) {
    return *(void **)(D_8006D328_6DF28 + 0x08);
}
```

The example illustrates the native interface and its required state.

## Notes

- This symbol names storage at the beginning of task-list state, not a task object. Pointer words are 32-bit in the native ABI.
- Mutating list pointers without the native backlink/depth rules corrupts task traversal.
