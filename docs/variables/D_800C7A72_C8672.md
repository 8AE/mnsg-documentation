`D_800C7A72_C8672` · **Variable**

Signed16 selector for the two native graphics banks.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x800C7A72` | — | `ABSOLUTE_SYMS` |

## Signature

```c
extern short D_800C7A72_C8672;
```

## How it works

The verified bank values are 0 and 1. The full system structure contains the two 0x1D6D8-byte bank records consecutively at its beginning.

The frame-submission path toggles this index only when graphics are submitted. func_80016950 initializes the selected bank before its next use.

## Known values

### Graphics-bank indices {#graphics-bank-values}

Stored signed16 index. These are array indices, not frame-counter phases.

| Raw value (hex) | Raw value (decimal) | Meaning |
| --- | --- | --- |
| `0x0000` | `0` | First bank at the full system base. |
| `0x0001` | `1` | Second bank at full system base +0x1D6D8. |

## Usage example

```c
extern short D_800C7A72_C8672;

int current_graphics_bank(void) {
    int bank = D_800C7A72_C8672;
    return bank >= 0 && bank < 2 ? bank : -1;
}
```

The example illustrates the native interface and its required state.

## Notes

- This selector is distinct from the world-frame counter. Do not infer bank reuse from a frame counter or overwrite the selector while work is in flight.
