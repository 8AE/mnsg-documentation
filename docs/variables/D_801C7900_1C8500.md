`D_801C7900_1C8500` · **Variable**

Native integer selecting controller-one, controller-two or merged scenario input.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x801C7900` | — | `ABSOLUTE_SYMS` |

## Signature

```c
extern int D_801C7900_1C8500;
```

## How it works

The scenario input sampler interprets 1 as controller one, 2 as controller two and 3 as merged input from both. This is an enumerated selector, not a general bitmask.

Zero and other values leave the previously sampled scenario input unchanged. Do not write zero expecting it to clear or disable input.

The scenario initializer selects source 3. Set source 1 after initialization when only controller one should respond.

## Known values

### Scenario input-source values {#scenario-controller-values}

The native 32-bit selector chooses a source by exact value. It is not a general bitmask; zero and unrecognized values retain previously sampled input.

| Raw value (hex) | Raw value (decimal) | Meaning |
| --- | --- | --- |
| `0x01` | `1` | Controller one |
| `0x02` | `2` | Controller two |
| `0x03` | `3` | Merged input from both controllers |
