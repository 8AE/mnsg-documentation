`D_8006B780_6C380` · **Variable**

Room-indexed table of default start positions and rotations.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8006B780` | `0x0006C380` | `.main` |

## Signature

```c
extern signed short D_8006B780_6C380[];
```

## How it works

Each entry consists of five signed shorts: position x,y,z, camera rotation and player rotation. An entry begins at room*5.

Validate a room ID against known entries before indexing. The unsized extern declaration does not itself provide table bounds.

## Known values

### Room start entry layout {#room-start-entry-layout}

Each room ID selects one entry of five signed 16-bit values. The first short index is room_id × 5 and the entry byte offset is room_id × 10. These rows describe field positions, not room IDs or stored coordinate values.

| Entry-relative short index | Entry-relative byte offset | Stored type | Meaning |
| --- | --- | --- | --- |
| `0` | `0x00` | `s16` | Default X position |
| `1` | `0x02` | `s16` | Default Y position |
| `2` | `0x04` | `s16` | Default Z position |
| `3` | `0x06` | `s16` | Default camera rotation |
| `4` | `0x08` | `s16` | Default player rotation |
