`D_8006B780_6C380` · **Variable**

Room-indexed records containing default XYZ, base player heading and a packed native camera-start parameter.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8006B780` | `0x0006C380` | `.main` |

## Signature

```c
extern signed short D_8006B780_6C380[];
```

## How it works

Each entry consists of five signed 16-bit values: X, Y, Z, base player Y heading copied to system +0x3AFEA, and packed camera-start parameter copied to +0x3AFE2. An entry begins at short index room * 5 or byte offset room * 10.

File11 initialization truncates the fifth halfword to camera-task byte +0xBC. Camera startup uses byte >> 3 as an unguarded index into five native callbacks and its direction bits to establish facing relative to the base heading. The common value 0x10 selects callback group 2; this field is not an Euler yaw.

The default reader func_800214E4_220E4 indexes five signed halfwords without a room-ID guard. The ordinary destination consumer invokes it even when an explicit arrival transform has been prepared. Custom room admission must cover this reader separately from graphics and actor metadata.

Validate the room against known native entries before indexing. An unused room actor-metadata slot does not establish a valid default-start entry.

The base heading uses the native 10-bit phase: 1024 units per revolution. Player construction copies it into object yaw and player task +0x94, and stores heading << 6 in player-work +0xA4. The camera also uses it as a facing baseline.

### Room start entry layout {#room-start-entry-layout}

Each room ID selects one entry of five signed 16-bit values. The first short index is room_id × 5 and the entry byte offset is room_id × 10. These rows describe field positions, not room IDs or stored coordinate values.

| Entry-relative short index | Entry-relative byte offset | Stored type | Meaning |

## Usage example

```c
extern signed short D_8006B780_6C380[];

/* This helper only reads the verified native Congo entry, room 0x0016. */
int congo_arrival_fields(short *base_heading, short *packed_camera_start)
{
    if (!base_heading || !packed_camera_start) return 0;
    const signed short *start = &D_8006B780_6C380[0x0016u * 5u];
    *base_heading = start[3];
    *packed_camera_start = start[4];
    return 1;
}
```

Reads the two native arrival fields for one known room without accepting an arbitrary room index. The fifth field retains its packed camera startup semantics.

## Notes

- The unsized declaration provides no runtime bounds check. Do not index it with a newly allocated room ID.
- Keep packed camera startup distinct from base player heading and object Euler rotation. Values 0 through 39 select an in-range callback index; this bound alone does not prove every value works in every scene.
