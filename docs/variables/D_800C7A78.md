`D_800C7A78` · **Variable**

Unsigned 16-bit frame counter whose parity drives the native player hurt-recovery flicker.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x800C7A78` | — | `ABSOLUTE_SYMS` |

## Signature

```c
extern unsigned short D_800C7A78;
```

## How it works

A live unsigned 16-bit counter at g_system +0x3ADB8. The exact exported symbol has no ROM suffix.

The native frame-submission routine at 0x8000098C increments this counter when it submits a prepared frame. It wraps at the width of the stored halfword.

The player recovery updater reads this counter with LHU. While player task byte +0xD4 is nonzero, it writes object byte +0x64 = counter & 1: even parity is visible and odd parity hides rendering. When the timer reaches zero it forces the object visible.

The kind-2 model renderer checks object +0x64 bit 0 before drawing. That render flag does not remove the task, change its model or scale, or disable its collision body.

## Usage example

```c
extern unsigned short D_800C7A78;

/* Call during the normal update of a live, caller-owned kind-2 object. */
void apply_recovery_flicker(void *object, unsigned char recovery_active)
{
    unsigned char *bytes = object;
    if (!bytes) return;
    unsigned char hidden = recovery_active ? (D_800C7A78 & 1u) : 0;
    bytes[0x64] = (unsigned char)((bytes[0x64] & 0xFEu) | hidden);
}
```

Updates only the native render-hide bit, preserving the remaining object state. The original player recovery updater also manages invulnerability and its countdown; this visual helper does not replace that gameplay behavior.

## Notes

- This is a native frame counter, not elapsed seconds or a timestamp. Its phase is local to one running game.
- Do not simulate flicker by deleting or unbinding an actor, setting its scale to zero, or disabling collision. Native flicker changes the render flag only.
- Read the halfword at its exact width. A word access would include neighboring native state.
