## Signature

extern unsigned short D_8006D350_6DF50[];

## How it works

The chain allocator subtracts active counts from this table to decide whether a request fits. Element 2 controls model/display records.

Changing a numeric limit does not create backing records or expand related actor-owner capacity. Engine initialization can restore the table; any capacity customization must account for the complete pool lifecycle.

The native initialized kind-2 capacity is 192 records. These are shared by visible roots, effects, and lazily allocated animated-model cache nodes; the number is not a character count.

## Known values

These are the first eight 16-bit entries in the verified US image. The array index is the pool kind, while the stored value is a capacity. Initialization can change capacities. Only kind 2 has an established record-type name here.
