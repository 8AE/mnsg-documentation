`D_80203F34_5BFE44` · **Variable**

Per-character pointers to 0x1C-byte action metadata records.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80203F34` | `0x005BFE44` | `.file_11` |

## Signature

```c
extern unsigned char *D_80203F34_5BFE44[];
```

## How it works

Character indices are Goemon=0, Ebisumaru=1, Sasuke=2 and Yae=3. Known fields include model command +0x00, animation speed scaled by 100 at +0x04, data range +0x0C/+0x10, auxiliary selector +0x14 and auxiliary resource table +0x18.

An action index selects a record within that character table. The documented action range is 0 through 0xE7. Validate the selected data range against its action-file length before binding it.

## Known values

### Character action-table pointers {#character-action-tables}

The outer array is indexed by character ID. The stored values below are the native US overlay addresses of each character’s action-record table; they are meaningful only while that overlay is resident.

| Character index (hex) | Character index (decimal) | Character | Stored table pointer |
| --- | --- | --- | --- |
| `0x00` | `0` | Goemon | `0x801FCF98` |
| `0x01` | `1` | Ebisumaru | `0x801FE9F0` |
| `0x02` | `2` | Sasuke | `0x802005A0` |
| `0x03` | `3` | Yae | `0x80202228` |

### Action metadata record {#action-record-fields}

Select a character table, then add action_id × 0x1C. The record is 28 bytes long. Only interpreted fields are listed; gaps must not be assumed unused.

| Offset | Storage type | Meaning |
| --- | --- | --- |
| `+0x00` | `uint32_t` | Segmented model command address. |
| `+0x04` | `int16_t` | Animation step in hundredths: divide by 100.0 to obtain the frame increment. |
| `+0x0C` | `uint32_t` | Action model-data start address, using the 0x07 segment tag. |
| `+0x10` | `uint32_t` | Action model-data end address. Zero instructs the native action-range loader to use the end of the selected action file. |
| `+0x14` | `uint8_t` | Initial auxiliary row selected for the second auxiliary channel. |
| `+0x18` | 32-bit pointer | Auxiliary-resource row table. |

### Auxiliary resource rows {#auxiliary-row-fields}

Each auxiliary row occupies 8 bytes. These are nested records reached through action metadata +0x18.

| Offset | Storage type | Meaning |
| --- | --- | --- |
| `+0x00` | `uint32_t` | Resource ID. Zero means no resource bind; 0xFF is the timed-sequence loop marker. |
| `+0x04` | `uint8_t` | Animation-frame threshold component. Cursor advancement also depends on the accumulated threshold and frame-reset conditions; zero is not a universal stop flag. |

## Usage example

```c
extern unsigned char *D_80203F34_5BFE44[];

/* The gameplay overlay containing these tables must be resident. */
const unsigned char *character_action_record(unsigned int character,
                                             unsigned int action) {
    if (character >= 4u || action >= 0xE8u) return 0;
    return D_80203F34_5BFE44[character] + action * 0x1C;
}
```

## Notes

- These are immutable metadata tables. Do not mutate shared action data to customize one remote.
- The numeric action limit and layout are specific to this game version.
