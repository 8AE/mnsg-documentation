`D_80209BC8` · **Variable**

Native 12-byte descriptor selecting the 8 by 8 position dot from resource 0x8004.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80209BC8` | `0x005C5AD8` | `.file_0C` |

## Signature

```c
extern unsigned short D_80209BC8[6];
```

## How it works

The descriptor is six big-endian halfwords: C003, 0808, 0000, 0000, 0300, 0300. C003 loads texture-bank entry three and ends the sprite command sequence.

The dimensions are 8 by 8. Texture coordinates are stored in thirty-seconds of a pixel; 0x0300 selects X=24, Y=24 in the 64 by 32 sheet.

D_80209CA0 entry three refers to loaded file 0x007F and segmented address 0x0A000000. Its original pixels come from PIC resource 0x8004, not from the descriptor itself.

The minimap constructor initially selects this round red dot. Open-map updates select directional descriptors from the same native texture system.

## Usage example

```c
extern unsigned short D_80209BC8[6];

unsigned int minimap_dot_width(void)
{
    return D_80209BC8[1] >> 8;
}
```

The example illustrates the native interface and its required state.

## Notes

- Only access this layout while its owning overlay and task are active. Task-pool addresses can be reused after destruction.
