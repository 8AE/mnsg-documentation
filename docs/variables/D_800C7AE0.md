`D_800C7AE0` · **Variable**

Native system byte whose low two bits suspend the normal player collision update.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x800C7AE0` | — | `ABSOLUTE_SYMS` |

## Signature

```c
extern unsigned char D_800C7AE0;
```

## How it works

This byte occupies full system-structure offset +0x3AE20, at runtime address 0x800C7AE0. It is stored directly; it is not a pointer.

The late player update at 0x801CBAF8 tests (value & 3) before calling its world collision and contact handlers. Either low bit bypasses those handlers.

Bit 0x04 also suppresses selected player input actions, but does not by itself bypass the late collision handlers.

## Known values

### Verified control masks {#control-masks}

Bit masks in the native unsigned control byte. These masks can be combined; the table is not a complete enum.

| Mask (hex) | Mask (decimal) | Meaning |
| --- | --- | --- |
| `0x03` | `3` | Either low bit suspends the late player movement collision and contact handlers. |
| `0x04` | `4` | Suppresses selected player input actions; does not by itself suspend the late collision handlers. |

## Usage example

```c
extern unsigned char D_800C7AE0;

int native_player_collision_is_suspended(void)
{
    return (D_800C7AE0 & 3u) != 0;
}
```

The example illustrates the native interface and its required state.

## Notes

- The byte is a control mask, not a universal cutscene boolean. Script-driven movement can continue to use world collision while this low-bit mask is clear; inspect D_800C7AE3 for that separate state.
- Read this state during a valid gameplay lifecycle. Do not clear native bits to force player collision during scripted sequences.
