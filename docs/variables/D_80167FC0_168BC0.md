`D_80167FC0_168BC0` · **Variable**

Resident scene-file registry with a sentinel allocation cursor.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80167FC0` | — | `ABSOLUTE_SYMS` |

## Signature

```c
extern SceneResourceEntry D_80167FC0_168BC0[SCENE_RESOURCE_ENTRY_COUNT];
```

## How it works

An array of 48 records. Each record contains a 16-bit file ID, 16-bit padding and data pointer. The first record with file ID zero terminates the resident list; its data pointer gives the next free scene-arena destination.

Native loading updates the sentinel after each resource. Any additional scene allocation must preserve alignment, bounds and the cursor so later loads cannot overwrite it.

## Known values

### Resident resource entry fields {#resource-entry-fields}

The registry has 48 entries. Each N64 record occupies 8 bytes. Scan only until the first entry whose file ID is zero; its data pointer records the next free resident-arena position.

| Offset | Storage type | Meaning |
| --- | --- | --- |
| `+0x00` | `uint16_t` | File ID. Zero terminates the occupied entries. |
| `+0x02` | 2 bytes | Uninterpreted padding/field. |
| `+0x04` | 32-bit pointer | Loaded data base for a nonzero file ID; next free arena position for the first zero-file-ID entry. |

## Usage example

```c
#define SCENE_RESOURCE_ENTRY_COUNT 48
typedef struct SceneResourceEntry {
    unsigned short file_id, padding;
    unsigned char *data;
} SceneResourceEntry;

extern SceneResourceEntry D_80167FC0_168BC0[SCENE_RESOURCE_ENTRY_COUNT];

/* Inspect only after the native stage resource registry is initialized. */
void *scene_arena_cursor(void) {
    for (int i = 0; i < SCENE_RESOURCE_ENTRY_COUNT; ++i) {
        if (D_80167FC0_168BC0[i].file_id == 0)
            return D_80167FC0_168BC0[i].data;
    }
    return 0;
}
```

## Notes

- Do not overwrite the sentinel cursor without checking bounds, alignment and all later allocations.
- Model texture buffers need original RDRAM addresses below 0x80800000.
- All registry-backed addresses are scene-lifetime resources.
