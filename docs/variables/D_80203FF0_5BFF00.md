## Signature

## How it works

Each channel uses two bytes. The second byte selects the object segment whose base is written at +0x38 + segment*8 when the action initial auxiliary resource is staged.

The first byte purpose is not established by the documented lookup.

## Known values

### Initial auxiliary descriptors {#initial-descriptor-values}

The established portion contains two byte pairs. The second byte selects an object base slot using +0x38 + selector × 8. The first byte of each pair is preserved as uninterpreted data.

| Byte index | Channel / field | Stored value (hex) | Stored value (decimal) | Meaning |
| --- | --- | --- | --- | --- |
| `0` | Channel 0, first byte | `0x00` | `0` | Purpose not established. |
| `1` | Channel 0, selector | `0x03` | `3` | Object base slot +0x50. |
| `2` | Channel 1, first byte | `0x00` | `0` | Purpose not established. |
| `3` | Channel 1, selector | `0x04` | `4` | Object base slot +0x58. |
