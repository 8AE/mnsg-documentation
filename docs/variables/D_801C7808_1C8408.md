## Signature

## How it works

The choice parser converts each four-word script record into a five-word, 20-byte runtime record.

Selection points at a runtime record, while the branch continuation refers back to the scenario instruction stream. These are distinct layouts and addresses.

Native runtime storage holds at most 10 records. The parser does not bounds-check its input list, so custom scripts must not exceed this capacity.
