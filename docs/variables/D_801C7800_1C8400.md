`D_801C7800_1C8400` · **Variable**

Native 32-bit address of the currently selected scenario choice record.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x801C7800` | — | `ABSOLUTE_SYMS` |

## Signature

```c
extern unsigned int D_801C7800_1C8400;
```

## How it works

Points into the five-word runtime choice-record table after the choice parser completes.

A two-choice Yes/No list uses the first record for Yes and the next record, five words later, for No. A private dialog can choose No initially after parsing to avoid accepting a held confirmation input.

## Notes

- The stored value is a native address, not 0 for Yes or 1 for No.
- Do not select a record outside the parsed list or modify a replacement native conversation.
