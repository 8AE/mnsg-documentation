`D_801FC604_5B8514` · **Variable**

Pointer to the current player task.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x801FC604` | `0x005B8514` | `.file_11` |

## Signature

```c
extern void *D_801FC604_5B8514;
```

## How it works

Use this task as the owner when creating a child associated with the player through func_802171A8_5D2678.

The player object is held separately at D_801FC60C_5B851C. Task storage contains callbacks and scheduling state rather than directly beginning with xyz coordinates.

The task contains the selected character byte at +0x60 and current action byte at +0xCC. It also owns the primary display object and can provide an owner for appropriately scoped visual child tasks.

The task pool can reuse an address after a room transition. Validate scene, linkage and ownership before retaining or dereferencing this pointer.

## Known values

### Player task fields {#player-task-fields}

Dereference the variable to obtain the player task. In this task type, +0x5C is a pointer to player work, rather than the ordinary actor-ID field.

| Offset | Storage type | Meaning |
| --- | --- | --- |
| `+0x18` | 32-bit pointer | Player render object. |
| `+0x30` | `uint8_t` | Contact flags: bit 0x01 accepts ordinary incoming hits, 0x02 enables outgoing attack scans, and 0x04 selects the native special incoming-hit filter. |
| `+0x34` | 32-bit pointer | Victim task hit by this task during the native scan; nonzero stops further victim scanning. |
| `+0x38` | 32-bit pointer | Incoming attacker task. Native collision-dependent callbacks consume this hit record. |
| `+0x3C` | `uint16_t` | Unscaled body radius copied from D_801FC660_5B8570 for the selected character. Native body contacts apply object scale X. |
| `+0x3E` | `uint16_t` | Unscaled body height copied from D_801FC668_5B8578 for the selected character. Native body contacts apply object scale Y. |
| `+0x44` | `uint8_t` | One-based sphere index recorded by an incoming native contact. This is not a health-damage amount. |
| `+0x48` | 32-bit descriptor | Active outgoing attack descriptor. Zero disables attack volumes; 0xFFFFFFFF selects the fixed sphere fields. |
| `+0x4C` | `uint8_t` | Native outgoing attack kind used by victim filters and damage handling; separate from the sphere index. |
| `+0x5C` | 32-bit pointer | Player work/state block. |
| `+0x60` | `uint8_t` | Selected character ID; see [`D_8015C5D8_15D1D8`](./D_8015C5D8_15D1D8.md#known-values). |
| `+0xCC` | `uint8_t` | Current native player action. |
| `+0xD4` | `uint8_t` | Player damage invulnerability countdown. While nonzero, the updater applies D_800C7A78 parity to render-object +0x64; expiry restores visible rendering and ordinary incoming contact. |

### Known player action values {#known-player-actions}

These are selected values of the action byte at player task +0xCC. Action semantics can depend on the selected character; this is not a complete native action list.

| Raw value (hex) | Raw value (decimal) | Meaning |
| --- | --- | --- |
| `0x00` | `0` | Idle. |
| `0x8E` | `142` | Ebisumaru shrink action. |
| `0x8F` | `143` | Ebisumaru grow action. |
| `0xBA` | `186` | Character-change transition. |

### Player work fields {#player-work-fields}

First read the pointer at task +0x5C, then apply these work-relative offsets. These fields are not located directly in the task.

| Offset | Storage type | Meaning |
| --- | --- | --- |
| `+0x69` | `uint8_t` | Character-change marker; the native character setter writes 1. |
| `+0x84` | `uint8_t` | Goemon Sudden Impact marker; the appearance reader recognizes exactly 1 as active. Other values are not established active states. |
| `+0x86` | `uint16_t` | Ebisumaru small-form marker: nonzero spans the shrink/small/grow interval; the native character-change path clears it to zero. |

## Notes

- Validate the player task and its lifetime before allocating children.
- Pointers are reused by the task pool; compare lifecycle/ownership as well as address.
- The 0x80000000 engine sentinel is not a live object.
