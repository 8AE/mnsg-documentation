| `0x801FC604` | `0x005B8514` | `.file_11` |

## Signature

```c
extern void *D_801FC604_5B8514;
```

## How it works

Use this task as the owner when creating a child associated with the player through func_802171A8_5D2678.

The player object is held separately at D_801FC60C_5B851C. Task storage contains callbacks and scheduling state rather than directly beginning with xyz coordinates.

The task contains the selected character byte at +0x60 and current action byte at +0xCC. It also owns the primary display object and can provide an owner for appropriately scoped visual child tasks.

The task pool can reuse an address after a room transition. Validate scene, linkage and ownership before retaining or dereferencing this pointer.

## Notes

- Validate the player task and its lifetime before allocating children.
- Pointers are reused by the task pool; compare lifecycle/ownership as well as address.
- The 0x80000000 engine sentinel is not a live object.
