`D_8015C604` · **Variable**

Mutable 32-bit weapon selection whose character-specific slots distinguish ordinary weapons from secondary and third weapons.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x8015C604` | — | `ABSOLUTE_SYMS` |

## Signature

```c
extern unsigned int D_8015C604;
```

## How it works

Stores the current selected weapon as a 32-bit word at runtime address 0x8015C604, four bytes before the save-data base D_8015C608_15D208. It is mutable selection state, not a packed acquisition flag.

Value 1 selects the ordinary tiered weapon. Values 2 and 3 select character-specific secondary and third weapons. For Ebisumaru, slot 2 is the Meat Hammer and slot 3 is the Wind-up Camera.

The native weapon-cycle path permits the 1-to-2 transition when the character equipment word at save +0xB4 + character_index * 4 is nonzero. Ebisumaru uses save +0xB8 for that acquisition check.

The attack initializer consumes this selection while arming a native attack. Inspect the already armed task kind to identify that attack afterward; a later selection change does not by itself rewrite an existing attack sphere.

## Known values

### Selected weapon slots {#selected-weapon-slots}

Stored 32-bit selection values. Ebisumaru meanings apply only when the active character index is 1. These values are neither acquisition flags nor native attack-kind bytes.

| Stored value (hex) | Stored value (decimal) | General meaning | Ebisumaru weapon | Ebisumaru armed attack kind |
| --- | --- | --- | --- | --- |
| `0x01` | `1` | Ordinary tiered weapon | Ordinary mallet | `0x15`, `0x16` or `0x17`, according to tier |
| `0x02` | `2` | Character-specific secondary weapon | Meat Hammer | `0x1D` |
| `0x03` | `3` | Character-specific third weapon | Wind-up Camera | `0x14` |

## Usage example

```c
extern unsigned int D_8015C604;

unsigned int selected_weapon_slot(void)
{
    return *(volatile unsigned int *)&D_8015C604;
}
```

Read the full native selection word. Interpret slots 2 and 3 together with the active character; this accessor does not establish that an attack is currently armed.

## Notes

- Preserve the 32-bit storage width. The negative save-relative offset is adjacent runtime storage, not a save-flag array index.
- Owning a weapon and selecting it are separate states. Do not infer attack contact or damage from the selection word alone.
