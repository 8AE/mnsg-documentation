`D_80204028_5BFF38` · **Variable**

Four file IDs for raw playable-character action-model data.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80204028` | `0x005BFF38` | `.file_11` |

## Signature

```c
extern unsigned short D_80204028_5BFF38[];
```

## How it works

Index order is Goemon, Ebisumaru, Sasuke, Yae. The action metadata in D_80203F34_5BFE44 supplies ranges within the corresponding raw file.

The whole file may be cached and shared read-only. Per-instance appearance substitutions require private writable slices rather than modification of the shared cache.

## Known values

### Action-model resource IDs {#known-resource-ids}

The array index is a character ID (0–3). The stored 16-bit value is a native file ID, not an address or a character ID. These are the initial US overlay values.

| Character index | Character | Stored file ID (hex) | Stored file ID (decimal) | Meaning |
| --- | --- | --- | --- | --- |
| `0` | Goemon | `0x123` | `291` | Raw action-model resource file. |
| `1` | Ebisumaru | `0x127` | `295` | Raw action-model resource file. |
| `2` | Sasuke | `0x12B` | `299` | Raw action-model resource file. |
| `3` | Yae | `0x12F` | `303` | Raw action-model resource file. |
