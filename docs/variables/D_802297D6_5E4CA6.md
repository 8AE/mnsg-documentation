`D_802297D6_5E4CA6` · **Variable**

Native actor metadata containing model IDs and owner categories.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x802297D6` | — | `ABSOLUTE_SYMS` |

## Signature

```c
extern unsigned char D_802297D6_5E4CA6[];
```

## How it works

The native room actor manager reads a signed 16-bit model ID at base + actor_id * 2 and an unsigned category byte at base + actor_id + 0x80D.

The category selects the owner through func_80219CA0_5D5170, and the model ID is supplied to func_8003555C_3615C. The surrounding aggregate structure is not fully named.

The model ID is read as a signed 16-bit value at byte actor_id*2. The owner category is an unsigned byte at actor_id+0x80D.

Validate actor IDs before either lookup. The byte-array declaration combines recovered packed table regions; it does not describe their complete bounds.
