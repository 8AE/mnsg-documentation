`D_80077860_78460` · **Variable**

Pointer to the native task that owns the shared scenario interpreter.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x80077860` | `0x00078460` | `.main` |

## Signature

```c
extern void *D_80077860_78460;
```

## How it works

A live scenario manager is a prerequisite for opening an ordinary native dialog.

Remember the manager identity while an interaction is active. If the manager pointer changes, the old interaction must treat shared scenario/window ownership as replaced.

## Usage example

```c
extern void *D_80077860_78460;

int same_scenario_manager(const void *expected)
{
    return expected && D_80077860_78460 == expected;
}
```

Complete C syntax using the reviewed 32-bit native interface. The engine owns these globals and resources; respect the stated lifecycle and ownership checks.

## Notes

- A nonnull manager alone does not establish that its interpreter and windows are idle or that the world is safe for input.
