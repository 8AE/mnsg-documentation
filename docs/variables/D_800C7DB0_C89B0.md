`D_800C7DB0_C89B0` · **Variable**

Inline storage for four derived gameplay-controller records, separate from raw dialog input.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x800C7DB0` | — | `ABSOLUTE_SYMS` |

## Signature

```c
extern unsigned char D_800C7DB0_C89B0[0x60];
```

## How it works

Inline native storage at full-system +0x3B0F0 contains four records of 0x18 bytes each. It is distinct from the raw controller input used by the scenario sampler.

The native gameplay-input copier fills these records from raw input only while both D_800C7AE2 and D_800C7AE3 are zero. Otherwise it decays the stick state and recomputes analog quantities without copying new buttons.

The scenario sampler reads raw controller input separately. Filtering the derived gameplay records after the native input-copy update can suppress player buttons/stick while leaving the native dialog responsive; it does not require changing raw input or holding a global player lock between updates.

## Known values

### Derived gameplay-controller record {#gameplay-controller-layout}

Offsets are relative to one of four 0x18-byte records in this inline 0x60-byte block. Read native-width values with the correct offset origin.

| Record-relative offset | Storage type | Meaning |
| --- | --- | --- |
| `0x00` | `uint16_t` | Controller connected/status value |
| `0x02` | `uint16_t` | Held buttons |
| `0x04` | `uint16_t` | Newly pressed buttons |
| `0x06` | `int16_t` | Stick X |
| `0x08` | `int16_t` | Stick Y |
| `0x0A` | `2 bytes` | Unresolved field; do not assign an enum meaning |
| `0x0C` | `float` | Analog magnitude |
| `0x10` | `float` | Derived analog X |
| `0x14` | `float` | Derived analog Y |

## Usage example

```c
extern unsigned char D_800C7DB0_C89B0[0x60];

unsigned short gameplay_buttons_held(unsigned int controller)
{
    if (controller >= 4) return 0;
    const unsigned char *record = &D_800C7DB0_C89B0[controller * 0x18u];
    return *(const unsigned short *)(record + 2);
}
```

The example validates the record index and reads its native held-button halfword. It does not modify raw input or player-control ownership.

## Notes

- This symbol is inline storage, not a pointer variable.
- Player-input and native scenario-input storage are separate. Clearing raw input would also make an interactive dialog unresponsive.
- Acquire and release the associated control lock according to scenario ownership. Do not clear a lock installed by a replacement native scene.
