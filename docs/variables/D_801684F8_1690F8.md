`D_801684F8_1690F8` · **Variable**

Signed32 lighting state used while preparing the current graphics bank.

| Runtime address | ROM address | Section |
| --- | --- | --- |
| `0x801684F8` | — | `ABSOLUTE_SYMS` |

## Signature

```c
extern int D_801684F8_1690F8;
```

## How it works

func_80016950 resets this state to zero. Native lighting setup uses it while accumulating lighting work and marks it -1 after the pending state has been applied.

It participates in command emission alongside the separate active-light count D_801684FC. It is not a model count or a graphics-bank capacity.

## Usage example

```c
extern int D_801684F8_1690F8;

int native_lighting_state(void) {
    return D_801684F8_1690F8;
}
```

The example illustrates the native interface and its required state.

## Notes

- Only the reset and applied marker are established here. Other numeric values retain native accumulation semantics and are not a complete enum.
- A custom command preflight must account for light emission; do not treat this state as an independent lighting override.
